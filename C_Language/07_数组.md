## 1. 一维数组

### 1.1 什么是数组

**数组**是**相同类型**的多个元素在内存中**连续存放**的集合，通过**下标**访问。

```c
int scores[5];          // 5 个 int，下标 0 ~ 4
```

```
地址 →   低                                          高
        ┌───────┬───────┬───────┬───────┬───────┐
scores  │ [0]   │ [1]   │ [2]   │ [3]   │ [4]   │   每格 4 字节
        └───────┴───────┴───────┴───────┴───────┘
        ← 连续 5 × 4 = 20 字节 →
```

### 1.2 定义语法

```c
类型 数组名[元素个数];
```

- 元素个数在传统 C 中必须是**整型常量表达式**（字面量、`#define`、`enum` 常量）；
- `const int n = 5; int a[n];` 在 C 中**不是**常量表达式，被当作 VLA（第 6 节）；
- 下标**从 0 开始**，最后一个下标是 `n - 1`。

```c
#define N 10
int a[N];                 // ✔
int b[3 + 2];             // ✔ 常量表达式
double c[100];
char name[20];
```

### 1.3 访问元素

```c
int a[5];
a[0] = 10;                // 第一个元素
a[4] = 50;                // 最后一个元素
int x = a[2];
a[i + 1] = a[i] * 2;      // 下标可以是任意整型表达式
```

### 1.4 遍历

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int n = sizeof(a) / sizeof(a[0]);       // 元素个数：20 / 4 = 5

    for (int i = 0; i < n; i++)
        printf("a[%d] = %d\n", i, a[i]);

    int sum = 0;
    for (int i = 0; i < n; i++) sum += a[i];
    printf("sum = %d, avg = %.1f\n", sum, (double)sum / n);
    return 0;
}
```

`sizeof(a) / sizeof(a[0])` 是求数组元素个数的标准惯用法，常封装成宏：
```c
#define ARRAY_SIZE(a)  (sizeof(a) / sizeof((a)[0]))
```
> **只对真正的数组有效**，对函数形参（实质是指针）无效。

### 1.5 数组在内存中的性质

```c
int a[5] = {1, 2, 3, 4, 5};
printf("%p %p %p\n", (void *)&a[0], (void *)&a[1], (void *)&a[2]);
// 相邻元素地址相差 sizeof(int) = 4
```

- 元素**连续**存放，这是随机访问 O(1) 与缓存友好的原因；
- **数组名**在大多数表达式中会转换成**指向首元素的指针**（第 8 章详述）；
- 数组整体**不能赋值、不能用 `==` 比较**：

```c
int a[3] = {1,2,3}, b[3];
b = a;                    // ✘ 数组名不是可修改的左值
if (a == b) { }           // ✘ 比较的是两个地址，不是内容
// 正确做法：逐个复制 / memcpy / memcmp
for (int i = 0; i < 3; i++) b[i] = a[i];
memcpy(b, a, sizeof a);   // <string.h>
```

## 2. 数组的初始化

### 2.1 各种写法

```c
int a[5] = {1, 2, 3, 4, 5};     // 完全初始化
int b[5] = {1, 2};              // 部分初始化：其余元素为 0 → {1,2,0,0,0}
int c[5] = {0};                 // 全部为 0（最常用的清零写法）
int d[]  = {1, 2, 3};           // 省略长度，由初值个数决定 → 长度 3
int e[5] = {};                  // 空花括号：C23 标准；GCC 以前作为扩展
int f[3] = {1,2,3,4};           // ✘ 初值过多：警告 / 错误
```

### 2.2 不初始化时的值

| 数组 | 初值 |
|---|---|
| 局部（自动）数组 | **不确定（垃圾值）** |
| 全局 / `static` 数组 | **全 0** |

```c
int g[5];                       // 全局：全 0

int main(void)
{
    int a[5];                   // 垃圾值！使用前必须初始化
    static int s[5];            // 全 0
}
```

### 2.3 指定初始化器（C99）

可以只给指定下标赋初值，其余为 0：

```c
int a[10] = { [2] = 5, [5] = 7 };           // {0,0,5,0,0,7,0,0,0,0}
int b[] = { [3] = 1 };                       // 长度为 4
int c[6] = { 1, 2, [4] = 9, 10 };            // {1,2,0,0,9,10}：指定后继续顺序往后

const char *names[] = { [0] = "zero", [2] = "two" };   // 中间的为 NULL
```
常用于稀疏表、查找表、状态映射。

### 2.4 用 `sizeof` 让长度"自动适应"

```c
int primes[] = {2, 3, 5, 7, 11, 13};
int n = sizeof primes / sizeof primes[0];    // 6，增删元素时无需改数字
```

### 2.5 字符串初始化（预览）

```c
char s1[] = "abc";             // 长度 4：'a' 'b' 'c' '\0'
char s2[5] = "abc";            // {'a','b','c','\0','\0'}
char s3[3] = "abc";            // 能编译，但没有 '\0'，不是合法字符串！
```

## 3. 数组越界

### 3.1 C 不检查下标

```c
int a[5] = {0};
a[5] = 1;        // ✘ 越界（合法下标 0~4）
a[-1] = 1;       // ✘ 越界
a[100] = 1;      // ✘ 越界
```
这些都是**未定义行为（UB）**：可能"什么事都没发生"，可能改坏其他变量，可能崩溃，也可能被攻击者利用（缓冲区溢出）。

### 3.2 经典 bug

```c
int a[5];
for (int i = 0; i <= 5; i++)        // ✘ 应为 i < 5
    a[i] = 0;
```
在某些编译布局下，`a[5]` 恰好覆盖循环变量 `i`，导致**死循环**——这是一个著名的诡异 bug。

### 3.3 检测方法

```bash
gcc -g -fsanitize=address,undefined demo.c -o demo && ./demo
```
AddressSanitizer 会精确报告：
```
ERROR: AddressSanitizer: stack-buffer-overflow ... WRITE of size 4
```
`-Wall -Warray-bounds -O2` 可在编译期发现部分越界。

### 3.4 合法的"越界一位"

指针可以指向数组**最后一个元素的下一个位置**（只用来比较/计算，不能解引用）：

```c
int a[5];
int *end = a + 5;                   // 合法
for (int *p = a; p != end; p++) { } // 标准写法
```

## 4. 数组的常见操作

### 4.1 求最大、最小值及位置

```c
int max = a[0], imax = 0;
for (int i = 1; i < n; i++) {
    if (a[i] > max) { max = a[i]; imax = i; }
}
```
> 初始值取 `a[0]` 而不是 `0`：否则全为负数时会得到错误结果。

### 4.2 反转

```c
for (int i = 0, j = n - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
// {1,2,3,4,5} → {5,4,3,2,1}
```

### 4.3 复制与比较

```c
#include <string.h>
memcpy(dst, src, n * sizeof src[0]);
if (memcmp(a, b, n * sizeof a[0]) == 0) { /* 内容相同 */ }
```
> `memcmp` 对 `int` 数组仅能判断**是否相等**；对浮点数（`NaN`、`-0.0` 与 `0.0`）、含填充字节的结构体不可靠。

### 4.4 线性查找

```c
int find(const int *a, int n, int key)
{
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}
```

### 4.5 插入与删除（元素移动）

```c
// 在下标 pos 处插入 x（数组容量足够，当前长度 n）
for (int i = n; i > pos; i--) a[i] = a[i - 1];    // 从后往前移
a[pos] = x;
n++;

// 删除下标 pos 的元素
for (int i = pos; i < n - 1; i++) a[i] = a[i + 1];  // 从前往后移
n--;
```
插入/删除是 O(n)，这是数组的短板（第 16 章链表可改善）。

### 4.6 去重（有序数组，双指针）

```c
int unique(int *a, int n)          // 返回去重后的长度
{
    if (n == 0) return 0;
    int k = 1;
    for (int i = 1; i < n; i++)
        if (a[i] != a[k - 1]) a[k++] = a[i];
    return k;
}
// {1,1,2,2,2,3} → {1,2,3}，返回 3
```

### 4.7 统计频次（计数数组）

```c
// 统计字符串中各小写字母出现次数
int cnt[26] = {0};
for (const char *p = s; *p; p++)
    if (*p >= 'a' && *p <= 'z') cnt[*p - 'a']++;
for (int i = 0; i < 26; i++)
    if (cnt[i]) printf("%c: %d\n", 'a' + i, cnt[i]);
```
**用下标作为"键"**是 C 中极常见的技巧（桶思想）。

### 4.8 前缀和

`sum[i]` 表示 `a[0..i-1]` 的和，则区间 `[l, r)` 的和 = `sum[r] - sum[l]`，查询 O(1)。

```c
long long sum[N + 1] = {0};
for (int i = 0; i < n; i++) sum[i + 1] = sum[i] + a[i];
long long range = sum[r] - sum[l];          // a[l] + ... + a[r-1]
```

### 4.9 数组循环右移 k 位（三次反转）

```c
void reverse(int *a, int l, int r) { while (l < r) { int t = a[l]; a[l++] = a[r]; a[r--] = t; } }

void rotate_right(int *a, int n, int k)
{
    k %= n;
    reverse(a, 0, n - 1);
    reverse(a, 0, k - 1);
    reverse(a, k, n - 1);
}
// {1,2,3,4,5}, k=2 → {4,5,1,2,3}
```

## 5. 二维数组与多维数组

### 5.1 定义与初始化

```c
int m[3][4];                       // 3 行 4 列，共 12 个 int

int a[2][3] = { {1, 2, 3},
                {4, 5, 6} };        // 按行初始化（推荐）
int b[2][3] = {1, 2, 3, 4, 5, 6};   // 按顺序平铺初始化（能编译，但可读性差）
int c[2][3] = { {1}, {4, 5} };      // 部分初始化，其余为 0 → {{1,0,0},{4,5,0}}
int d[][3]  = { {1,2,3}, {4,5,6}, {7,8,9} };   // 只能省略第一维 → 3 行
int e[3][3] = {0};                  // 全 0
int f[3][3] = { [1][1] = 5 };       // 指定初始化，只有中心为 5
```

**规则**：**只有第一维可以省略**，其余维度必须写明，因为编译器需要它们来计算偏移。

### 5.2 内存布局：行优先（Row-major）

二维数组实际上是**"数组的数组"**：`int a[2][3]` 是由 2 个元素组成的数组，每个元素是 `int[3]`。在内存中仍是**一维连续**排列，**一行接一行**：

```
逻辑视图：              内存布局（连续）：
        列0 列1 列2
行0 [   1   2   3 ]     a[0][0] a[0][1] a[0][2] a[1][0] a[1][1] a[1][2]
行1 [   4   5   6 ]       1       2       3       4       5       6
```

`a[i][j]` 的偏移量 = `(i * 列数 + j) * sizeof(元素)`。

```c
int a[2][3] = {{1,2,3},{4,5,6}};
int *p = &a[0][0];
for (int k = 0; k < 6; k++) printf("%d ", p[k]);     // 1 2 3 4 5 6（按一维访问）

printf("%zu %zu %zu\n", sizeof a, sizeof a[0], sizeof a[0][0]);   // 24 12 4
```

### 5.3 遍历：外层行，内层列

```c
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++)
        printf("%3d", a[i][j]);
    putchar('\n');
}
```
**按行遍历（内层循环变化的是最后一维）与内存顺序一致，缓存命中率高**；按列遍历（内层变第一维）在大数组上会明显变慢。

### 5.4 例：矩阵运算

**转置**
```c
int a[2][3] = {{1,2,3},{4,5,6}}, t[3][2];
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 3; j++)
        t[j][i] = a[i][j];
```

**矩阵乘法** `C[n][p] = A[n][m] × B[m][p]`
```c
#define N 2
#define M 3
#define P 2

void matmul(int a[N][M], int b[M][P], int c[N][P])
{
    for (int i = 0; i < N; i++)
        for (int j = 0; j < P; j++) {
            c[i][j] = 0;
            for (int k = 0; k < M; k++)
                c[i][j] += a[i][k] * b[k][j];
        }
}
```

**方阵对角线、杨辉三角、螺旋矩阵、魔方阵**等是常见练习。

**杨辉三角**
```c
int tri[10][10] = {0};
for (int i = 0; i < 10; i++) {
    tri[i][0] = 1;
    for (int j = 1; j <= i; j++)
        tri[i][j] = tri[i - 1][j - 1] + tri[i - 1][j];
}
```
（当 `j == i` 时，`tri[i-1][j]` 是上一行右侧为 0 的元素，因此公式依然成立。）

### 5.5 三维及更高维

```c
int cube[2][3][4];                // 2 层，每层 3 行 4 列，共 24 个元素
cube[1][2][3] = 100;
```
实际中很少超过三维。

### 5.6 "锯齿数组"：指针数组（预览）

行长度不同的"二维表"通常用**指针数组**或动态分配实现（第 8、11 章）：
```c
int r0[] = {1}, r1[] = {2, 3}, r2[] = {4, 5, 6};
int *jag[] = { r0, r1, r2 };
int len[]  = { 1, 2, 3 };
```

## 6. 变长数组（VLA）

### 6.1 什么是 VLA

C99 允许数组长度是**运行时才确定的变量**：

```c
#include <stdio.h>

int main(void)
{
    int n;
    if (scanf("%d", &n) != 1 || n <= 0) return 1;

    int a[n];                            // VLA：长度由 n 决定
    for (int i = 0; i < n; i++) a[i] = i * i;

    printf("%zu\n", sizeof a);           // n * sizeof(int)，运行时计算
    return 0;
}
```

### 6.2 特点与限制

- 创建在**栈**上，离开作用域自动释放；
- **不能初始化**：`int a[n] = {0};` 非法（需要 `memset`）；
- **不能是全局或 `static`**；
- 一旦创建，**长度不能改变**（"变长"指"创建时长度可变"）；
- **C11 起为可选特性**（`__STDC_NO_VLA__` 宏表示不支持），C++ 不支持；
- 长度为 0 或负数、过大时，**未定义行为**（栈溢出）。

### 6.3 使用建议

| 场景 | 建议 |
|---|---|
| 小而固定上限的数据 | 普通数组 |
| 数据量由用户/文件决定、可能很大 | **`malloc`**（第 11 章） |
| 作为函数参数的维度声明 | VLA 语法有用（见 7.4） |
| 安全关键/嵌入式代码 | 通常禁止 VLA（MISRA 等） |

可以用 `-Wvla` 让编译器对 VLA 发出警告。

## 7. 数组作为函数参数

### 7.1 退化（Decay）为指针

**数组名在作为函数实参时，会转换成指向首元素的指针**，数组内容并不会被复制。

```c
void print(int a[], int n)      // 与 void print(int *a, int n) 完全等价
{
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    putchar('\n');
}

int main(void)
{
    int arr[5] = {1, 2, 3, 4, 5};
    print(arr, 5);              // 传入首元素地址
    return 0;
}
```

**推论**：

1. 函数内**无法**通过 `sizeof` 得到数组长度（得到的是指针大小）；**必须另传长度参数**；
2. 函数内对数组元素的修改**会影响**调用者的数组；
3. 形参中写的长度 `int a[10]` 会被**忽略**，编译器不检查。

```c
void f(int a[10])
{
    printf("%zu\n", sizeof a);        // 8（64 位平台）：这是指针的大小，不是 40！
}
```
GCC 会警告：`'sizeof' on array function parameter 'a' will return size of 'int *'`。

### 7.2 只读参数加 const

```c
int sum(const int a[], int n)        // 承诺不修改数组
{
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
```

### 7.3 修改数组的函数

```c
void fill(int a[], int n, int v)   { for (int i = 0; i < n; i++) a[i] = v; }
void double_all(int *a, int n)     { for (int i = 0; i < n; i++) a[i] *= 2; }
```

### 7.4 二维数组作为参数

**必须指明除第一维以外的所有维度**：

```c
void print_matrix(int m[][4], int rows)           // 等价于 int (*m)[4]
{
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 4; j++) printf("%3d", m[i][j]);
        putchar('\n');
    }
}

int a[3][4] = { /* ... */ };
print_matrix(a, 3);
```
原因：`m[i][j]` 需要知道一行有多长才能算出偏移，所以列数必须是编译期可知。

**借助 VLA 语法支持任意尺寸**（C99，**维度参数要写在数组参数之前**）：

```c
void print_matrix2(int rows, int cols, int m[rows][cols])
{
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) printf("%3d", m[i][j]);
        putchar('\n');
    }
}
```
> 这里的 `m[rows][cols]` 等价于 `int (*m)[cols]`——一个指向"含 `cols` 个 `int` 的一维数组"的指针（第 8 章详解）。

**另一种通用做法**：当成一维数组处理：
```c
void print_flat(const int *p, int rows, int cols)
{
    for (int i = 0; i < rows; i++, putchar('\n'))
        for (int j = 0; j < cols; j++)
            printf("%3d", p[i * cols + j]);
}
// 调用：print_flat(&a[0][0], 3, 4);
```

### 7.5 函数不能返回数组

C 函数不能直接返回数组，替代方法：

```c
// ① 让调用者提供输出数组（推荐）
void squares(int out[], int n) { for (int i = 0; i < n; i++) out[i] = i * i; }

// ② 返回 malloc 出来的内存（调用者负责 free）
int *make_array(int n) { return malloc(n * sizeof(int)); }

// ③ 返回 static 数组的地址（不可重入，不线程安全）
// ④ 把数组包进结构体按值返回（第 10 章）
```

## 8. 字符数组预览

字符串在 C 中就是**以 `'\0'` 结尾的 `char` 数组**（第 9 章详述）。

```c
char s[10] = "hello";
//  下标:  0   1   2   3   4   5   6..9
//  内容: 'h' 'e' 'l' 'l' 'o' '\0'  0 ...
printf("%s\n", s);                 // hello
printf("%zu %zu\n", sizeof s, strlen(s));    // 10 5
```
- `sizeof` 是数组总大小，`strlen` 是 `'\0'` 之前的字符数；
- 字符数组必须有足够空间容纳 `'\0'`；
- 不能用 `=` 赋值字符串，应使用 `strcpy`/`snprintf`；
- 不能用 `==` 比较，应使用 `strcmp`。

## 9. 经典算法：排序与查找

### 9.1 复杂度速览

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|---|---|---|---|---|---|
| 冒泡排序 | O(n)（带优化） | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |

（快排、归并、堆排序等在第 16 章详述。）

### 9.2 冒泡排序

反复比较相邻元素，把较大的"冒泡"到末尾。

```c
void bubble_sort(int a[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {      // 每轮后最大的 i+1 个已就位
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;                       // 一轮没有交换：已有序，提前结束
    }
}
```

过程（`{5, 3, 8, 1}`）：
```
第 1 轮： 5 3 8 1 → 3 5 8 1 → 3 5 8 1 → 3 5 1 8
第 2 轮： 3 5 1 8 → 3 5 1 8 → 3 1 5 8
第 3 轮： 3 1 5 8 → 1 3 5 8
```

### 9.3 选择排序

每轮从未排序部分选出最小的，放到已排序部分末尾。交换次数少（≤ n−1）。

```c
void selection_sort(int a[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[min]) min = j;
        if (min != i) { int t = a[i]; a[i] = a[min]; a[min] = t; }
    }
}
```

### 9.4 插入排序

像整理扑克牌：把每个新元素插入到前面已排序序列的合适位置。**对近乎有序的数据非常快**。

```c
void insertion_sort(int a[], int n)
{
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];           // 大于 key 的元素后移
            j--;
        }
        a[j + 1] = key;
    }
}
```

### 9.5 标准库排序 qsort（预览，第 8 章详述）

```c
#include <stdlib.h>

int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);          // 不要用 x - y：可能溢出
}

qsort(a, n, sizeof a[0], cmp_int);
```

### 9.6 二分查找（要求数组**有序**）

每次与中间元素比较，把范围缩小一半，O(log n)。

```c
int binary_search(const int a[], int n, int key)
{
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;      // 不写 (lo + hi) / 2：可能溢出
        if (a[mid] == key)      return mid;
        else if (a[mid] < key)  lo = mid + 1;
        else                    hi = mid - 1;
    }
    return -1;
}
```
要点：
- 区间约定为闭区间 `[lo, hi]`，循环条件 `lo <= hi`，更新为 `mid ± 1`；
- 100 万个元素最多只需约 20 次比较；
- 若有重复元素，需要"找第一个/最后一个"的变体（左边界/右边界二分）。

**左边界（第一个 ≥ key 的位置）**
```c
int lower_bound(const int a[], int n, int key)
{
    int lo = 0, hi = n;                    // 半开区间 [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < key) lo = mid + 1;
        else              hi = mid;
    }
    return lo;                              // 范围 [0, n]
}
```

## 10. 其他常见算法

### 10.1 埃氏筛法：求 N 以内所有素数

```c
#include <stdbool.h>
#include <stdio.h>

#define N 100

int main(void)
{
    bool composite[N + 1] = {false};         // composite[i] 为 true 表示 i 是合数

    for (int i = 2; (long long)i * i <= N; i++) {
        if (!composite[i]) {
            for (int j = i * i; j <= N; j += i)   // 从 i*i 开始划掉 i 的倍数
                composite[j] = true;
        }
    }

    int cnt = 0;
    for (int i = 2; i <= N; i++)
        if (!composite[i]) { printf("%d ", i); cnt++; }
    printf("\n共 %d 个\n", cnt);               // 25 个
    return 0;
}
```
复杂度约 O(n log log n)，远快于逐个试除。

### 10.2 合并两个有序数组（归并的核心）

```c
void merge(const int a[], int na, const int b[], int nb, int out[])
{
    int i = 0, j = 0, k = 0;
    while (i < na && j < nb)
        out[k++] = (a[i] <= b[j]) ? a[i++] : b[j++];
    while (i < na) out[k++] = a[i++];
    while (j < nb) out[k++] = b[j++];
}
```

### 10.3 两数之和（有序数组，双指针）

```c
// 在有序数组中找两个数，和为 target
int l = 0, r = n - 1;
while (l < r) {
    int s = a[l] + a[r];
    if (s == target) { printf("%d %d\n", a[l], a[r]); break; }
    else if (s < target) l++;
    else r--;
}
```

### 10.4 约瑟夫环（数组模拟）

n 个人围成一圈，从 1 开始报数，报到 m 的出圈，求出圈顺序。

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    int n = 7, m = 3;
    bool out[8] = {false};
    int left = n, pos = 0, cnt = 0;

    while (left > 0) {
        pos = pos % n + 1;                 // 在 1..n 循环
        if (out[pos]) continue;
        if (++cnt == m) {
            printf("%d ", pos);            // 出圈
            out[pos] = true;
            cnt = 0;
            left--;
        }
    }
    putchar('\n');                         // 3 6 2 7 5 1 4
    return 0;
}
```

### 10.5 螺旋矩阵输出（n×n）

```c
#define N 5

int a[N][N] = {0};
int top = 0, bottom = N - 1, left = 0, right = N - 1, v = 1;

while (top <= bottom && left <= right) {
    for (int j = left; j <= right; j++)  a[top][j] = v++;       // 上边，从左到右
    top++;
    for (int i = top; i <= bottom; i++)  a[i][right] = v++;     // 右边，从上到下
    right--;
    if (top <= bottom) {
        for (int j = right; j >= left; j--) a[bottom][j] = v++; // 下边，从右到左
        bottom--;
    }
    if (left <= right) {
        for (int i = bottom; i >= top; i--) a[i][left] = v++;   // 左边，从下到上
        left++;
    }
}
```
`N = 3` 时得到：
```
1 2 3
8 9 4
7 6 5
```

## 11. 常见错误

| 错误 | 说明 | 对策 |
|---|---|---|
| 下标从 1 开始 | 数组 `a[n]` 的合法下标是 `0 ~ n-1` | 循环用 `i < n` |
| 越界读写 | UB，可能崩溃/篡改数据 | ASan、边界检查 |
| 未初始化局部数组 | 垃圾值 | `= {0}` |
| 在函数中用 `sizeof` 求形参数组长度 | 得到指针大小 | 另传长度 |
| 数组整体赋值/比较 | 编译错误/比较了地址 | 循环、`memcpy`、`memcmp` |
| `int a[n] = {0}`（VLA 初始化） | 编译错误 | `memset` |
| 二维数组传参省略列数 | 编译错误 | `int m[][COLS]` 或 VLA 语法 |
| 返回局部数组 | 悬空指针 | 传入输出数组或 `malloc` |
| 字符数组没留 `'\0'` 位置 | 字符串越界 | 容量 ≥ 长度 + 1 |
| 局部超大数组 | 栈溢出 | `static` 或 `malloc` |
| 把 `a[i][j]` 与 `a[i, j]` 混淆 | 后者是逗号表达式，只用 `j` | 写成 `a[i][j]` |
| 冒泡内层循环上界写错 | 越界或漏排 | `n - 1 - i` |
| 二分用 `(lo+hi)/2` | 极大时溢出 | `lo + (hi-lo)/2` |

## 12. 本章小结与练习

### 12.1 知识要点回顾

- 数组：同类型元素**连续存放**，下标从 **0** 开始，**不检查越界**；
- 初始化：部分初始化其余为 0；局部数组默认是垃圾值，全局/静态数组默认全 0；C99 支持指定初始化器；
- 数组**不能整体赋值/比较**，需 `memcpy`/`memcmp`；
- 二维数组是"数组的数组"，**行优先**连续存放，按行遍历更高效；
- VLA：C99 特性、栈上、不能初始化，大数据应使用 `malloc`；
- 数组传参**退化为指针**：丢失长度，必须另传；二维数组需指明列数；
- 算法：冒泡/选择/插入排序、二分查找（O(log n)）、埃氏筛、双指针、前缀和。

### 12.2 练习题

**基础**
1. 输入 10 个整数，输出最大值、最小值、平均值，以及最大值的下标。
2. 把数组逆序输出（不开辟新数组）。
3. 输入 n 个成绩，统计各分数段（90+、80-89、70-79、60-69、<60）的人数（用计数数组）。
4. 编写函数，判断数组是否升序。
5. 编写函数，删除数组中所有值为 x 的元素（原地、保持顺序），返回新长度。

**理解**
6. 下列程序输出什么？
   ```c
   int a[5] = {1, 2, 3};
   int b[] = {1, 2, 3};
   int c[2][3] = {{1}, {2, 3}};
   printf("%d %d %d\n", a[4], (int)(sizeof b / sizeof b[0]), c[1][2]);
   ```
7. 指出错误：
   ```c
   int n = 5;
   int a[n] = {0};
   int b[3] = {1, 2, 3}, c[3];
   c = b;
   void f(int a[]) { int len = sizeof(a) / sizeof(a[0]); }
   ```
8. 说明为什么二维数组作为参数时，`int m[][]` 是非法的，而 `int m[][4]` 是合法的。

**进阶**
9. 实现矩阵乘法，维度由输入决定（使用 VLA 参数语法）。
10. 实现 `lower_bound` 与 `upper_bound`，并求有序数组中某元素的出现次数。
11. 编写程序输出 n×n 的**蛇形矩阵**与**螺旋矩阵**。
12. 找出数组中出现次数超过一半的元素（摩尔投票法：维护候选者和计数器）。
13. 把数组分成"奇数在前、偶数在后"，要求原地 O(n)（双指针）。
14. 用计数排序对 0~100 的成绩排序，时间 O(n + k)。
15. 实现数组的"向左循环移动 k 位"，要求 O(n) 时间、O(1) 额外空间。
16. 编写小程序比较冒泡、选择、插入排序在 `n = 10000` 随机数据上的耗时（用 `clock()`）。

### 12.3 参考答案（部分）

**第 6 题**：`0 3 0`。`a[4]` 未显式初始化，为 0；`b` 长度由初值个数决定为 3；`c[1] = {2, 3, 0}`，所以 `c[1][2]` 为 0。

**第 7 题**：
- `int a[n] = {0};`：VLA 不能初始化；
- `c = b;`：数组不能整体赋值；
- 形参 `a[]` 实质是指针，`sizeof(a)/sizeof(a[0])` 得到的是 `指针大小 / 元素大小`，并非元素个数。

**第 8 题**：`m[i][j]` 的地址 = `m + i * 每行字节数 + j * 元素大小`。每行字节数由列数决定，列数缺失则无法计算偏移；而第一维（行数）不参与偏移计算，所以可省。

**第 13 题（参考）**
```c
void odd_first(int a[], int n)
{
    int l = 0, r = n - 1;
    while (l < r) {
        while (l < r && a[l] % 2 != 0) l++;        // 找左边的偶数
        while (l < r && a[r] % 2 == 0) r--;        // 找右边的奇数
        if (l < r) { int t = a[l]; a[l] = a[r]; a[r] = t; }
    }
}
```

**第 12 题（参考）**
```c
int majority(const int a[], int n)
{
    int cand = 0, cnt = 0;
    for (int i = 0; i < n; i++) {
        if (cnt == 0) { cand = a[i]; cnt = 1; }
        else if (a[i] == cand) cnt++;
        else cnt--;
    }
    return cand;        // 题目保证存在多数元素；否则需再扫描验证
}
```

**第 14 题（参考）**
```c
void counting_sort(int a[], int n)          // 假设 0 <= a[i] <= 100
{
    int cnt[101] = {0};
    for (int i = 0; i < n; i++) cnt[a[i]]++;
    int k = 0;
    for (int v = 0; v <= 100; v++)
        while (cnt[v]--) a[k++] = v;
}
```
