## 1. 标准流与 I/O 概览

C 把所有输入输出抽象成**流（stream）**——一串按顺序读写的字节。程序启动时自动打开三个标准流：

| 流 | 名称 | 默认设备 | 文件描述符（Linux） |
|---|---|---|---|
| `stdin` | 标准输入 | 键盘 | 0 |
| `stdout` | 标准输出 | 屏幕 | 1 |
| `stderr` | 标准错误 | 屏幕 | 2 |

```
 键盘 ──▶ stdin  ──▶  [程序]  ──▶ stdout ──▶ 屏幕
                        └─────▶ stderr ──▶ 屏幕（错误信息）
```

所有 I/O 函数都在 `<stdio.h>` 中，分为几组：

| 类别 | 输出 | 输入 |
|---|---|---|
| 格式化 | `printf` / `fprintf` / `sprintf` / `snprintf` | `scanf` / `fscanf` / `sscanf` |
| 字符 | `putchar` / `putc` / `fputc` | `getchar` / `getc` / `fgetc` |
| 行/字符串 | `puts` / `fputs` | `fgets`（`gets` 已被移除） |

`printf(...)` 等价于 `fprintf(stdout, ...)`；`scanf(...)` 等价于 `fscanf(stdin, ...)`。
文件操作（第 13 章）使用的是同一套函数，只是把 `stdout/stdin` 换成 `FILE *`。

**为什么有 `stderr`？** 正常结果与错误信息分开，便于重定向：
```bash
./prog > out.txt          # 正常输出进文件，错误信息仍显示在屏幕
./prog 2> err.txt         # 只把错误信息写入文件
```

## 2. 格式化输出 printf

### 2.1 基本语法

```c
int printf(const char *format, ...);
```
- 返回值：**成功输出的字符数**，出错返回负数；
- `format` 中的普通字符原样输出，`%` 开头的是**转换说明**，依次被后面的参数替换。

**转换说明的完整形式**：

```
%[标志][宽度][.精度][长度修饰符]转换字符
```

```c
printf("%-8.3lf|", 3.14159);
//      ││ │ │ └ 转换字符 f
//      ││ │ └ 长度修饰符 l
//      ││ └ 精度 .3
//      │└ 宽度 8
//      └ 标志 -
```

### 2.2 转换字符

| 转换 | 参数类型 | 说明 | 示例 → 输出 |
|---|---|---|---|
| `%d` `%i` | `int` | 有符号十进制 | `printf("%d", -42)` → `-42` |
| `%u` | `unsigned` | 无符号十进制 | `printf("%u", 42u)` → `42` |
| `%o` | `unsigned` | 八进制 | `printf("%o", 8)` → `10` |
| `%x` `%X` | `unsigned` | 十六进制（小/大写） | `printf("%x", 255)` → `ff` |
| `%f` | `double` | 小数形式 | `printf("%f", 3.14)` → `3.140000` |
| `%e` `%E` | `double` | 科学计数法 | `printf("%e", 12345.678)` → `1.234568e+04` |
| `%g` `%G` | `double` | 自动选 `%f`/`%e`，去掉多余的 0 | `printf("%g", 0.5)` → `0.5` |
| `%a` | `double` | 十六进制浮点 | |
| `%c` | `int` | 单个字符 | `printf("%c", 65)` → `A` |
| `%s` | `char *` | 字符串（遇 `\0` 结束） | `printf("%s", "hi")` → `hi` |
| `%p` | `void *` | 指针地址 | `printf("%p", (void *)&x)` |
| `%%` | — | 输出字符 `%` | `printf("100%%")` → `100%` |
| `%n` | `int *` | 写入已输出字符数（**危险**，不要用） | |

### 2.3 长度修饰符

| 修饰符 | 搭配 | 对应类型 |
|---|---|---|
| `hh` | `d u x` | `char` |
| `h` | `d u x` | `short` |
| （无） | `d u x` | `int` |
| `l` | `d u x` | `long` |
| `ll` | `d u x` | `long long` |
| `z` | `u x d` | `size_t` / `ssize_t` |
| `t` | `d` | `ptrdiff_t` |
| `j` | `d u` | `intmax_t` / `uintmax_t` |
| `L` | `f e g` | `long double` |

```c
printf("%ld\n",  1234567890123L);
printf("%lld\n", 9000000000000000000LL);
printf("%zu\n",  sizeof(int));          // size_t 必须用 %zu
printf("%hhd\n", (char)65);             // 65
```

> `printf` 中 `float` 会被自动提升为 `double`，所以 `%f` 既用于 `float` 也用于 `double`（`%lf` 在 C99 起与 `%f` 等价）。
> 但 **`scanf` 中 `float` 用 `%f`，`double` 必须用 `%lf`**。

### 2.4 标志

| 标志 | 作用 | 示例 → 输出 |
|---|---|---|
| `-` | 左对齐（默认右对齐） | `"%-5d\|"`, 42 → `42   \|` |
| `+` | 正数也显示 `+` | `"%+d"`, 5 → `+5` |
| 空格 | 正数前加空格 | `"% d"`, 5 → ` 5` |
| `0` | 用 0 填充（数字） | `"%05d"`, 42 → `00042` |
| `#` | 备用格式：八进制加 `0`，十六进制加 `0x`，浮点总带小数点 | `"%#x"`, 255 → `0xff`；`"%#o"`, 8 → `010` |

### 2.5 宽度与精度

**宽度**：最小输出宽度，不够则补空格（或 0），**过长不会截断**。
**精度** `.n`：
- 整数：至少输出 n 位数字（不足补 0）；
- 浮点 `%f %e`：小数点后 n 位（**四舍五入**）；`%g`：n 位有效数字；
- 字符串 `%s`：**最多**输出 n 个字符。

可以用 `*` 从参数中读取宽度/精度：

```c
#include <stdio.h>

int main(void)
{
    printf("[%5d]\n",    42);           // [   42]
    printf("[%-5d]\n",   42);           // [42   ]
    printf("[%05d]\n",   42);           // [00042]
    printf("[%+d]\n",    42);           // [+42]
    printf("[%8.3f]\n",  3.14159);      // [   3.142]
    printf("[%-8.2f]\n", 3.14159);      // [3.14    ]
    printf("[%.0f]\n",   2.5);          // [2]  （2.5 恰为一半，glibc 按"舍入到偶数"得 2；不同实现可能不同）
    printf("[%10s]\n",   "hi");         // [        hi]
    printf("[%-10s]\n",  "hi");         // [hi        ]
    printf("[%.3s]\n",   "abcdef");     // [abc]
    printf("[%*d]\n",    6, 42);        // [    42]
    printf("[%-*.*f]\n", 9, 2, 3.14159);// [3.14     ]
    printf("[%x] [%X] [%#x]\n", 255, 255, 255);   // [ff] [FF] [0xff]
    printf("[%e]\n",     12345.678);    // [1.234568e+04]
    printf("[%g] [%g]\n", 0.0001234, 1234567.0);  // [0.0001234] [1.23457e+06]
    printf("[%c%c%c]\n", 'C', 'a', 't');
    printf("100%%\n");
    return 0;
}
```

### 2.6 示例：对齐的表格

```c
#include <stdio.h>

int main(void)
{
    struct { const char *name; int qty; double price; } items[] = {
        {"Apple",  3,  2.5},
        {"Banana", 12, 0.75},
        {"Cherry", 100, 12.0},
    };

    printf("%-10s %5s %8s\n", "Name", "Qty", "Price");
    printf("%-10s %5s %8s\n", "----", "---", "-----");
    for (int i = 0; i < 3; i++)
        printf("%-10s %5d %8.2f\n", items[i].name, items[i].qty, items[i].price);
    return 0;
}
```
输出：
```
Name         Qty    Price
----         ---    -----
Apple          3     2.50
Banana        12     0.75
Cherry       100    12.00
```

> 中文字符在终端占 2 列宽，但 `printf` 的宽度按**字节**计，所以中英混排时 `%-10s` 无法对齐，需要自行处理。

### 2.7 常见的 printf 错误

**① 格式符与参数类型不匹配 → 未定义行为**

```c
printf("%d\n", 3.14);        // ✘ 输出垃圾值
printf("%f\n", 3);           // ✘
printf("%d\n", 10L);         // 在 long 为 8 字节的平台上不安全
printf("%d\n", sizeof(int)); // ✘ sizeof 是 size_t，应使用 %zu
printf("%s\n", 65);          // ✘ 当作地址，崩溃
```

**② 参数个数不足**

```c
printf("%d %d\n", 1);        // ✘ UB：读取不存在的参数
```

**③ 参数个数多于格式符**：多余的被忽略（合法，但通常是 bug）。

**④ `%s` 传入 `NULL`** → UB（有的实现输出 `(null)`，不要依赖）。

**⑤ 格式化字符串漏洞（安全问题）**

```c
char *input = get_user_input();
printf(input);            // ✘ 若 input 含 "%s%s%n"，可导致崩溃或任意内存写
printf("%s", input);      // ✔ 永远把不可信数据作为参数，而不是格式串
puts(input);              // ✔
```

**⑥ 用 `%p` 打印指针时转成 `void *`**

```c
int x;
printf("%p\n", (void *)&x);
```

### 2.8 返回值与 `puts` / `putchar`

```c
int n = printf("Hello\n");     // n = 6
```
```c
puts("Hello");        // 输出 Hello 并自动追加 '\n'
putchar('A');         // 输出一个字符
putchar('\n');
fputs("Hello", stdout);        // 输出字符串，不追加 '\n'
fprintf(stderr, "error: %s\n", "file not found");   // 错误信息写到 stderr
```

| | 追加换行 | 说明 |
|---|---|---|
| `puts(s)` | ✔ | 简单快速 |
| `fputs(s, stdout)` | ✘ | 可指定输出流 |
| `printf("%s", s)` | ✘ | 可格式化 |

### 2.9 输出整数的二进制、常用技巧

```c
// 输出带前导零的时间
printf("%02d:%02d:%02d\n", 9, 5, 3);        // 09:05:03

// 输出 64 位无符号数（可移植写法）
#include <inttypes.h>
uint64_t v = 123;
printf("%" PRIu64 "\n", v);

// 进度条刷新（\r 回到行首；\r 后不换行，需要 fflush）
for (int i = 0; i <= 100; i += 10) {
    printf("\r进度：%3d%%", i);
    fflush(stdout);
}
putchar('\n');
```

## 3. 格式化输入 scanf

### 3.1 基本语法

```c
int scanf(const char *format, ...);
```
- 按 `format` 解析 `stdin`，把结果存入**后面参数所指向的内存**，所以参数必须是**地址**；
- **返回值**：成功赋值的项数；若在第一个转换前就遇到输入结束/错误，返回 `EOF`。

```c
#include <stdio.h>

int main(void)
{
    int age;
    double height;
    char initial;

    printf("输入年龄、身高、姓名首字母：");
    int n = scanf("%d %lf %c", &age, &height, &initial);
    if (n != 3) {
        fprintf(stderr, "输入格式错误\n");
        return 1;
    }
    printf("%d, %.1f, %c\n", age, height, initial);
    return 0;
}
```
输入 `20 1.75 K`（用空格、Tab 或回车分隔均可）。

### 3.2 常用转换

| 转换 | 目标类型 | 说明 |
|---|---|---|
| `%d` | `int *` | 十进制整数（跳过前导空白） |
| `%i` | `int *` | 自动识别进制（`0x`、`0` 前缀） |
| `%u` `%x` `%o` | `unsigned *` | |
| `%ld` `%lld` `%hd` | `long *` `long long *` `short *` | |
| `%zu` | `size_t *` | |
| `%f` | `float *` | |
| **`%lf`** | **`double *`** | **double 必须用 `%lf`** |
| `%Lf` | `long double *` | |
| `%c` | `char *` | **不跳过空白**，读一个字符 |
| `%s` | `char *`（字符数组） | 跳过前导空白，读到下一个空白为止，自动加 `\0` |
| `%[...]` | `char *` | 扫描集 |
| `%*d` | 无 | `*` 表示读取但丢弃 |
| `%n` | `int *` | 到目前为止读取的字符数（不计入返回值） |
| `%%` | | 匹配字面量 `%` |

### 3.3 scanf 的工作规则（重点）

1. **空白字符**（空格、Tab、换行）在格式串中匹配**任意数量**的空白（包括 0 个）；
2. 除 `%c`、`%[`、`%n` 外，**转换会自动跳过前导空白**；
3. **普通字符**必须与输入**精确匹配**，不匹配则停止；
4. 遇到不符合类型的输入（如读 `%d` 时遇到字母）→ **匹配失败**，该字符**留在缓冲区**；
5. **回车（换行符）也会留在缓冲区**，影响后续读取。

### 3.4 示例

```c
int y, m, d;
scanf("%d-%d-%d", &y, &m, &d);    // 输入 2026-11-26 → y=2026 m=11 d=26
scanf("%d,%d", &a, &b);           // 输入 3,4（必须带逗号）
scanf("%d%d", &a, &b);            // 输入 3 4 或 3\n4
scanf(" %c", &ch);                // 前面的空格：跳过所有前导空白（含上次留下的换行）
scanf("%*d %d", &x);              // 输入 10 20：丢弃 10，x=20
scanf("%9s", name);               // 限制最多读 9 个字符（数组至少 10 字节）
scanf("%[^\n]", line);            // 读取一行（含空格），直到换行，不含换行
scanf("%[0-9]", digits);          // 只读数字字符
scanf("%2d%2d", &h, &mi);         // 输入 1230 → h=12 mi=30（宽度限制）
```

### 3.5 scanf 的经典陷阱

**陷阱 ①：忘记取地址符 `&`**

```c
int n;
scanf("%d", n);        // ✘ 把 n 的值当地址写入，崩溃
scanf("%d", &n);       // ✔
```
`-Wall` 会警告 `format '%d' expects argument of type 'int *'`。

**陷阱 ②：字符数组不需要 `&`，但要防溢出**

```c
char name[10];
scanf("%s", name);        // ✔ 数组名即地址；✘ 但输入超过 9 个字符会溢出！
scanf("%9s", name);       // ✔ 限制宽度 = 数组大小 - 1
```

**陷阱 ③：`%c` 读到上一次留下的换行**

```c
int n; char c;
scanf("%d", &n);        // 输入 5 回车 → 缓冲区剩下 '\n'
scanf("%c", &c);        // ✘ 读到的是 '\n'，不是用户的下一次输入
scanf(" %c", &c);       // ✔ 格式串开头加空格，跳过空白
```

**陷阱 ④：输入类型不符导致死循环**

```c
int n;
while (scanf("%d", &n) != 1) {     // 输入 abc：scanf 失败，'a' 仍在缓冲区
    printf("请重输：");             // 下一次依然读到 'a' → 无限循环！
}
```
修复：失败后**清除缓冲区**：
```c
int n;
while (scanf("%d", &n) != 1) {
    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) { }   // 丢弃这一行
    if (ch == EOF) return 1;
    printf("请重输：");
}
```

**陷阱 ⑤：`%s` 不能读含空格的字符串**
输入 `Hello World`，`scanf("%s", s)` 只得到 `Hello`。读整行用 `fgets`（见第 4、6 节）。

**陷阱 ⑥：double 用 `%f` 读入**

```c
double d;
scanf("%f", &d);        // ✘ 写入 4 字节，d 的值错乱
scanf("%lf", &d);       // ✔
```

**陷阱 ⑦：不检查返回值**

```c
int a, b;
scanf("%d %d", &a, &b);        // 若输入非法，a、b 仍是未初始化的垃圾值
if (scanf("%d %d", &a, &b) != 2) { /* 处理错误 */ }
```

**陷阱 ⑧：宽字符、整数溢出**：`scanf("%d")` 读入超出范围的数，行为未定义。

> **结论**：`scanf` 适合快速写练习题（如算法竞赛），但**不适合处理不可信或复杂的输入**。生产代码请用 `fgets` + `strtol/strtod/sscanf`（第 6 节）。

## 4. 字符与字符串 I/O

### 4.1 getchar / putchar

```c
int getchar(void);        // 从 stdin 读一个字符，返回 int
int putchar(int c);       // 向 stdout 写一个字符
```

**返回类型是 `int` 而不是 `char`**——因为需要区分合法字符（0~255）与 `EOF`（通常 −1）：

```c
char c;
while ((c = getchar()) != EOF) { }     // ✘ 若 char 无符号则永远不等于 EOF；
                                        //    若有符号，字符 0xFF 会被误判为 EOF
int ch;
while ((ch = getchar()) != EOF) { }    // ✔
```

**例：把输入原样复制到输出（直到 EOF）**
```c
#include <stdio.h>

int main(void)
{
    int ch;
    while ((ch = getchar()) != EOF)
        putchar(ch);
    return 0;
}
```
- Linux/macOS 终端中按 `Ctrl+D` 表示 EOF；Windows 命令行中为 `Ctrl+Z` 后回车。

**例：统计字符、单词、行数（简化的 wc）**
```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    int ch, chars = 0, words = 0, lines = 0, in_word = 0;

    while ((ch = getchar()) != EOF) {
        chars++;
        if (ch == '\n') lines++;
        if (isspace(ch))      in_word = 0;
        else if (!in_word)  { in_word = 1; words++; }
    }
    printf("%d %d %d\n", lines, words, chars);
    return 0;
}
```

### 4.2 puts / fputs

```c
puts("hello");           // 输出 hello\n
fputs("hello", stdout);  // 输出 hello（不换行）
```

### 4.3 gets —— 已被移除，绝对不要使用

```c
char buf[10];
gets(buf);               // ✘ 无法限制长度，必然存在缓冲区溢出；C11 已从标准中删除
```
编译器会警告：`the 'gets' function is dangerous and should not be used.`

### 4.4 fgets —— 安全地读一行

```c
char *fgets(char *s, int size, FILE *stream);
```
- 最多读 `size - 1` 个字符，**遇到换行就停止，并把换行符保留在缓冲区中**；末尾自动加 `\0`；
- 成功返回 `s`；遇到 EOF 且未读到任何字符，或出错，返回 `NULL`。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[64];

    printf("输入一行：");
    if (fgets(line, sizeof line, stdin) == NULL) {
        puts("输入结束或出错");
        return 1;
    }

    // 去掉末尾换行
    line[strcspn(line, "\n")] = '\0';

    printf("你输入的是：[%s]，长度 %zu\n", line, strlen(line));
    return 0;
}
```

**注意**：如果输入的行长度 ≥ `size - 1`，`fgets` 只读走前一部分，**剩余字符仍在缓冲区**，换行符也没读到。可检测并丢弃：

```c
size_t len = strlen(line);
if (len > 0 && line[len - 1] == '\n') {
    line[len - 1] = '\0';               // 完整读入一行
} else {
    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) { }   // 行过长，丢弃剩余
}
```

`strcspn(line, "\n")` 返回 `line` 中第一个 `\n` 的下标（没有则返回长度），一行代码即可安全去掉换行。

### 4.5 三种读取字符串方式对比

| | `scanf("%s")` | `gets` | `fgets` |
|---|---|---|---|
| 读含空格的行 | ✘ | ✔ | ✔ |
| 能限制长度 | 需写 `%9s` | ✘ | ✔ |
| 保留换行 | — | 丢弃 | **保留** |
| 安全性 | 需小心 | **危险，已移除** | 安全 |

## 5. 输入缓冲区与缓冲机制

### 5.1 为什么需要缓冲

读写设备（磁盘、终端）很慢，逐字符与设备交互效率低。C 标准库在内存中为每个流维护一个**缓冲区**，攒够了/满足条件时再一次性传输。

### 5.2 三种缓冲模式

| 模式 | 触发写出的时机 | 默认用于 |
|---|---|---|
| **全缓冲** | 缓冲区满、`fflush`、关闭流 | 输出到**文件/管道**的 `stdout` |
| **行缓冲** | 遇到 `\n`、缓冲区满、`fflush`；**读取 stdin 时也会触发刷新 stdout**（多数实现） | 连接**终端**的 `stdin/stdout` |
| **无缓冲** | 立即写出 | `stderr` |

```c
#include <stdio.h>
#include <unistd.h>      // sleep（POSIX）

int main(void)
{
    printf("loading");   // 没有 \n：在终端下不会立即出现（行缓冲）
    sleep(3);            // 3 秒后才一起显示
    printf("...done\n");
    return 0;
}
```
解决：`fflush(stdout);` 或使用 `stderr` 或输出 `\n`。

**经典现象：程序崩溃时，最后一行输出丢失**

```c
printf("step 1");        // 没有 \n，仍在缓冲区
int *p = NULL;
*p = 1;                  // 崩溃 → 缓冲区没被刷新 → "step 1" 不显示
```
所以**调试输出请带 `\n`，或写到 `stderr`**。

**控制缓冲**
```c
setvbuf(stdout, NULL, _IONBF, 0);     // 关闭 stdout 缓冲
setvbuf(stdout, NULL, _IOLBF, 0);     // 行缓冲
fflush(stdout);                        // 手动刷新输出缓冲
```

### 5.3 输入缓冲区的运作

用户在终端输入时，**按下回车后**整行内容（含 `\n`）才被送入 `stdin` 缓冲区。`scanf/getchar/fgets` 都从这个缓冲区取数据。

```
用户键入 "12 abc\n"
缓冲区： [1][2][ ][a][b][c][\n]
scanf("%d", &n);     取走 "12"，剩下 [ ][a][b][c][\n]
```

### 5.4 清空输入缓冲区

```c
// 标准、可移植的做法：读掉直到换行（或 EOF）
static void clear_stdin(void)
{
    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) { }
}
```

> **不要使用 `fflush(stdin)`**：C 标准规定对输入流 `fflush` 是未定义行为。只有 MSVC 等少数实现把它定义成"清空输入缓冲"，不可移植。

> **注意**：若缓冲区里已经没有未读的换行（例如刚用 `fgets` 读完整行），再调用 `clear_stdin()` 会**阻塞等待下一行输入**。只在确定有残留时调用。

### 5.5 混用输入函数的陷阱

```c
int n;
char name[32];

scanf("%d", &n);                 // 输入 5⏎ → 留下 '\n'
fgets(name, sizeof name, stdin); // ✘ 立刻读到 "\n"，得到空字符串
```
方案：
1. **统一使用 `fgets`**，再用 `sscanf/strtol` 解析（推荐）；
2. 或在 `scanf` 之后手动清除缓冲区；
3. 或使用 `scanf(" %c")`、`scanf("%d%*c")` 之类的技巧（不够稳健）。

## 6. 健壮的输入：fgets + 解析

### 6.1 推荐模式

> **"先读一整行，再解析"** —— 读取与解析分离，任何一步失败都不会留下脏数据。

### 6.2 读取整数（带完整校验）

```c
#include <ctype.h>
#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>

/* 成功返回 0，输入结束返回 -1 */
int read_int(const char *prompt, int *out)
{
    char buf[64];

    for (;;) {
        printf("%s", prompt);
        if (fgets(buf, sizeof buf, stdin) == NULL)
            return -1;                          // EOF

        char *end;
        errno = 0;
        long v = strtol(buf, &end, 10);

        if (end == buf) {                       // 一个数字都没读到
            puts("请输入整数。");
            continue;
        }
        while (isspace((unsigned char)*end)) end++;   // 允许尾部空白
        if (*end != '\0') {                     // 后面还有非法字符
            puts("含有非法字符。");
            continue;
        }
        if (errno == ERANGE || v < INT_MIN || v > INT_MAX) {
            puts("数值超出范围。");
            continue;
        }
        *out = (int)v;
        return 0;
    }
}

int main(void)
{
    int age;
    if (read_int("年龄：", &age) == 0)
        printf("你的年龄是 %d\n", age);
    return 0;
}
```
> 此示例假设每行不超过 63 个字符。更严格的版本应检测并丢弃超长行（见 4.4 节）。

### 6.3 用 sscanf 解析一行

```c
char line[128];
int  id;
char name[32];
double score;

if (fgets(line, sizeof line, stdin) &&
    sscanf(line, "%d %31s %lf", &id, name, &score) == 3) {
    printf("%d %s %.1f\n", id, name, score);
} else {
    puts("格式错误");
}
```

### 6.4 strtol / strtod 简介（详见第 9 章）

```c
long   strtol(const char *s, char **endp, int base);
double strtod(const char *s, char **endp);
```
相比 `atoi`/`atof`，它们能**报告错误**（`endp`、`errno`），推荐使用。

### 6.5 一个完整的小程序：成绩统计

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("学生人数：");
    if (scanf("%d", &n) != 1 || n <= 0) {
        fprintf(stderr, "人数无效\n");
        return 1;
    }

    double sum = 0, max = 0, min = 100;
    for (int i = 1; i <= n; i++) {
        double s;
        printf("第 %d 个成绩：", i);
        if (scanf("%lf", &s) != 1) {
            fprintf(stderr, "成绩无效\n");
            return 1;
        }
        sum += s;
        if (s > max) max = s;
        if (s < min) min = s;
    }
    printf("平均 %.2f，最高 %.1f，最低 %.1f\n", sum / n, max, min);
    return 0;
}
```

## 7. 内存中的格式化：sprintf / snprintf / sscanf

与 `printf/scanf` 类似，但对象是**内存中的字符串**，而不是流。

### 7.1 sprintf / snprintf —— 格式化到字符串

```c
int sprintf (char *buf, const char *fmt, ...);
int snprintf(char *buf, size_t size, const char *fmt, ...);
```

```c
char buf[32];
sprintf(buf, "%d-%02d-%02d", 2026, 11, 26);        // ✘ 不检查长度，可能溢出
snprintf(buf, sizeof buf, "%d-%02d-%02d", 2026, 11, 26);   // ✔ 最多写 size-1 个字符并补 '\0'
```

- `snprintf` 返回**本应写入的字符数**（不含 `\0`），若返回值 ≥ `size` 则说明被截断；
- **永远用 `snprintf` 代替 `sprintf`。**

```c
int n = snprintf(buf, sizeof buf, "%s", very_long_string);
if (n < 0 || (size_t)n >= sizeof buf)
    fprintf(stderr, "输出被截断\n");

int need = snprintf(NULL, 0, "%d", 12345);     // 先试算长度：5
```

### 7.2 sscanf —— 从字符串解析

```c
const char *s = "ID=42, score=95.5";
int id; double score;
if (sscanf(s, "ID=%d, score=%lf", &id, &score) == 2)
    printf("%d %.1f\n", id, score);
```

整数转字符串、字符串转整数的简单方式：
```c
char buf[16];
snprintf(buf, sizeof buf, "%d", 12345);        // 整数 → 字符串

int n;
sscanf("12345", "%d", &n);                     // 字符串 → 整数（推荐用 strtol）
```

## 8. 重定向与 EOF

### 8.1 命令行重定向（Shell 功能，程序无需改动）

```bash
./prog < input.txt          # 从文件读 stdin
./prog > output.txt         # stdout 写入文件（覆盖）
./prog >> output.txt        # 追加
./prog 2> err.txt           # stderr 写入文件
./prog > all.txt 2>&1       # stdout 和 stderr 都写入 all.txt
./prog1 | ./prog2           # 管道：prog1 的输出作为 prog2 的输入
```

### 8.2 EOF 的判断

| 函数 | EOF 时的表现 |
|---|---|
| `getchar()` | 返回 `EOF` |
| `scanf()` | 返回 `EOF`（若第一个转换前遇到结束） |
| `fgets()` | 返回 `NULL` |

**读取任意多行直到 EOF（读取数据文件/管道的标准写法）**
```c
char line[256];
while (fgets(line, sizeof line, stdin) != NULL) {
    /* 处理一行 */
}
```
```c
int x, sum = 0;
while (scanf("%d", &x) == 1)       // 遇到 EOF 或非数字时结束
    sum += x;
printf("%d\n", sum);
```

> 不要写 `while (!feof(stdin))` 循环：`feof` 只在**读取失败后**才为真，会导致最后一次多处理一遍。正确做法是**检查读函数的返回值**。

### 8.3 文本换行符差异

- Unix/Linux/macOS：`\n`
- Windows：`\r\n`（在文本模式下，C 库会自动转换，程序里仍写 `\n`）

## 9. 常见错误清单

| 错误 | 现象 | 修正 |
|---|---|---|
| `scanf("%d", n)` 忘 `&` | 崩溃/警告 | 加 `&` |
| `scanf("%f", &double_var)` | 结果错乱 | 用 `%lf` |
| `scanf("%s", buf)` 无宽度 | 缓冲区溢出 | `%Ns`（N = 大小−1）或 `fgets` |
| `gets(buf)` | 溢出，已被移除 | `fgets` |
| `printf("%d", 3.14)` / `printf("%f", 3)` | 乱码 | 格式符与类型匹配 |
| `printf("%d", sizeof x)` | 警告/可能错 | `%zu` |
| `printf(user_input)` | 格式化字符串漏洞 | `printf("%s", user_input)` |
| `scanf` 后接 `fgets`/`getchar`/`%c` | 读到残留换行 | 清缓冲区或统一用 `fgets` |
| `char c = getchar();` 与 EOF 比较 | 死循环/误判 | 用 `int` |
| `fflush(stdin)` | 未定义行为 | 手写清除循环 |
| `while(!feof(fp))` | 多读一次 | 检查读函数返回值 |
| `scanf` 失败后重试不清缓冲区 | 死循环 | 清除或改 `fgets` |
| 调试输出无 `\n` | 崩溃时看不到 | 加 `\n` 或写 `stderr` |
| 不检查 `scanf` 返回值 | 使用未初始化值 | 检查 `== 预期个数` |

## 10. 本章小结与练习

### 10.1 知识要点回顾

- 三个标准流：`stdin / stdout / stderr`；错误信息写 `stderr`。
- `printf`：`%[标志][宽度][.精度][长度]转换`；**类型必须匹配**；`size_t` 用 `%zu`；永远不要把用户输入当格式串。
- `scanf`：参数是**地址**；检查**返回值**；`double` 用 `%lf`；`%s` 要限制宽度；`%c` 前加空格；失败要清缓冲区。
- 字符/行 I/O：`getchar` 返回 `int`；`gets` 已移除；`fgets` 保留换行、需手动去除。
- 缓冲：全缓冲/行缓冲/无缓冲；`fflush(stdout)`；**不要** `fflush(stdin)`。
- 稳健输入：`fgets` 读整行 → `strtol / strtod / sscanf` 解析。
- `snprintf` 代替 `sprintf`。

### 10.2 练习题

**基础**
1. 输入圆的半径，输出周长与面积，保留 2 位小数（`π` 用 `3.14159265358979`）。
2. 输入一个字符，输出它的 ASCII 码（十进制、八进制、十六进制）。
3. 输入三个整数，用 `%5d` 形式右对齐输出，再用 `%-5d` 左对齐输出。
4. 输入 `hh:mm:ss` 形式的时间（如 `09:05:03`），输出总秒数。

**理解**
5. 下面程序输入 `12 abc` 后输出什么？为什么？
   ```c
   int a, b;
   int n = scanf("%d %d", &a, &b);
   printf("%d %d %d\n", n, a, b);
   ```
6. 下面程序有什么问题？如何修改？
   ```c
   int age; char name[20];
   printf("年龄：");  scanf("%d", &age);
   printf("姓名：");  gets(name);
   ```
7. 预测输出：
   ```c
   printf("[%6.2f][%-6d][%06d][%+d][%x][%#o][%.3s]\n", 3.14159, 42, 42, 7, 255, 8, "abcdef");
   ```
8. 为什么下面循环输入字母时会死循环？写出修复版本。
   ```c
   int n;
   while (scanf("%d", &n) != 1) printf("重输：");
   ```

**进阶**
9. 实现 `read_double(prompt, &x)`，仿照 6.2 节用 `fgets + strtod` 校验输入。
10. 实现简易计算器：读入一行 `3.5 * 4`，用 `sscanf(line, "%lf %c %lf", ...)` 解析并输出结果，处理除零与格式错误。
11. 实现小型 `wc`：从 `stdin` 读取直到 EOF，统计行数、单词数、字节数，并用 `./wc < file.txt` 测试。
12. 输出九九乘法表，要求每列严格对齐（用 `%-2d` 或 `%2d`）。
13. 读入若干整数直到 EOF，输出最大值、最小值与平均值；用管道 `echo "3 9 1 7" | ./prog` 测试。
14. 用 `snprintf` 实现 `format_size(bytes, buf, n)`，把字节数格式化为 `1.5 KB`、`3.2 MB` 之类的字符串。

### 10.3 参考答案（部分）

**第 5 题**：输出 `1 12 <随机值>`。`%d` 成功读入 12，第二个 `%d` 遇到 `a` 匹配失败，返回 1；`b` 未被赋值，是垃圾值（若事先未初始化）；`abc` 留在缓冲区。

**第 6 题**：`scanf("%d")` 之后换行符留在缓冲区，`gets` 立即读到空行；且 `gets` 本身不安全。修复：
```c
int age; char name[20];
printf("年龄：");
if (scanf("%d", &age) != 1) return 1;
int ch; while ((ch = getchar()) != '\n' && ch != EOF) { }     // 清残留
printf("姓名：");
if (fgets(name, sizeof name, stdin)) name[strcspn(name, "\n")] = '\0';
```

**第 7 题**：`[  3.14][42    ][000042][+7][ff][010][abc]`

**第 8 题**：输入非数字时 `scanf` 不消耗该字符，下一轮仍读到同一字符，失败 → 无限循环。修复：
```c
int n;
while (scanf("%d", &n) != 1) {
    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) { }
    if (ch == EOF) return 1;
    printf("重输：");
}
```

**第 10 题（参考）**：
```c
#include <stdio.h>

int main(void)
{
    char line[128];
    double a, b;
    char op;

    printf("表达式：");
    if (!fgets(line, sizeof line, stdin) ||
        sscanf(line, "%lf %c %lf", &a, &op, &b) != 3) {
        fprintf(stderr, "格式错误\n");
        return 1;
    }
    switch (op) {
    case '+': printf("%g\n", a + b); break;
    case '-': printf("%g\n", a - b); break;
    case '*': printf("%g\n", a * b); break;
    case '/':
        if (b == 0) { fprintf(stderr, "除数不能为 0\n"); return 1; }
        printf("%g\n", a / b);
        break;
    default:  fprintf(stderr, "未知运算符 %c\n", op); return 1;
    }
    return 0;
}
```
