## 1. 表达式基础

### 1.1 什么是表达式

**表达式** = 由运算符和操作数组成、能**计算出一个值**的式子。

```c
3 + 4          // 值为 7
a * b + c      // 值取决于变量
x = 5          // 赋值也是表达式，值为 5
f(2)           // 函数调用也是表达式
```

在表达式后加分号就成为**表达式语句**：

```c
a + b;        // 合法但无意义（编译器会警告 "statement with no effect"）
x = 5;        // 赋值语句：计算 x = 5 这个表达式，丢弃结果
printf("hi"); // 函数调用语句
```

### 1.2 副作用（Side Effect）

除了产生值，有些运算还会**修改状态**，称为副作用：

| 运算 | 值 | 副作用 |
|---|---|---|
| `a + b` | a+b 的和 | 无 |
| `a = 5` | 5 | 修改 a |
| `a++` | a 的旧值 | a 加 1 |
| `printf(...)` | 输出字符数 | 输出到屏幕 |

> 理解"值"与"副作用"的区别，是理解第 10 节"未定义行为"的关键。

### 1.3 左值与右值（简化理解）

- **左值（lvalue）**：有确定内存位置、**可以出现在赋值号左边**的表达式（变量、`*p`、`a[i]`）。
- **右值（rvalue）**：只是一个值（字面量、`a + b` 的结果）。

```c
int a = 1, b = 2;
a = b + 1;       // ✔ a 是左值
b + 1 = a;       // ✘ b+1 不是左值：error: lvalue required as left operand of assignment
5 = a;           // ✘
```

取地址 `&` 的操作数、自增 `++` 的操作数也必须是左值。

## 2. 算术运算符

| 运算符 | 含义 | 例 | 结果 |
|---|---|---|---|
| `+` | 加（也可作正号） | `5 + 2` | 7 |
| `-` | 减（也可作负号） | `5 - 2` | 3 |
| `*` | 乘 | `5 * 2` | 10 |
| `/` | 除 | `5 / 2` | **2**（整数除法） |
| `%` | 取余（模） | `5 % 2` | 1 |

### 2.1 整数除法与浮点除法

两个操作数**都是整数** → 整数除法，**向零截断**（C99 起明确规定）；只要有一个是浮点 → 浮点除法。

```c
#include <stdio.h>

int main(void)
{
    printf("%d\n", 7 / 2);        // 3
    printf("%d\n", -7 / 2);       // -3（向零截断，不是 -4）
    printf("%f\n", 7 / 2.0);      // 3.500000
    printf("%f\n", 7.0 / 2);      // 3.500000
    printf("%f\n", (double)7 / 2);// 3.500000
    printf("%f\n", (double)(7 / 2)); // 3.000000（先整除再转换）
    return 0;
}
```

### 2.2 取余运算符 %

- **只能用于整数**；浮点取余用 `fmod()`（`<math.h>`）。
- C99 规定：**结果符号与被除数相同**，并满足 `a == (a / b) * b + a % b`。

```c
printf("%d\n",  7 %  3);   //  1
printf("%d\n", -7 %  3);   // -1
printf("%d\n",  7 % -3);   //  1
printf("%d\n", -7 % -3);   // -1
// 5.5 % 2           ✘ 编译错误
// fmod(5.5, 2) = 1.5
```

**常见用途**

```c
n % 2 == 0          // 判断偶数
n % 10              // 取个位
n / 10              // 去掉个位
n % 100 / 10        // 取十位
x % 60              // 秒数回绕
(i + 1) % N         // 循环下标
```

> 注意：`n % 2 == 1` 对负奇数不成立（`-3 % 2 == -1`），判断奇数用 `n % 2 != 0`。

### 2.3 除零与溢出

```c
int a = 10, b = 0;
int c = a / b;        // 未定义行为（通常触发 SIGFPE 崩溃）
int d = a % b;        // 同样未定义
double e = 10.0 / 0;  // +inf（浮点除零不崩溃）
int m = INT_MIN / -1; // 未定义（结果 2147483648 超出 int 范围）
```

**写除法前，先判断除数是否为 0。**

### 2.4 一元 + 与 -

```c
int a = 5;
int b = -a;      // -5
int c = +a;      // 5（几乎无作用）
int d = -(-a);   // 5
// 注意： --a 是自减，不是两个负号！写成 - -a 或 -(-a)
```

### 2.5 类型提升回顾

```c
int    i = 3;
double d = 2.5;
i * d;                 // i 转为 double → 7.5
char c = 'a';
c + 1;                 // c 提升为 int → 98
```

### 2.6 例：数字拆分

```c
#include <stdio.h>

int main(void)
{
    int n = 4821;
    printf("个位：%d\n", n % 10);          // 1
    printf("十位：%d\n", n / 10 % 10);     // 2
    printf("百位：%d\n", n / 100 % 10);    // 8
    printf("千位：%d\n", n / 1000);        // 4

    int sec = 3725;
    printf("%d 小时 %d 分 %d 秒\n", sec / 3600, sec % 3600 / 60, sec % 60);
    // 1 小时 2 分 5 秒
    return 0;
}
```

## 3. 关系运算符

| 运算符 | 含义 |
|---|---|
| `>` `>=` `<` `<=` | 大于、大于等于、小于、小于等于 |
| `==` `!=` | 等于、不等于 |

结果是 **`int` 类型的 0（假）或 1（真）**。

```c
printf("%d\n", 3 > 2);        // 1
printf("%d\n", 3 == 4);       // 0
printf("%d\n", (3 > 2) + (5 > 1));   // 2
```

### 3.1 经典陷阱

**① `=` 与 `==` 混淆**

```c
int x = 0;
if (x = 5)  { /* 恒为真！x 被赋值为 5 */ }
if (x == 5) { /* 正确比较 */ }
```
`gcc -Wall` 会给出 `suggest parentheses around assignment used as truth value`。
防御写法（Yoda 写法）：`if (5 == x)`，漏写一个 `=` 时会编译报错。

**② 连续比较不是数学意义的区间判断**

```c
int x = 15;
if (0 < x < 10)          // ✘ 先算 (0 < x) = 1，再算 1 < 10 → 恒为真
if (0 < x && x < 10)     // ✔
```

**③ 浮点数不能直接用 `==`**

```c
double a = 0.1 + 0.2;
if (a == 0.3) { }                     // ✘ 不成立
if (fabs(a - 0.3) < 1e-9) { }         // ✔
```

**④ 有符号与无符号比较**（第 2 章已述）

```c
int a = -1; unsigned b = 1;
printf("%d\n", a < b);   // 0
```

**⑤ 字符串不能用 `==` 比较内容**（比较的是地址），应使用 `strcmp`（第 9 章）。

## 4. 逻辑运算符与短路求值

| 运算符 | 含义 | 规则 |
|---|---|---|
| `&&` | 逻辑与 | 两边都真才真 |
| `\|\|` | 逻辑或 | 有一边真就真 |
| `!` | 逻辑非 | 真变假，假变真 |

- **任何非 0 值都视为"真"**，0 视为"假"；
- 结果只会是 **1 或 0**。

```c
printf("%d\n", 5 && 3);     // 1（不是 3）
printf("%d\n", 0 || 7);     // 1
printf("%d\n", !5);         // 0
printf("%d\n", !0);         // 1
printf("%d\n", !!5);        // 1（"!!" 把任意非零值规范成 1）
```

**真值表**

| a | b | a && b | a \|\| b | !a |
|---|---|---|---|---|
| 真 | 真 | 真 | 真 | 假 |
| 真 | 假 | 假 | 真 | 假 |
| 假 | 真 | 假 | 真 | 真 |
| 假 | 假 | 假 | 假 | 真 |

### 4.1 短路求值（Short-circuit）

- `a && b`：**若 a 为假，b 不再计算**；
- `a || b`：**若 a 为真，b 不再计算**。
- `&&`、`||` 左右两侧之间有**序列点**，保证先算左边。

```c
#include <stdio.h>

int main(void)
{
    int i = 0, j = 0;

    if (i++ || j++) { }      // i++ 值为 0（假），继续算 j++
    printf("i=%d j=%d\n", i, j);   // i=1 j=1

    i = 0; j = 0;
    if (i || ++j) { }
    printf("i=%d j=%d\n", i, j);   // i=0 j=1

    i = 1; j = 0;
    if (i || j++) { }        // i 为真，j++ 不执行
    printf("i=%d j=%d\n", i, j);   // i=1 j=0

    i = 0; j = 0;
    if (i && j++) { }        // i 为假，j++ 不执行
    printf("i=%d j=%d\n", i, j);   // i=0 j=0
    return 0;
}
```

### 4.2 短路的实用价值

**① 防止空指针解引用 / 越界 / 除零**

```c
if (p != NULL && p->value > 0) { }      // p 为空时不会访问 p->value
if (i < n && arr[i] == key)  { }        // 先检查边界
if (b != 0 && a / b > 2)     { }        // 先检查除数
```

**② 条件执行（简写）**

```c
ok = check() && do_next();   // check 成功才调用 do_next
```

### 4.3 优先级提醒

`!` > 算术 > 关系 > `&&` > `||`。`&&` 比 `||` 高，混用时请加括号：

```c
if (a || b && c)        // 实际是 a || (b && c)
if ((a || b) && c)      // 若本意如此，必须加括号
```
`gcc -Wall` 会提示 `suggest parentheses around '&&' within '||'`。

### 4.4 例：闰年判断

```c
int is_leap(int y)
{
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}
// 2024 → 1；1900 → 0；2000 → 1
```

## 5. 位运算符

位运算直接对**二进制位**操作，操作数必须是整型。常用于：标志位、掩码、协议解析、硬件寄存器、加密、位图、性能优化。

| 运算符 | 名称 | 规则 |
|---|---|---|
| `&` | 按位与 | 对应位都为 1 才为 1 |
| `\|` | 按位或 | 对应位有一个为 1 就为 1 |
| `^` | 按位异或 | 对应位**不同**为 1 |
| `~` | 按位取反 | 0 变 1，1 变 0 |
| `<<` | 左移 | 整体左移，右侧补 0 |
| `>>` | 右移 | 整体右移 |

### 5.1 基本演示

```c
unsigned char a = 0b00001100;   // 12  （0b 为 GCC/C23 写法，可改写成 0x0C）
unsigned char b = 0b00001010;   // 10

a & b   →  0000 1000  =  8
a | b   →  0000 1110  = 14
a ^ b   →  0000 0110  =  6
~a      →  1111 0011（8位）
```

> **逻辑与 `&&` ≠ 按位与 `&`**：`2 && 1` 为 1，`2 & 1` 为 0。

### 5.2 异或的性质

```
a ^ a = 0        a ^ 0 = a
a ^ b = b ^ a    (a ^ b) ^ b = a   ← 可用于加密、交换
```

### 5.3 移位

```c
1 << 3        // 8      左移 n 位 ≈ 乘以 2^n
20 >> 2       // 5      右移 n 位 ≈ 除以 2^n（向下取整，对非负数）
```

**必须注意**

| 情形 | 后果 |
|---|---|
| 移位位数为**负数**，或**≥ 类型位宽** | **未定义行为** |
| 对**有符号负数**右移 | **实现定义**（多数编译器为算术右移，高位补符号位） |
| 对有符号数左移，结果**不能被表示**（如 `1 << 31` 作用于 `int`） | **未定义行为**（C23 前），应使用 `1u << 31` |
| 无符号数的移位 | 行为明确，右移补 0 |

```c
int x = 1 << 31;       // ✘ 有符号 int 上的 UB 风险
unsigned y = 1u << 31; // ✔ 0x80000000
int z = -8 >> 1;       // 多数平台 -4（算术右移），但标准未保证
```

### 5.3.1 整型提升陷阱

```c
unsigned char c = 0x0F;
printf("%x\n", ~c);                    // fffffff0 （c 先提升为 int，再取反）
printf("%x\n", (unsigned char)~c);     // f0
printf("%x\n", (~c) & 0xFF);           // f0
```

### 5.4 位操作"五件套"

假设 `unsigned x`，第 n 位（从 0 开始，最低位为第 0 位）：

```c
x |=  (1u << n);          // 置位：把第 n 位设为 1
x &= ~(1u << n);          // 清位：把第 n 位设为 0
x ^=  (1u << n);          // 翻转：第 n 位取反
(x >> n) & 1u             // 取位：读取第 n 位的值（0 或 1）
x & 0xFFu                 // 掩码：保留低 8 位
```

**示例：权限标志位**

```c
#include <stdio.h>

#define PERM_READ   (1u << 0)    // 0001
#define PERM_WRITE  (1u << 1)    // 0010
#define PERM_EXEC   (1u << 2)    // 0100

int main(void)
{
    unsigned perm = 0;

    perm |= PERM_READ | PERM_WRITE;        // 授予读写 → 0011
    printf("可写？%d\n", (perm & PERM_WRITE) != 0);   // 1
    printf("可执行？%d\n", (perm & PERM_EXEC) != 0);  // 0

    perm &= ~PERM_WRITE;                   // 撤销写权限 → 0001
    perm ^= PERM_EXEC;                     // 翻转执行权限 → 0101
    printf("perm = %u\n", perm);           // 5
    return 0;
}
```

### 5.5 常用位技巧

```c
// ① 判断奇偶
(n & 1) == 0                 // 偶数

// ② 判断 2 的幂（n > 0）
n > 0 && (n & (n - 1)) == 0  // n-1 会把最低位的 1 变 0、其右边变 1

// ③ 清除最低位的 1，并统计 1 的个数（Kernighan 算法）
int popcount(unsigned x)
{
    int c = 0;
    while (x) { x &= x - 1; c++; }
    return c;
}

// ④ 取最低位的 1
x & (~x + 1)                 // 对无符号数；有符号补码下等价于 x & -x

// ⑤ 不用临时变量交换（a、b 须为不同对象）
a ^= b;  b ^= a;  a ^= b;

// ⑥ 乘除 2 的幂
x << 3   // x * 8
x >> 2   // x / 4（仅对非负数等价）

// ⑦ 取出第 8~15 位
(x >> 8) & 0xFF

// ⑧ 组合 4 个字节成 32 位整数
uint32_t v = ((uint32_t)b0 << 24) | ((uint32_t)b1 << 16)
           | ((uint32_t)b2 <<  8) |  (uint32_t)b3;
```

### 5.6 例：用位运算输出二进制

```c
void print_bin(unsigned char x)
{
    for (int i = 7; i >= 0; i--)
        putchar(((x >> i) & 1) ? '1' : '0');
    putchar('\n');
}
// print_bin(37) → 00100101
```

## 6. 赋值与复合赋值运算符

### 6.1 简单赋值

```c
a = 5;
```
- 把右边的值转换成左边类型后存入；
- **赋值本身是表达式，值为被赋值后左操作数的值**；
- **右结合**。

```c
int a, b, c;
a = b = c = 0;        // 从右向左：c=0 → b=(c=0) → a=(b=0)

int ch;
while ((ch = getchar()) != EOF) { /* 常见写法：赋值+比较 */ }
```

### 6.2 复合赋值

| 运算符 | 等价于 |
|---|---|
| `a += b` | `a = a + b` |
| `-=`、`*=`、`/=`、`%=` | 同理 |
| `<<=`、`>>=`、`&=`、`^=`、`\|=` | 同理 |

```c
int x = 10;
x += 5;      // 15
x *= 2;      // 30
x %= 7;      // 2
x <<= 3;     // 16
```

注意：复合赋值中**表达式只计算一次**，且右侧整体先算：

```c
x *= 2 + 3;     // x = x * (2 + 3)，而不是 x = x * 2 + 3
```

### 6.3 赋值中的隐式转换

```c
int i = 3.9;          // 3（截断，且可能有 -Wconversion 警告）
float f = 1.0 / 3;    // double 转 float，精度丢失
char c = 65;          // 'A'
unsigned u = -1;      // 4294967295
```

## 7. 自增与自减

`++`（加 1）、`--`（减 1），操作数必须是**可修改的左值**。

| 形式 | 名称 | 表达式的值 | 变量最终 |
|---|---|---|---|
| `++a` | 前缀 | **自增后**的值 | a + 1 |
| `a++` | 后缀 | **自增前**的值 | a + 1 |

```c
#include <stdio.h>

int main(void)
{
    int a = 5, b, c;

    b = a++;                       // b = 5, a = 6
    printf("a=%d b=%d\n", a, b);   // a=6 b=5

    c = ++a;                       // a = 7, c = 7
    printf("a=%d c=%d\n", a, c);   // a=7 c=7

    int i = 3;
    int s = i-- + 10;              // s = 13, i = 2
    printf("i=%d s=%d\n", i, s);
    return 0;
}
```

### 7.1 独立语句中，前缀与后缀没有区别

```c
i++;      // 等价于 ++i;   （C 中二者效率通常一样；C++ 迭代器才有区别）
```

### 7.2 与指针的搭配（后续章节会用到）

```c
*p++       // 优先级：后缀 ++ 高于 *，等价于 *(p++)：取 p 所指的值，然后 p 后移
(*p)++     // p 所指的值加 1
*++p       // 先 p 后移，再取值
++*p       // 先取值再加 1
```

经典：字符串拷贝 `while ((*dst++ = *src++)) ;`

### 7.3 铁律

> **同一个表达式中，不要对同一个变量既修改又使用（或修改两次）。**
> 否则结果未定义，详见第 10 节。

## 8. 条件运算符、逗号运算符、sizeof

### 8.1 条件运算符 `? :`（C 中唯一的三目运算符）

```
表达式1 ? 表达式2 : 表达式3
```
表达式 1 为真 → 值为表达式 2；否则 → 值为表达式 3。**只计算其中一个分支**。

```c
int a = 3, b = 7;
int max = a > b ? a : b;                  // 7
printf("%s\n", n % 2 ? "奇数" : "偶数");

// 嵌套（右结合），但嵌套过深可读性差
char *grade = score >= 90 ? "A" : score >= 80 ? "B" : score >= 60 ? "C" : "D";
```

注意：
- 两个分支会做**常规算术转换**：`1 ? 1 : 2.0` 的值是 `double` 的 1.0；
- 有符号与无符号混用的陷阱同样存在：`(flag ? -1 : 1u)` 的类型是 `unsigned`；
- 优先级低于关系/逻辑，高于赋值：`x = a > b ? a : b` 即 `x = ((a > b) ? a : b)`。

### 8.2 逗号运算符 `,`

从左到右依次计算，**整个表达式的值是最后一个表达式的值**，逗号后是序列点。优先级**最低**。

```c
int x = (1, 2, 3);       // x = 3，必须加括号，否则变成声明列表
int y = 1, z = 2;        // 这里的逗号是声明分隔符，不是逗号运算符

// 常见用途：for 循环里的多个变量
for (int i = 0, j = 9; i < j; i++, j--) { }

// 函数参数里的逗号也只是分隔符，不是逗号运算符
printf("%d %d\n", 1, 2);
```

### 8.3 sizeof 运算符

```c
sizeof(int)        // 类型：必须加括号
sizeof a           // 表达式：括号可省
sizeof(a + 1)      // 操作数不会被求值，只看类型
```
返回 `size_t`，输出用 `%zu`。详见第 2 章。

> 常用写法：`sizeof(arr) / sizeof(arr[0])` 求数组元素个数（仅对真正的数组有效，**对函数参数中的"数组"无效**，因为它实际是指针）。

## 9. 优先级与结合性

### 9.1 概念

- **优先级**：不同运算符混在一起时，谁先算（`*` 先于 `+`）；
- **结合性**：同优先级时，从左到右还是从右到左（`a - b - c` 是 `(a - b) - c`，`a = b = c` 是 `a = (b = c)`）。

> 优先级决定"**怎么加括号**"，**并不**决定"**先计算哪个操作数**"（见第 10 节）。

### 9.2 优先级表（从高到低）

| 级别 | 运算符 | 结合性 |
|---|---|---|
| 1 | `()` 函数调用　`[]`　`.`　`->`　后缀 `++` `--`　复合字面量 | 左 → 右 |
| 2 | 前缀 `++` `--`　一元 `+` `-`　`!` `~`　`(type)`　`*`（解引用）　`&`（取地址）　`sizeof`　`_Alignof` | **右 → 左** |
| 3 | `*` `/` `%` | 左 → 右 |
| 4 | `+` `-` | 左 → 右 |
| 5 | `<<` `>>` | 左 → 右 |
| 6 | `<` `<=` `>` `>=` | 左 → 右 |
| 7 | `==` `!=` | 左 → 右 |
| 8 | `&`（按位与） | 左 → 右 |
| 9 | `^` | 左 → 右 |
| 10 | `\|` | 左 → 右 |
| 11 | `&&` | 左 → 右 |
| 12 | `\|\|` | 左 → 右 |
| 13 | `? :` | **右 → 左** |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | **右 → 左** |
| 15 | `,` | 左 → 右 |

**记忆口诀**：
> 单目 > 算术 > 移位 > 关系 > 相等 > 位运算（& ^ \|）> 逻辑（&& \|\|）> 条件 > 赋值 > 逗号

### 9.3 高频踩坑

| 表达式 | 实际含义 | 说明 |
|---|---|---|
| `x & 1 == 0` | `x & (1 == 0)` → 恒为 0 | `==` 比 `&` 高！应写 `(x & 1) == 0` |
| `a << 2 + 1` | `a << (2 + 1)` | `+` 比 `<<` 高 |
| `!a == b` | `(!a) == b` | `!` 极高 |
| `c = getchar() != EOF` | `c = (getchar() != EOF)` | 赋值最低，需写 `(c = getchar()) != EOF` |
| `a = b == c` | `a = (b == c)` | |
| `*p++` | `*(p++)` | |
| `-a++` | `-(a++)` | |
| `a + b >> 1` | `(a + b) >> 1` | 算术优先于移位 |
| `a ? b : c = d` | 解析复杂 | 避免 |
| `a || b && c` | `a || (b && c)` | |
| `sizeof a + b` | `(sizeof a) + b` | |
| `(char)x + y` | `((char)x) + y` | 强转优先级高于算术 |

### 9.4 实践原则

> **不确定就加括号。** 括号不会降低性能，却能显著提升可读性、避免错误。

```c
if ((flags & MASK_A) != 0 && (x + y) > limit) { }
```

## 10. 求值顺序、序列点与未定义行为

### 10.1 优先级 ≠ 求值顺序

```c
int r = f() + g() * h();
```
- 优先级：`g() * h()` 先结合，再与 `f()` 相加；
- 但 `f()`、`g()`、`h()` **谁先被调用，C 标准不规定**（**未指定行为**）。若它们互相依赖输出/全局状态，结果不可移植。

```c
printf("%d %d\n", f(), g());    // f 和 g 的调用顺序未指定
```

### 10.2 序列点（Sequence Point）

序列点是程序执行中的一个"**所有之前的副作用都已完成，之后的副作用尚未发生**"的点。主要出现在：

| 位置 | 说明 |
|---|---|
| 完整表达式末尾（`;`） | 语句结束 |
| `&&`、`\|\|` 的左操作数之后 | 短路求值保证 |
| `? :` 的第一个操作数之后 | |
| 逗号运算符之后 | |
| 函数调用中，**所有实参求值之后、函数体执行之前** | 注意：实参之间**没有**序列点 |

C11 术语为"**sequenced before / unsequenced**"（先序于/无序于），含义类似。

### 10.3 核心规则

> 在两个序列点之间（即同一个表达式内），**一个标量对象的值若被修改，则同一表达式中对它的其他访问，只能用于计算它的新值**；否则行为未定义（UB）。
> 通俗说：**同一表达式里，别对同一个变量"改一次、再读/再改一次"**。

### 10.4 经典未定义行为

```c
int i = 1, a[5] = {0};

i = i++ + ++i;           // UB：i 被修改多次，无序列点
i = i++;                 // UB：i 被修改两次
a[i] = i++;              // UB：读 i（下标）与修改 i 无序
printf("%d %d\n", i, i++);   // UB：实参之间无序
printf("%d %d\n", i++, i++); // UB
int x = i++ * i++;           // UB
i = ++i + 1;                 // UB（C 中 ++i 的写入与再次赋值无序）
```

不同编译器会给出不同结果（甚至同一编译器不同优化级别也不同），**不要研究它们的"结果"，要做的是避免写出来**。

### 10.4.1 合法的写法（有序列点保障）

```c
i++;  j = i;                 // 分成多个语句
a[i] = i + 1;                // i 只被读取，没有被修改，OK
*p++ = *q++;                 // 修改的是不同对象 p、q，OK
if (i++ && i > 0) { }        // && 左侧后有序列点，OK
x = (i++, i + 1);            // 逗号后有序列点，OK
i = i + 1;                   // 修改 i，但读取 i 仅用于计算新值，OK
```

### 10.5 三类"不确定行为"（预览，第 17 章详述）

| 类别 | 含义 | 举例 |
|---|---|---|
| **未指定行为**（unspecified） | 标准给出若干可选，编译器不必文档化 | 函数实参求值顺序 |
| **实现定义行为**（implementation-defined） | 编译器必须文档化其选择 | `char` 是否有符号、负数右移 |
| **未定义行为**（undefined） | 标准不对结果作任何要求：崩溃、错误结果、甚至"看似正常" | 有符号溢出、越界访问、`i = i++` |

### 10.6 如何避免

1. **一个表达式只做一件有副作用的事**；
2. 复杂表达式拆成多行；
3. 开启 `-Wall -Wextra`（含 `-Wsequence-point`）并认真对待警告；
4. 用 `-fsanitize=undefined` 在运行时抓有符号溢出、非法移位等 UB。

## 11. 综合示例

### 11.1 交换两个整数的多种写法

```c
// ① 临时变量（推荐）
int t = a; a = b; b = t;

// ② 异或
if (&a != &b) { a ^= b; b ^= a; a ^= b; }

int abs_val = x < 0 ? -x : x;                  // x == INT_MIN 时溢出，需特殊处理
int max2 = a > b ? a : b;
int max3 = (a > b ? a : b) > c ? (a > b ? a : b) : c;   // 太绕，改写：
int m = a > b ? a : b;
int max3b = m > c ? m : c;

### 11.3 判断一个字符的类别

char c = 'k';
if (c >= 'a' && c <= 'z')       puts("小写字母");
else if (c >= 'A' && c <= 'Z')  puts("大写字母");
else if (c >= '0' && c <= '9')  puts("数字");
else                            puts("其他");
```

### 11.4 位运算：RGB 颜色的打包与解包

```c
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint8_t r = 0x12, g = 0x34, b = 0x56;
    uint32_t rgb = ((uint32_t)r << 16) | ((uint32_t)g << 8) | b;
    printf("0x%06X\n", rgb);                 // 0x123456

    uint8_t r2 = (rgb >> 16) & 0xFF;
    uint8_t g2 = (rgb >>  8) & 0xFF;
    uint8_t b2 =  rgb        & 0xFF;
    printf("%02X %02X %02X\n", r2, g2, b2);  // 12 34 56
    return 0;
}
```

### 11.5 只出现一次的数字

数组中其余数字都出现两次，只有一个出现一次，找出它（异或的应用）：

```c
int single(const int *a, int n)
{
    int r = 0;
    for (int i = 0; i < n; i++) r ^= a[i];   // 成对的数字异或后抵消
    return r;
}
// {4, 1, 2, 1, 2} → 4
```

## 12. 本章小结与练习

### 12.1 知识要点回顾

| 主题 | 关键点 |
|---|---|
| 算术 | 整数除法向零截断；`%` 仅整数，符号随被除数；除零 UB |
| 关系 | 结果 0/1；`=` 与 `==`；不能连写 `a < b < c`；浮点用差值比较 |
| 逻辑 | 非零即真，结果 0/1；`&&`、`\|\|` **短路**并有序列点 |
| 位运算 | `& \| ^ ~ << >>`；移位位数不得为负或 ≥ 位宽；优先用无符号数；注意整型提升 |
| 赋值 | 右结合；赋值也是表达式；复合赋值 |
| 自增自减 | 前缀先改后用，后缀先用后改；同一表达式不要多次改同一变量 |
| `?:` / `,` | 三目、右结合；逗号最低、值为最后一项 |
| 优先级 | 单目 > 算术 > 移位 > 关系 > 相等 > `& ^ \|` > `&& \|\|` > `?:` > 赋值 > `,`；不确定就加括号 |
| 求值顺序 | 优先级 ≠ 求值顺序；实参顺序未指定；同一表达式改同一变量是 UB |

### 12.2 易错点清单

1. `-7 / 2` 是 `-3`，`-7 % 2` 是 `-1`。
2. `if (x = 5)` 恒真；`0 < x < 10` 恒真。
3. `x & 1 == 0` 并非判断偶数。
4. `1 << 31`（int）有风险；移位位数不能 ≥ 位宽。
5. `~` 作用在 `unsigned char` 上会先提升为 `int`。
6. `i = i++`、`a[i] = i++`、`printf("%d %d", i++, i++)` 都是 UB。
7. `#define SQUARE(x) x*x` 遇到 `SQUARE(a+1)` 出错（第 12 章详述），且 `SQUARE(i++)` 有副作用重复。
8. 无符号数 `x - 1` 在 `x == 0` 时回绕。
9. `abs(INT_MIN)`、`INT_MIN / -1` 都是 UB。
10. 逗号运算符与声明、函数参数中的逗号不是一回事。

### 12.3 练习题

**基础**
1. 输入一个三位整数，分别输出其百位、十位、个位，并输出反转后的数。
2. 输入秒数，输出"时:分:秒"格式（`%02d:%02d:%02d`）。
3. 判断一个年份是否为闰年；判断一个整数是否能被 3 且被 5 整除。
4. 输入华氏温度，输出摄氏温度，保留 2 位小数（注意 `5/9` 的整数除法陷阱）。

**理解**
5. 写出下面每个表达式的值（先手算，再运行验证）：
   ```c
   int a = 5, b = 3, c;
   c = a++ + b;          // c = ?  a = ?
   c = ++a * b--;        // c = ?  a = ?  b = ?
   c = a > b ? a : b;
   c = (a & b) | (a ^ b);
   c = a << 2 | b >> 1;
   c = !a || b && 0;
   c = -7 / 2 + -7 % 2;
   ```
6. 下列哪些是未定义行为？说明原因：
   `a[i++] = i;`　`x = y = z = 0;`　`i = (i++, i + 1);`　`p = p++ + 1;`　`f(i++, i++)`　`if (i++ == 0 && i++ == 1)`
7. 找出下面代码的 bug 并修复：
   ```c
   if (flags & MASK == 0) { ... }
   if (c = getchar() != EOF) { ... }
   if (0 <= score <= 100)    { ... }
   ```

**进阶**
8. 不使用乘除法与 `%`，用位运算实现 `x * 10`（提示：`x * 10 = (x << 3) + (x << 1)`）。
9. 写函数判断一个整数是否为 2 的幂，并统计其二进制中 1 的个数。
10. 实现 `swap_bits(x, i, j)`：交换整数 `x` 的第 i 位与第 j 位。
11. 实现安全的 `int_add(a, b, &result)`，溢出时返回错误码。
12. 给定一个整型数组，除两个数字只出现一次外，其余都出现两次，找出这两个数。（提示：全体异或得 `a^b`，取其最低位 1 将数组分为两组。）

### 12.4 参考答案（部分）

**第 5 题**：
- `c = a++ + b` → c = 8，a = 6
- `c = ++a * b--` → a = 7，c = 7 × 3 = 21，b = 2
- `c = a > b ? a : b` → 7
- `(a & b) | (a ^ b)` = `(7 & 2) | (7 ^ 2)` = `2 | 5` = 7
- `a << 2 | b >> 1` = `(7 << 2) | (2 >> 1)` = `28 | 1` = 29
- `!a || b && 0` = `0 || (2 && 0)` = 0
- `-7 / 2 + -7 % 2` = `-3 + -1` = -4

**第 6 题**：`a[i++] = i;` UB；`x=y=z=0;` 合法；`i = (i++, i + 1);` 合法（逗号之后有序列点，`i++` 的副作用先完成，之后才计算 `i + 1` 并赋值）；`p = p++ + 1;` UB；`f(i++, i++)` UB；`if (i++ == 0 && i++ == 1)` 合法（`&&` 有序列点）。

**第 7 题**：
```c
if ((flags & MASK) == 0)
if ((c = getchar()) != EOF)
if (0 <= score && score <= 100)
```

**第 9 题**：
```c
int is_pow2(unsigned n)  { return n != 0 && (n & (n - 1)) == 0; }
int popcount(unsigned n) { int c = 0; while (n) { n &= n - 1; c++; } return c; }
```

**第 10 题**：
```c
unsigned swap_bits(unsigned x, int i, int j)
{
    if (((x >> i) & 1u) != ((x >> j) & 1u))
        x ^= (1u << i) | (1u << j);     // 两位不同才需要翻转
    return x;
}
```
