## 1. 标识符与关键字

### 1.1 标识符命名规则

标识符 = 变量名、函数名、类型名、宏名等**程序员起的名字**。

规则：
1. 只能由**字母、数字、下划线**组成；
2. **不能以数字开头**；
3. **区分大小写**（`count` 与 `Count` 不同）；
4. 不能是关键字；
5. 长度：标准保证外部标识符前 31 个字符有效（现代编译器基本不限）。

```c
int age;          // ✔
int _count;       // ✔（但以下划线开头的名字多保留给系统，不建议）
int student2;     // ✔
int 2student;     // ✘ 数字开头
int my-var;       // ✘ 含 '-'
int int;          // ✘ 关键字
```

**保留名字**（不要自己使用）：
- 以 `_` 加大写字母开头，或以 `__` 开头的名字（如 `_Bool`、`__FILE__`）；
- 标准库中已存在的名字（如 `printf`、`strlen`、`abs`）；
- 以 `str`、`mem`、`is`、`to` 开头且后接小写字母的名字，是标准库预留的（如 `strdup`、`isnumber`）。

### 1.2 命名风格

| 风格 | 示例 | 常见用途 |
|---|---|---|
| snake_case | `student_count` | 变量、函数（C 主流风格） |
| UPPER_SNAKE | `MAX_SIZE` | 宏、常量 |
| 带前缀 | `g_total`（全局）、`s_buf`（静态） | 部分团队规范 |

好名字要**见名知意**：`n`、`i`、`j` 只适合小范围循环变量；其余用 `student_count` 这类名字。

### 1.3 关键字

**C99 的 37 个关键字**（C11 / C23 又有新增）：

| 类别 | 关键字 |
|---|---|
| 数据类型 | `char` `short` `int` `long` `float` `double` `signed` `unsigned` `void` `_Bool` `_Complex` `_Imaginary` |
| 自定义类型 | `struct` `union` `enum` `typedef` |
| 存储类别 | `auto` `register` `static` `extern` |
| 类型限定 | `const` `volatile` `restrict` |
| 流程控制 | `if` `else` `switch` `case` `default` `for` `while` `do` `break` `continue` `goto` `return` |
| 其他 | `sizeof` `inline` |

**C11 新增**：`_Alignas` `_Alignof` `_Atomic` `_Generic` `_Noreturn` `_Static_assert` `_Thread_local`
**C23 新增**：`bool` `true` `false` `nullptr` `constexpr` `typeof` `static_assert` `alignas` `alignof` 等

## 2. 整型

### 2.1 基本整型一览

| 类型 | 说明 | 最低保证 |
|---|---|---|
| `char` | 最小的整型，通常用于字符 | 至少 8 位 |
| `short`（`short int`） | 短整型 | 至少 16 位 |
| `int` | 基本整型，"最自然"的长度 | 至少 16 位 |
| `long`（`long int`） | 长整型 | 至少 32 位 |
| `long long`（C99） | 更长整型 | 至少 64 位 |

标准只规定**最小范围与大小关系**：

```
sizeof(char) == 1  ≤  sizeof(short) ≤ sizeof(int) ≤ sizeof(long) ≤ sizeof(long long)
```

### 2.2 常见平台的实际大小

| 类型 | 64 位 Linux / macOS（LP64） | 64 位 Windows（LLP64） | 32 位平台（ILP32） |
|---|---|---|---|
| `char` | 1 | 1 | 1 |
| `short` | 2 | 2 | 2 |
| `int` | 4 | 4 | 4 |
| `long` | **8** | **4** | 4 |
| `long long` | 8 | 8 | 8 |
| 指针 | 8 | 8 | 4 |

> **要点**：`long` 的大小在不同平台**不一致**。要求固定宽度时请用 `<stdint.h>` 里的类型（见第 7 节）。

### 2.3 有符号与无符号

- `signed`（默认，`char` 除外）：可表示正负数；
- `unsigned`：只表示非负数，范围翻倍。

以 8 位为例：

| 类型 | 范围 |
|---|---|
| `signed char` | −128 ~ 127 |
| `unsigned char` | 0 ~ 255 |

以常见 4 字节 `int` 为例：

| 类型 | 范围 |
|---|---|
| `int` | −2,147,483,648 ~ 2,147,483,647（约 ±21 亿） |
| `unsigned int` | 0 ~ 4,294,967,295（约 42 亿） |

书写形式：

```c
unsigned int a;       // 可简写为 unsigned a;
long int b;           // 可简写为 long b;
unsigned long long c; // 以上都合法
```

> 注意：**`char` 是否有符号由实现决定**。x86 的 GCC 上为 signed，ARM 的 Linux 上常为 unsigned。需要明确语义时，写 `signed char` 或 `unsigned char`。

### 2.4 用 printf 输出整型

| 类型 | 格式符 |
|---|---|
| `int` | `%d` / `%i` |
| `unsigned int` | `%u`（十六进制 `%x`，八进制 `%o`） |
| `short` | `%hd` |
| `long` | `%ld` |
| `unsigned long` | `%lu` |
| `long long` | `%lld` |
| `unsigned long long` | `%llu` |
| `size_t` | `%zu` |

```c
#include <stdio.h>

int main(void)
{
    int a = -10;
    unsigned int b = 4000000000u;
    long c = 1234567890123L;
    long long d = 9000000000000000000LL;

    printf("a = %d\n",   a);
    printf("b = %u\n",   b);
    printf("c = %ld\n",  c);
    printf("d = %lld\n", d);
    printf("0x%x\n", 255);        // 输出 0xff
    return 0;
}
```

> **陷阱**：格式符与参数类型不匹配属于未定义行为。例如 `printf("%d", 3000000000u)` 或 `printf("%d", 10L)`（`long` 为 8 字节时）可能输出错误结果。

### 2.5 无符号数的"坑"

```c
#include <stdio.h>

int main(void)
{
    unsigned int u = 0;
    u = u - 1;
    printf("%u\n", u);           // 4294967295（回绕）

    for (unsigned int i = 3; i >= 0; i--) {   // ✘ 死循环！无符号数永远 >= 0
        printf("%u ", i);
    }
    return 0;
}
```

**经验**：除非需要位运算或明确的非负语义（如下标、大小 `size_t`），**优先使用有符号数**；二者混用时要格外小心（见第 11 节）。

## 3. 浮点型

### 3.1 三种浮点类型

| 类型 | 典型大小 | 有效数字（十进制） | 典型范围 |
|---|---|---|---|
| `float` | 4 字节 | 约 6–7 位 | ±3.4×10³⁸ |
| `double` | 8 字节 | 约 15–16 位 | ±1.8×10³⁰⁸ |
| `long double` | 8/12/16 字节（依平台） | 18+ 位（x86 为 80 位扩展精度） | 更大 |

> 默认的浮点字面量（如 `3.14`）是 `double`。**日常首选 `double`**。

### 3.2 输出格式

| 类型 | printf | scanf |
|---|---|---|
| `float` | `%f`（实际按 double 传入） | `%f` |
| `double` | `%f` / `%lf` | **`%lf`** |
| `long double` | `%Lf` | `%Lf` |

科学计数：`%e`（如 `1.230000e+02`），自动选择：`%g`。

```c
#include <stdio.h>

int main(void)
{
    double pi = 3.14159265358979;
    float  f  = 3.14159265358979f;

    printf("%f\n",   pi);        // 3.141593   (默认6位小数)
    printf("%.2f\n", pi);        // 3.14
    printf("%10.3f|\n", pi);     // "     3.142|"  宽10，3位小数
    printf("%e\n",   pi);        // 3.141593e+00
    printf("%.10f\n", f);        // 3.1415927410  ← float 精度有限！
    return 0;
}
```

### 3.3 精度问题（务必理解）

十进制小数大多**无法用二进制精确表示**（就像 1/3 无法用十进制有限小数表示）。

```c
#include <stdio.h>

int main(void)
{
    double a = 0.1 + 0.2;
    printf("%.20f\n", a);              // 0.30000000000000004441
    printf("%d\n", a == 0.3);          // 0 （不相等！）
    return 0;
}
```

**正确的比较方式：看差值是否足够小**

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    double a = 0.1 + 0.2;
    double eps = 1e-9;
    if (fabs(a - 0.3) < eps)
        printf("近似相等\n");
    return 0;
}
```

**其他典型现象**

```c
float big = 16777216.0f;     // 2^24
printf("%f\n", big + 1.0f);  // 仍是 16777216.000000（float 有效位 24 位，加 1 被"吞掉"）

double sum = 0;
for (int i = 0; i < 10; i++) sum += 0.1;
printf("%d\n", sum == 1.0);  // 0
```

**金融计算**：不要用浮点表示金额，应使用**整数（以"分"为单位）**或专门的十进制库。

### 3.4 特殊值

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    double inf = 1.0 / 0.0;      // +Inf（浮点除零不崩溃）
    double nan = 0.0 / 0.0;      // NaN
    printf("%f %f\n", inf, nan); // inf nan
    printf("%d\n", nan == nan);  // 0 ：NaN 不等于任何值，包括自己
    printf("%d\n", isnan(nan));  // 非0
    return 0;
}
```

> **对比**：**整数除以 0 是未定义行为**（通常导致程序崩溃），浮点除以 0 得到 Inf/NaN。

## 4. 字符型与 ASCII

### 4.1 char 本质上是一个小整数

```c
#include <stdio.h>

int main(void)
{
    char c = 'A';
    printf("%c\n", c);        // A
    printf("%d\n", c);        // 65
    printf("%c\n", c + 1);    // B
    printf("%c\n", 97);       // a
    return 0;
}
```

- 单引号 `'A'` 是**字符常量**，其类型在 C 中是 `int`（在 C++ 中才是 `char`），值为 ASCII 码 65。
- 双引号 `"A"` 是**字符串字面量**，类型是 `char[2]`（`'A'` 和 `'\0'`）。

```c
printf("%zu %zu\n", sizeof('A'), sizeof("A"));   // 4 2
```

### 4.2 ASCII 表速记

| 范围 | 内容 |
|---|---|
| 0–31, 127 | 控制字符（如 `\n`=10, `\t`=9, `\0`=0） |
| 32 | 空格 |
| 48–57 | `'0'`–`'9'` |
| 65–90 | `'A'`–`'Z'` |
| 97–122 | `'a'`–`'z'` |

规律：**小写 = 大写 + 32**；`'0'` 的值是 48。

### 4.3 常见字符技巧

```c
char ch = 'g';

// 小写转大写
char upper = ch - 'a' + 'A';          // 'G'
char upper2 = ch - 32;                // 同上，但可读性差

// 数字字符转数值
char d = '7';
int v = d - '0';                      // 7

// 数值转数字字符
int n = 5;
char dc = n + '0';                    // '5'

// 判断是否为字母（更推荐使用 <ctype.h> 的 isalpha）
if ((ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')) { /* ... */ }
```

### 4.4 字符编码概览

| 编码 | 特点 |
|---|---|
| **ASCII** | 7 位，128 个字符，仅英文 |
| **GBK / GB2312** | 中文双字节编码（Windows 中文版常见） |
| **Unicode** | 字符集，给每个字符一个编号（码点） |
| **UTF-8** | Unicode 的变长编码：1–4 字节，兼容 ASCII，**事实标准** |

```c
printf("%zu\n", sizeof("你"));     // 在 UTF-8 源文件中为 4（3 字节汉字 + '\0'）
```

> 一个汉字不能放进一个 `char`。处理中文需要多字节字符串或宽字符（第 9 章）。

## 5. 布尔类型

C89 没有布尔类型，传统上**用整数表示：0 为假，非 0 为真**。

```c
int x = 5;
if (x)       { /* 真 */ }
if (!x)      { /* 假 */ }
int r = (3 > 2);   // r 为 1，关系/逻辑运算结果只有 0 或 1
```

**C99** 引入 `_Bool`，头文件 `<stdbool.h>` 提供 `bool / true / false` 宏：

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool ok = true;
    _Bool b = 100;          // 任何非0值赋给 _Bool 都变成 1
    printf("%d %d\n", ok, b);   // 1 1
    printf("%zu\n", sizeof(bool));  // 通常为 1
    return 0;
}
```

> `_Bool` 的赋值规则：**非零 → 1，零 → 0**。C23 中 `bool/true/false` 成为关键字，无需头文件。

## 6. sizeof 与类型极限值

### 6.1 sizeof 运算符

- 返回对象或类型占用的**字节数**，类型为 `size_t`（无符号整型），用 `%zu` 输出。
- 是**编译期运算符**（VLA 除外），不是函数。

```c
#include <stdio.h>

int main(void)
{
    int a = 0;
    int arr[10];

    printf("char        : %zu\n", sizeof(char));
    printf("short       : %zu\n", sizeof(short));
    printf("int         : %zu\n", sizeof(int));
    printf("long        : %zu\n", sizeof(long));
    printf("long long   : %zu\n", sizeof(long long));
    printf("float       : %zu\n", sizeof(float));
    printf("double      : %zu\n", sizeof(double));
    printf("long double : %zu\n", sizeof(long double));
    printf("void*       : %zu\n", sizeof(void *));

    printf("a           : %zu\n", sizeof a);         // 对变量可省略括号
    printf("arr         : %zu\n", sizeof(arr));      // 40
    printf("元素个数     : %zu\n", sizeof(arr) / sizeof(arr[0]));   // 10
    return 0;
}
```

64 位 Linux 典型输出：`1 2 4 8 8 4 8 16 8`。

> **提示**：`sizeof` 的表达式**不会被求值**：`int i = 0; sizeof(i++);` 之后 `i` 仍是 0。

### 6.2 `<limits.h>` —— 整型极限

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("CHAR_BIT  = %d\n",  CHAR_BIT);       // 8
    printf("CHAR_MIN  = %d\n",  CHAR_MIN);
    printf("CHAR_MAX  = %d\n",  CHAR_MAX);
    printf("SHRT_MAX  = %d\n",  SHRT_MAX);       // 32767
    printf("INT_MIN   = %d\n",  INT_MIN);        // -2147483648
    printf("INT_MAX   = %d\n",  INT_MAX);        // 2147483647
    printf("UINT_MAX  = %u\n",  UINT_MAX);       // 4294967295
    printf("LONG_MAX  = %ld\n", LONG_MAX);
    printf("LLONG_MAX = %lld\n", LLONG_MAX);
    printf("ULLONG_MAX= %llu\n", ULLONG_MAX);
    return 0;
}
```

常用宏：`CHAR_BIT / SCHAR_MIN / SCHAR_MAX / UCHAR_MAX / SHRT_MIN / SHRT_MAX / USHRT_MAX / INT_MIN / INT_MAX / UINT_MAX / LONG_MIN / LONG_MAX / ULONG_MAX / LLONG_MIN / LLONG_MAX / ULLONG_MAX`。

### 6.3 `<float.h>` —— 浮点特性

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("FLT_MAX  = %e\n", FLT_MAX);       // 3.402823e+38
    printf("FLT_MIN  = %e\n", FLT_MIN);       // 1.175494e-38（最小正规数）
    printf("FLT_EPSILON = %e\n", FLT_EPSILON);// 1.192093e-07
    printf("FLT_DIG  = %d\n", FLT_DIG);       // 6
    printf("DBL_MAX  = %e\n", DBL_MAX);       // 1.797693e+308
    printf("DBL_EPSILON = %e\n", DBL_EPSILON);// 2.220446e-16
    printf("DBL_DIG  = %d\n", DBL_DIG);       // 15
    return 0;
}
```

`EPSILON` 表示"1.0 与比 1.0 大的下一个可表示数之间的差"，可用来设计浮点比较阈值。

## 7. 定长整数类型 stdint.h

由于 `int / long` 大小因平台而异，C99 提供了**固定宽度**类型（`<stdint.h>`）：

| 类型 | 含义 |
|---|---|
| `int8_t` `int16_t` `int32_t` `int64_t` | 恰好 N 位有符号 |
| `uint8_t` `uint16_t` `uint32_t` `uint64_t` | 恰好 N 位无符号 |
| `int_least32_t` 等 | 至少 N 位的最小类型 |
| `int_fast32_t` 等 | 至少 N 位的最快类型 |
| `intptr_t` / `uintptr_t` | 能存放指针的整数类型 |
| `intmax_t` / `uintmax_t` | 最大的整数类型 |

极限值宏：`INT32_MAX`、`UINT8_MAX`、`INT64_MIN`、`SIZE_MAX` 等。

**配套输出格式宏在 `<inttypes.h>`**：

```c
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    int32_t  a = -100;
    uint64_t b = 18446744073709551615ULL;
    uint8_t  c = 200;

    printf("a = %" PRId32 "\n", a);
    printf("b = %" PRIu64 "\n", b);
    printf("c = %" PRIu8  "\n", c);
    printf("c = 0x%" PRIx8 "\n", c);   // 0xc8
    return 0;
}
```

> **适用场景**：网络协议、文件格式、嵌入式寄存器、跨平台数据结构——凡是"位宽必须确定"的地方都应使用定长类型。

其他常用的标准类型（`<stddef.h>`）：
- `size_t`：表示大小/下标，无符号，`sizeof` 的结果类型；
- `ptrdiff_t`：两个指针相减的结果类型，有符号。

## 8. 字面量与转义字符

字面量（literal）是**直接写在代码里的值**。

### 8.1 整数字面量

| 形式 | 例子 | 说明 |
|---|---|---|
| 十进制 | `123` | |
| 八进制 | `017`（=15） | 以 `0` 开头！ |
| 十六进制 | `0x1F`、`0XFF` | 值 31、255 |
| 二进制 | `0b1010` | C23 标准；GCC/Clang 早已作为扩展支持 |

**后缀**决定类型：

| 后缀 | 类型 | 例子 |
|---|---|---|
| `u` / `U` | unsigned | `10u` |
| `l` / `L` | long | `10L` |
| `ll` / `LL` | long long | `10LL` |
| 组合 | | `10UL`、`10ULL` |

> 推荐用大写 `L`，因为小写 `l` 易与数字 `1` 混淆。

```c
int a = 010;      // 8，而不是 10！
int b = 0x10;     // 16
long big = 3000000000L;
```

**十进制整数字面量的类型**：会选第一个能装下它的类型（`int → long → long long`）。所以 `3000000000` 在 `int` 为 32 位的平台上就是 `long`。

### 8.2 浮点字面量

```c
3.14        // double
3.14f       // float
3.14L       // long double
1e3         // 1000.0  (double)
2.5e-4      // 0.00025
.5          // 0.5
5.          // 5.0
0x1.8p1     // 十六进制浮点：1.5 × 2^1 = 3.0（C99）
```

### 8.3 字符与字符串字面量

```c
'A'          // 字符常量，类型 int，值 65
'\n'         // 转义字符
'\x41'       // 十六进制转义，即 'A'
'\101'       // 八进制转义，即 'A'
"Hello"      // 字符串字面量，类型 char[6]
"Hel" "lo"   // 相邻字符串自动拼接 → "Hello"
```

相邻字符串拼接的实用场景：

```c
printf("这是一行很长很长的文字，"
       "写成多行更便于阅读。\n");
```

### 8.4 常用转义字符

| 转义 | 含义 | ASCII |
|---|---|---|
| `\n` | 换行 | 10 |
| `\r` | 回车（回到行首） | 13 |
| `\t` | 水平制表符 | 9 |
| `\b` | 退格 | 8 |
| `\a` | 响铃 | 7 |
| `\f` | 换页 | 12 |
| `\v` | 垂直制表符 | 11 |
| `\0` | 空字符（字符串结束标志） | 0 |
| `\\` | 反斜杠 | 92 |
| `\'` | 单引号 | 39 |

| `\?` | 问号 | 63 |

#include <stdio.h>

int main(void)

    printf("abc\rX\n");                    // 输出 Xbc（\r 回到行首覆盖）
    return 0;
}

## 9. 常量：const、#define、enum

"常量"= 值不可改变的量。C 中有四种常见方式。

### 9.1 字面量常量
直接写数值，如 `100`、`3.14`、`'a'`、`"abc"`。

### 9.2 `#define` 宏常量

```c
#define PI        3.14159
#define MAX_SIZE  100
#define MSG       "Hello"
```

- **预处理阶段做文本替换**，无类型、无作用域、不占内存；
- 调试时看不到宏名，类型检查缺失。

**宏的经典陷阱**：

```c
#define N 3 + 4
int x = N * 2;      // 展开为 3 + 4 * 2 = 11，而非 14

#define N2 (3 + 4)  // 正确做法：加括号
```

结尾不要加分号：
```c
#define MAX 100;     // ✘ 展开后 int a[MAX]; 变成 int a[100;];
```

### 9.3 `const` 修饰的只读变量

```c
const double pi = 3.14159265358979;
const int max_count = 100;

pi = 3.14;           // ✘ 编译错误：不能修改只读变量
```

- 有类型、有作用域、可被调试器查看；
- **C 中的 `const` 变量不是真正的"编译期常量"**：

```c
const int n = 5;
int arr[n];          // C89 中非法；C99 起视为 VLA（变长数组），语法合法但并不是常量表达式
```
需要真正的常量表达式（如 `switch` 的 `case`、静态数组长度、位域宽度）时，用 `#define`、`enum`，或 C23 的 `constexpr`。

```c
const int k = 3;
switch (x) {
    case k:  break;   // ✘ C 中 case 后必须是常量表达式
}
```

**强行修改 const 是未定义行为**：

```c
const int a = 10;
int *p = (int *)&a;
*p = 20;             // UB：可能崩溃，可能输出 10 或 20
```

### 9.4 `enum` 枚举常量

```c
enum Color { RED, GREEN, BLUE };             // 0, 1, 2
enum Weekday { MON = 1, TUE, WED, THU, FRI, SAT, SUN };   // 1..7
enum Size { SMALL = 10, MEDIUM = 20, LARGE = 30 };

enum Color c = GREEN;
printf("%d\n", c);          // 1
```

- 枚举常量是**整型常量表达式**，可用于数组长度、`case` 标签；
- 用来表示"一组相关的整数常量"（状态码、选项、错误码）。

```c
enum { BUF_SIZE = 256 };         // 匿名枚举，常用作"真正的整型常量"
char buf[BUF_SIZE];
```

### 9.5 四者对比

| 特性 | 字面量 | `#define` | `const` | `enum` |
|---|---|---|---|---|
| 有类型检查 | — | ✘ | ✔ | 整型 |
| 有作用域 | — | ✘（从定义处到文件末/`#undef`） | ✔ | ✔ |
| 可作数组长度/`case` | ✔ | ✔ | ✘（C 中） | ✔ |
| 调试可见 | — | ✘ | ✔ | ✔ |
| 可为浮点/字符串 | ✔ | ✔ | ✔ | ✘（仅整型） |

**选用建议**：整型常量集合用 `enum`；浮点、字符串等常量用 `const`；需要常量表达式又不是整型时用 `#define`；条件编译与宏函数用 `#define`。

## 10. 变量的声明、定义与初始化

### 10.1 变量是什么

**变量 = 一块有名字的内存**。它有三要素：**类型**（决定大小和解释方式）、**名字**、**值**。

```c
int age = 20;
```

```
内存地址        内容
0x7ffc...a4   | 00 00 00 14 |  ← age（int，4 字节，值 20）
```

### 10.2 声明与定义

- **定义**：为变量**分配内存**（可同时初始化）。
- **声明**：只告诉编译器"这个名字存在，类型是什么"，**不分配内存**（用 `extern`）。

```c
int a;               // 定义（同时也是声明）
extern int b;        // 仅声明：b 定义在别处（别的文件或本文件后面）
```

> 一个变量**只能定义一次**，但可以声明多次。这是多文件编程的基础（第 15 章详述）。

### 10.3 声明语法

```c
int a;                   // 一个
int b, c, d;             // 同类型多个
int e = 1, f = 2;        // 带初始化
double x = 1.5, y;       // x 有初值，y 没有
```

> **陷阱**：`int a, b = 0;` 只有 `b` 被初始化，`a` 没有。

**C99 起允许在代码中间声明变量**，尽量**就近声明**（用时才定义）：

```c
for (int i = 0; i < 10; i++) {   // i 仅在循环内可见
    int sq = i * i;
    printf("%d\n", sq);
}
```

### 10.4 初始化

| 变量位置 | 未显式初始化时的值 |
|---|---|
| **局部变量**（自动存储期） | **不确定（垃圾值）** |
| **全局变量 / `static` 变量** | **自动初始化为 0** |

```c
#include <stdio.h>

int g;                       // 全局：自动为 0

int main(void)
{
    int a;                   // 局部：垃圾值
    static int s;            // static：为 0

    printf("%d\n", g);       // 0
    printf("%d\n", s);       // 0
    printf("%d\n", a);       // 不确定！读取未初始化变量是未定义行为
    return 0;
}
```

> **铁律**：**局部变量必须初始化后再使用。**

数组、结构体的初始化会在后续章节详述。

### 10.5 变量赋值与交换

```c
int a = 3, b = 5;

// 借助临时变量交换
int t = a;
a = b;
b = t;

// 不借助临时变量（算术法，有溢出风险，仅作了解）
a = a + b;
b = a - b;
a = a - b;

// 异或法（仅限整数，且 a、b 不能是同一个变量）
a ^= b;
b ^= a;
a ^= b;
```

## 11. 类型转换

### 11.1 隐式转换的几种场景

**① 赋值转换**：右边的值转成左边变量的类型

```c
int a = 3.99;          // a = 3（小数部分被截断，不是四舍五入）
double d = 5;          // d = 5.0
char c = 300;          // 实现定义（300 超出 char 范围，通常得 44）
unsigned u = -1;       // u = 4294967295
```

**② 整型提升（Integer Promotion）**：
在表达式中，**比 `int` 小的类型（`char`、`short`、`_Bool`）会先被提升为 `int`**（若 `int` 装得下）再运算。

```c
char a = 100, b = 100;
int c = a + b;         // 200，不会溢出，因为运算时 a、b 已提升为 int
char d = a + b;        // 200 存入 char（有符号）→ 溢出，通常得 -56
```

**③ 常规算术转换（Usual Arithmetic Conversions）**：
二元运算符两边类型不同时，向"更高等级"转换：

```
int  →  unsigned int  →  long  →  unsigned long  →  long long  →  unsigned long long
                                                                     ↓
                                                float → double → long double
```
（简记：**整型 → 浮点；窄 → 宽；有符号 → 无符号**。严格规则见标准，同宽度时无符号优先。）

```c
int a = 5;
double b = 2.0;
printf("%f\n", a / b);     // 2.500000  （a 被转成 double）
printf("%d\n", 5 / 2);     // 2         （整数除法，舍去小数）
printf("%f\n", 5 / 2);     // ✘ 未定义（格式符与参数类型不符）
printf("%f\n", 5 / 2.0);   // 2.500000
printf("%f\n", (double)5 / 2);  // 2.500000
```

### 11.2 有符号与无符号混合——最危险的转换

```c
#include <stdio.h>

int main(void)
{
    int a = -1;
    unsigned int b = 1;

    if (a < b)
        printf("a < b\n");
    else
        printf("a >= b\n");      // 实际输出这一行！
    return 0;
}
```
**原因**：`a` 被转换为 `unsigned int`，−1 变成 4294967295，大于 1。

另一经典陷阱：

```c
size_t n = 0;
for (int i = 10; i >= 0; i--) {
    if (i < n) { /* ... */ }     // i 被转为无符号，负数变巨大值
}
```

```c
// 常见的错误：求数组长度 - 1
size_t len = 0;
for (size_t i = 0; i <= len - 1; i++)    // len-1 变成 SIZE_MAX，几乎死循环
    ;
```

`gcc -Wall -Wextra -Wsign-compare` 可以提示这类问题。

### 11.3 强制类型转换

语法：`(目标类型) 表达式`

```c
int a = 7, b = 2;
double r1 = a / b;            // 3.0   先整数除，再转换
double r2 = (double)a / b;    // 3.5   先转换 a，再浮点除
double r3 = (double)(a / b);  // 3.0

double pi = 3.99;
int n = (int)pi;              // 3（截断）
int m = (int)(pi + 0.5);      // 4（简单四舍五入，仅对正数有效）

unsigned char uc = (unsigned char)-1;   // 255
```

> 强制转换优先级高于算术运算符，所以 `(double)a / b` 是先转 `a` 再除。

### 11.4 浮点与整型转换

```c
double d = 3.7;
int i = (int)d;          // 3
int j = (int)-3.7;       // -3（向零截断，不是向下取整）

double big = 1e20;
int k = (int)big;        // 未定义行为：值超出 int 范围
```
需要四舍五入时，使用 `<math.h>` 的 `round()`、`floor()`、`ceil()`、`trunc()`。

### 11.5 整数之间的转换总结

| 情形 | 结果 |
|---|---|
| 小 → 大（值不变） | 有符号：符号扩展；无符号：零扩展 |
| 大 → 小 | **截断高位**，保留低位 |
| 有符号 ↔ 无符号（同宽度） | **位模式不变，解释方式改变** |
| 无符号 ← 超范围值 | 取模 2ⁿ（**有明确定义**） |
| 有符号 ← 超范围值 | **实现定义**（通常也是截断） |

```c
short s = -1;               // 0xFFFF
int   i = s;                // 0xFFFFFFFF（符号扩展）→ -1
unsigned short us = 0xFFFF;
int   j = us;               // 0x0000FFFF（零扩展）→ 65535
```

## 12. 溢出

### 12.1 无符号溢出：定义明确（回绕）

```c
unsigned char c = 255;
c = c + 1;                  // 0
unsigned int u = UINT_MAX;
u++;                        // 0
```
结果 = 数学结果对 2ⁿ 取模。

### 12.2 有符号溢出：**未定义行为（UB）**

```c
#include <limits.h>
int x = INT_MAX;
x = x + 1;                  // UB！可能是 INT_MIN，也可能被编译器当作"不可能发生"而优化掉
```

**编译器优化带来的诡异现象**：

```c
int check(int x)
{
    return x + 1 > x;       // 编译器在 -O2 下可直接返回 1（因为认为有符号溢出不会发生）
}
```

**安全做法：先检查再运算**

```c
#include <limits.h>

int safe_add(int a, int b, int *out)
{
    if ((b > 0 && a > INT_MAX - b) ||
        (b < 0 && a < INT_MIN - b))
        return -1;           // 将会溢出
    *out = a + b;
    return 0;
}
```
GCC/Clang 也提供内建函数 `__builtin_add_overflow`；C23 提供 `<stdckdint.h>`。

### 12.3 浮点溢出

```c
float f = 3.4e38f * 10;     // +inf
double d = 1e-400;          // 下溢为 0
```

### 12.4 现实世界的教训

- **Ariane 5 火箭（1996）**：64 位浮点数转 16 位整数溢出，导致发射失败。
- **Y2038 问题**：32 位 `time_t` 在 2038 年溢出。

## 13. 进制与数据的二进制表示

### 13.1 进制转换

| 十进制 | 二进制 | 八进制 | 十六进制 |
|---|---|---|---|
| 0 | 0000 | 0 | 0 |
| 5 | 0101 | 5 | 5 |
| 9 | 1001 | 11 | 9 |
| 10 | 1010 | 12 | A |
| 15 | 1111 | 17 | F |
| 16 | 10000 | 20 | 10 |
| 255 | 1111 1111 | 377 | FF |

**十进制 → 二进制**：除 2 取余，倒序排列。
```
13 ÷ 2 = 6 …… 1
 6 ÷ 2 = 3 …… 0
 3 ÷ 2 = 1 …… 1
 1 ÷ 2 = 0 …… 1      →  13 = 1101₂
```

**二进制 → 十六进制**：每 4 位一组。
```
1101 0110 1010 → D 6 A → 0xD6A
```

**为什么程序员爱用十六进制**：1 个十六进制位 = 4 个二进制位，1 字节 = 2 个十六进制位，转换直观。

用 C 输出不同进制：

```c
int n = 255;
printf("%d\n", n);     // 255
printf("%o\n", n);     // 377
printf("%x\n", n);     // ff
printf("%#x\n", n);    // 0xff
printf("%X\n", n);     // FF
// C 标准库没有二进制格式符 %b（C23 的 printf 新增了 %b），可自己写：
for (int i = 7; i >= 0; i--)
    putchar((n >> i) & 1 ? '1' : '0');       // 11111111
```

### 13.2 整数的补码表示

计算机用**补码**存放有符号整数。理由：加减法可统一用加法器处理，且 0 只有一种表示。

**规则**（以 8 位为例）：
- 正数：补码 = 原码（二进制本身）；
- 负数：补码 = **原码符号位保持不变、其余位取反、末尾加 1**；等价地，**补码 = 对应正数按位取反再加 1**。

**例：求 −5 的 8 位补码**
```
5  的原码：0000 0101
按位取反：1111 1010
加 1     ：1111 1011   = 0xFB    → −5 的补码
```

**反过来：1111 1011 是多少？**
```
最高位为 1 → 负数
取反加 1 ：0000 0100 + 1 = 0000 0101 = 5   → 值为 −5
```

**8 位补码范围**：
```
0111 1111 = +127（最大）
1000 0000 = −128（最小）
1111 1111 = −1
0000 0000 = 0
```
范围为 −2ⁿ⁻¹ ~ 2ⁿ⁻¹−1，**负数比正数多一个**（所以 `-INT_MIN` 会溢出，`abs(INT_MIN)` 也是 UB）。

**验证补码加法：5 + (−5)**
```
  0000 0101
+ 1111 1011
-----------
 1 0000 0000     → 丢弃进位，结果 0000 0000 = 0 ✔
```

**三种码对比**

| | 原码 | 反码 | 补码 |
|---|---|---|---|
| +5 | 0000 0101 | 0000 0101 | 0000 0101 |
| −5 | 1000 0101 | 1111 1010 | 1111 1011 |
| 0 的表示 | +0、−0 两种 | +0、−0 两种 | **唯一** |

> 原码、反码是学习中的过渡概念，**现代计算机（以及 C23 标准）一律使用补码**。

用程序观察：
```c
#include <stdio.h>

int main(void)
{
    signed char a = -5;
    unsigned char b = (unsigned char)a;
    printf("%d  0x%02X  %u\n", a, b, b);     // -5  0xFB  251
    return 0;
}
```

### 13.3 浮点数：IEEE 754

浮点数用 **符号位 S + 指数 E + 尾数 M** 表示：

$$ (-1)^S \times 1.M \times 2^{E - bias} $$

| 类型 | 总位数 | S | E（指数） | M（尾数） | bias |
|---|---|---|---|---|---|
| `float` | 32 | 1 | 8 | 23 | 127 |
| `double` | 64 | 1 | 11 | 52 | 1023 |

**例：把 5.75 表示为 float**

1. 转二进制：`5.75 = 101.11₂`（0.75 = 0.5 + 0.25 = `.11`）
2. 规格化：`101.11₂ = 1.0111₂ × 2²`
3. 符号位 S = 0
4. 指数 E = 2 + 127 = 129 = `1000 0001`
5. 尾数 M = `0111` 后补 0 至 23 位：`011 1000 0000 0000 0000 0000`

```
S  EEEEEEEE  MMMMMMMMMMMMMMMMMMMMMMM
0  10000001  01110000000000000000000
→ 0100 0000 1011 1000 0000 0000 0000 0000 = 0x40B80000
```

用程序验证（利用 `memcpy`，避免违反严格别名规则）：

```c
#include <stdint.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    float f = 5.75f;
    uint32_t bits;
    memcpy(&bits, &f, sizeof bits);
    printf("0x%08X\n", bits);          // 0x40B80000
    return 0;
}
```

**为什么 0.1 无法精确表示？**
`0.1 = 0.0001100110011…₂`（无限循环），float/double 只能保存有限位，必然产生舍入误差。而 0.5、0.25、0.75 这类 2 的负幂之和，是可以精确表示的。

**特殊值**

| 指数位 | 尾数位 | 含义 |
|---|---|---|
| 全 0 | 全 0 | ±0 |
| 全 0 | 非 0 | 非规格化数（极小数） |
| 全 1 | 全 0 | ±Inf |
| 全 1 | 非 0 | NaN |

### 13.4 字节序预览（第 17 章详述）

多字节数据在内存中存放的字节顺序：
- **小端（Little-endian）**：低位字节在低地址（x86、ARM 多数情况）；
- **大端（Big-endian）**：高位字节在低地址（网络字节序）。

```c
#include <stdio.h>

int main(void)
{
    unsigned int x = 0x12345678;
    unsigned char *p = (unsigned char *)&x;
    printf("%02X %02X %02X %02X\n", p[0], p[1], p[2], p[3]);
    // 小端机器输出：78 56 34 12
    return 0;
}
```

## 14. 本章小结与练习

### 14.1 知识要点回顾

| 主题 | 关键点 |
|---|---|
| 标识符 | 字母/数字/下划线，不能数字开头，区分大小写，避开关键字与保留名 |
| 整型 | `char/short/int/long/long long`，大小依平台；`long` 在 Win64 与 Linux64 不同 |
| 有/无符号 | 无符号回绕有定义，有符号溢出是 UB；混用时有符号被转成无符号 |
| 浮点 | 默认 `double`；有精度误差，不能直接用 `==` 比较 |
| `char` | 本质是小整数，`'A'` = 65；字符常量类型为 `int` |
| `_Bool` | 非零转 1 |
| `sizeof` | 返回 `size_t`，用 `%zu` |
| 极限值 | `<limits.h>`、`<float.h>`、`<stdint.h>` |
| 定长类型 | `int32_t`、`uint8_t` 等，输出用 `PRId32` 等宏 |
| 字面量 | 前缀（`0`、`0x`）与后缀（`U/L/LL/f`） |
| 常量 | `#define`（文本替换）、`const`（只读变量）、`enum`（整型常量） |
| 初始化 | 局部变量不初始化为垃圾值，全局/静态变量默认 0 |
| 类型转换 | 整型提升、常规算术转换、强制转换；整数除法舍去小数 |
| 底层表示 | 补码、IEEE 754、进制转换 |

### 14.2 易错点清单

1. `int a = 010;` 是 8，不是 10。
2. `5 / 2` 是 2；要得到 2.5 写 `5 / 2.0` 或 `(double)5 / 2`。
3. `printf("%d", 3.5)`、`printf("%f", 3)` 都是未定义行为。
4. `double` 读入用 `scanf("%lf")`，输出用 `%f` 或 `%lf` 均可。
5. `0.1 + 0.2 == 0.3` 为假。
6. `unsigned` 变量做 `i >= 0` 恒真；`-1 < 1u` 为假。
7. 局部变量不初始化就使用 → 垃圾值（UB）。
8. `#define N 3+4` 要加括号；`#define` 末尾不要加分号。
9. `char` 是否有符号取决于平台。
10. `INT_MAX + 1` 是未定义行为。

### 14.3 练习题

**基础**
1. 编写程序，输出所有基本类型的 `sizeof`，并输出 `INT_MAX`、`INT_MIN`、`UINT_MAX`、`DBL_MAX`、`DBL_EPSILON`。
2. 定义 `int a = 7, b = 2;`，分别输出 `a/b`、`a%b`、`(double)a/b`、`a/(double)b`、`(double)(a/b)`。
3. 将字符 `'q'` 转为大写，将字符 `'8'` 转为整数 8。
4. 输出 `printf("%d %o %x %X %#x\n", 255, 255, 255, 255, 255);` 并解释每项。

**理解**
5. 预测输出（先想再运行）：
   ```c
   unsigned char c = 250;
   c += 10;
   printf("%d\n", c);

   signed char s = 127;
   s++;
   printf("%d\n", s);       // 注意：有符号 char 提升到 int 后赋回，结果实现定义

   int a = -1;
   unsigned b = 1;
   printf("%d\n", a < b);

   printf("%d\n", 'a' + 1);
   printf("%c\n", 'a' + 1);
   printf("%d\n", sizeof('a'));
   ```
6. 写一个 `is_equal(double a, double b)`，使用 `DBL_EPSILON` 进行近似比较，并测试 `0.1+0.2` 与 `0.3`。
7. 手工计算：−18 的 8 位补码是什么？`1010 1100` 作为有符号 8 位数的值是多少？

**进阶**
8. 编写函数，把一个 `uint32_t` 以二进制形式输出（每 4 位用空格隔开）。
9. 用 `memcpy` 把 `float` 的位模式取出，分别打印符号位、指数位、尾数位，验证 `-0.15625f` 的结果。（提示：`-0.15625 = -1.25 × 2⁻³`，E = 124）
10. 写出 `safe_add`、`safe_mul` 函数，在乘法/加法溢出时返回错误码，并用 `-fsanitize=undefined` 验证未检查版本会被报告。
11. 设计 `enum` 表示一周七天，并写函数返回"明天"，处理周日到周一的回绕。

### 14.4 参考答案（部分）

**第 2 题**
```c
#include <stdio.h>

int main(void)
{
    int a = 7, b = 2;
    printf("%d\n",  a / b);            // 3
    printf("%d\n",  a % b);            // 1
    printf("%f\n",  (double)a / b);    // 3.500000
    printf("%f\n",  a / (double)b);    // 3.500000
    printf("%f\n",  (double)(a / b));  // 3.000000
    return 0;
}
```

**第 5 题**：`4`、`-128`（典型实现）、`0`、`98`、`b`、`4`。

**第 7 题**：18 = `0001 0010` → 取反 `1110 1101` → 加 1 → `1110 1110`（0xEE）。`1010 1100`：最高位为 1，取反加 1 得 `0101 0100` = 84，故值为 −84。

**第 8 题（参考）**
```c
#include <stdint.h>
#include <stdio.h>

void print_bin(uint32_t x)
{
    for (int i = 31; i >= 0; i--) {
        putchar((x >> i) & 1 ? '1' : '0');
        if (i % 4 == 0 && i != 0) putchar(' ');
    }
    putchar('\n');
}

int main(void)
{
    print_bin(0xDEADBEEF);   // 1101 1110 1010 1101 1011 1110 1110 1111
    return 0;
}
```

**第 9 题提示**：`-0.15625f` 的位模式为 `0xBE200000`：S=1，E=`0111 1100`(124)，M=`010 0000 0000 0000 0000 0000`。
