## 1. 为什么需要函数

函数是**可重复调用的、有名字的代码块**。

| 作用 | 说明 |
|---|---|
| **复用** | 同一段逻辑写一次，到处调用 |
| **抽象** | 调用者只需知道"做什么"，不必关心"怎么做" |
| **分解** | 把大问题拆成小问题，各个击破 |
| **便于测试与维护** | 每个函数可以单独验证、修改 |
| **模块化** | 多个函数组织成文件、库（第 15 章） |

```c
// 没有函数：重复且难维护
printf("%d\n", a > b ? a : b);
printf("%d\n", c > d ? c : d);

// 有函数：
int max2(int x, int y) { return x > y ? x : y; }
printf("%d\n", max2(a, b));
printf("%d\n", max2(c, d));
```

C 程序的本质就是**一组函数**，`main` 是入口。标准库（`printf`、`strlen`）也是函数。

## 2. 函数的定义、声明与调用

### 2.1 定义

```c
返回类型 函数名(参数列表)
{
    函数体
}
```

```c
int add(int a, int b)        // 返回 int，两个 int 形参
{
    int sum = a + b;
    return sum;              // 把结果交给调用者
}

void say_hello(void)         // 无返回值、无参数
{
    puts("Hello");
}
```

| 部分 | 说明 |
|---|---|
| 返回类型 | 返回值的类型；没有返回值写 `void` |
| 函数名 | 标识符，遵循命名规则 |
| 形参（形式参数） | 函数内部使用的变量，调用时被赋值 |
| `return` | 结束函数并返回值 |

> **术语**：定义时的参数叫**形参**，调用时传入的叫**实参**。

### 2.2 调用

```c
int r = add(3, 4);       // 实参 3、4；返回值 7 赋给 r
say_hello();
printf("%d\n", add(add(1, 2), 3));    // 函数调用可嵌套，结果 6
```

### 2.3 声明（函数原型）

C 要求：**函数在使用前必须已经声明或定义**，编译器才知道它的参数和返回类型。

```c
#include <stdio.h>

int add(int a, int b);          // 函数声明（原型），以分号结束；参数名可省：int add(int, int);

int main(void)
{
    printf("%d\n", add(3, 4));  // 使用在前
    return 0;
}

int add(int a, int b)           // 定义在后
{
    return a + b;
}
```

- **声明**：告诉编译器"这个函数存在，参数与返回类型如下"；
- **定义**：给出函数体；
- 声明可以多次，定义只能一次；
- 实际项目中，声明放在**头文件**（`.h`），定义放在 `.c`。

### 2.4 `()` 与 `(void)` 的区别

```c
int f();         // 旧式：参数未指定（可传任意个参数，不检查！）  C23 起等价于 (void)
int g(void);     // 明确：无参数
```
**没有参数时一律写 `(void)`**。

### 2.5 隐式声明：已被淘汰

C89 允许调用未声明的函数（编译器假定返回 `int`），C99 起非法，GCC 14+ 默认报错。**务必先声明再使用，开启 `-Wall`。**

### 2.6 几个事实

- C **没有函数重载**：同名函数只能有一个；
- C **没有默认参数**；
- C 标准**不允许函数嵌套定义**（GCC 有扩展，不要用）；
- 函数名不能与变量同名同作用域。

### 2.7 例：几个小函数

```c
#include <stdbool.h>
#include <stdio.h>

bool is_even(int n)      { return n % 2 == 0; }
int  square(int x)       { return x * x; }
double average(int a, int b) { return (a + b) / 2.0; }

void print_line(char ch, int n)
{
    for (int i = 0; i < n; i++) putchar(ch);
    putchar('\n');
}

int main(void)
{
    print_line('=', 20);
    printf("%d %d %.1f\n", is_even(4), square(5), average(3, 4));  // 1 25 3.5
    print_line('=', 20);
    return 0;
}
```

## 3. 参数传递：值传递

**C 只有值传递**：调用时，实参的**值被复制**给形参，函数内部修改形参**不会影响**实参。

```c
#include <stdio.h>

void try_swap(int a, int b)
{
    int t = a; a = b; b = t;
    printf("函数内：a=%d b=%d\n", a, b);    // 交换了
}

int main(void)
{
    int x = 1, y = 2;
    try_swap(x, y);
    printf("函数外：x=%d y=%d\n", x, y);    // 仍是 1 2
    return 0;
}
```

```
main:      x [1]   y [2]
               ↓复制   ↓复制
try_swap:  a [1]   b [2]    ← 另外两块内存，改它们不影响 x、y
```

### 3.1 想修改调用者的变量：传指针（第 8 章详述）

```c
void swap(int *a, int *b)
{
    int t = *a; *a = *b; *b = t;
}
// 调用：swap(&x, &y);
```
其实传的仍是"值"——**地址的值**被复制，但通过地址能访问到原变量。

### 3.2 数组作为参数：退化为指针

```c
void fill(int a[], int n)        // 等价于 int *a
{
    for (int i = 0; i < n; i++) a[i] = 0;    // 能修改调用者的数组！
}
```
传数组其实传的是**首元素地址**，数组内容不会被复制，所以能被修改。长度信息丢失，必须另传 `n`（第 7 章详述）。

### 3.3 结构体：整体复制

结构体按值传递会复制全部成员，大结构体开销大，通常传指针（第 10 章）。

### 3.4 实参求值顺序

```c
f(a(), b());        // a、b 的调用顺序未指定
f(i++, i++);        // 未定义行为
```

## 4. 返回值

### 4.1 return 的作用

```c
int abs_val(int x)
{
    if (x < 0) return -x;       // 可以有多个 return
    return x;
}
```
- `return 表达式;` 先把值转换成返回类型，再返回；
- `void` 函数可用 `return;` 提前结束，但**不能带值**；
- 非 `void` 函数的**所有路径都应有 return**，否则若调用者使用了返回值，行为未定义（`-Wall` 会警告 `control reaches end of non-void function`）。

```c
int sign(int x)
{
    if (x > 0) return 1;
    if (x < 0) return -1;
    // ✘ x == 0 时没有 return
}
```

### 4.2 一次返回多个结果

C 函数只能返回一个值，需要多个时：
1. **输出参数**（指针）：
   ```c
   void min_max(const int *a, int n, int *min, int *max)
   {
       *min = *max = a[0];
       for (int i = 1; i < n; i++) {
           if (a[i] < *min) *min = a[i];
           if (a[i] > *max) *max = a[i];
       }
   }
   ```
2. 返回**结构体**（第 10 章）；
3. 返回状态码 + 输出参数（最常见）：
   ```c
   int divide(int a, int b, int *result)    // 成功返回 0，失败返回 -1
   {
       if (b == 0) return -1;
       *result = a / b;
       return 0;
   }
   ```

### 4.3 忽略返回值

```c
printf("hi\n");       // printf 返回字符数，常被忽略
(void)printf("hi\n"); // 显式表示"我有意忽略"
```
但 `malloc`、`fopen`、`scanf` 等的返回值**必须检查**。

### 4.4 不要返回局部变量的地址

```c
int *bad(void)
{
    int x = 10;
    return &x;            // ✘ 函数返回后 x 的内存已回收，指针悬空
}
```
可返回：`static` 变量地址、堆内存（`malloc`）、调用者传入的指针（第 8、11 章）。

## 5. 递归

**递归**：函数直接或间接地**调用自身**。

### 5.1 两要素

1. **终止条件（基例）**：什么情况下不再递归；
2. **递归关系**：把问题化为**规模更小**的同类问题。

缺少终止条件或没有向终止条件逼近 → 无限递归 → **栈溢出**。

### 5.2 经典例子

**① 阶乘** `n! = n × (n-1)!`，`0! = 1`
```c
unsigned long long fact(int n)
{
    if (n <= 1) return 1;            // 终止条件
    return n * fact(n - 1);          // 递归关系
}
```
调用 `fact(4)` 的展开：
```
fact(4) = 4 * fact(3)
                = 3 * fact(2)
                        = 2 * fact(1)
                                = 1          ← 到达终止条件
                        = 2 * 1 = 2          ← 逐层返回
                = 3 * 2 = 6
        = 4 * 6 = 24
```

**② 最大公约数**
```c
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
```

**③ 进制转换（利用"先递归后输出"得到逆序）**
```c
void print_bin(unsigned n)
{
    if (n > 1) print_bin(n / 2);       // 先输出高位
    putchar('0' + n % 2);
}
// print_bin(13) → 1101
```

**④ 快速幂：O(log n)**
```c
long long power(long long x, int n)
{
    if (n == 0) return 1;
    long long half = power(x, n / 2);
    return n % 2 ? half * half * x : half * half;
}
// power(2, 10) = 1024
```

**⑤ 汉诺塔**：把 n 个盘从 `from` 借助 `via` 移到 `to`

```c
#include <stdio.h>

void hanoi(int n, char from, char via, char to)
{
    if (n == 0) return;
    hanoi(n - 1, from, to, via);                  // 先把上面 n-1 个移到辅助柱
    printf("盘 %d: %c -> %c\n", n, from, to);     // 移动最大的盘
    hanoi(n - 1, via, from, to);                  // 再把 n-1 个从辅助柱移到目标柱
}

int main(void)
{
    hanoi(3, 'A', 'B', 'C');       // 共 2^3 - 1 = 7 步
    return 0;
}
```
移动次数为 `2ⁿ − 1`，n = 64 时需要约 1.8×10¹⁹ 步。

**⑥ 二分查找（递归版）、全排列、八皇后、归并/快速排序**：后续章节涉及。

### 5.3 栈帧：递归的底层原理

每次函数调用，系统在**调用栈**上分配一块**栈帧**，保存：

```
高地址
┌───────────────────┐
│  调用者的栈帧       │
├───────────────────┤
│  实参（部分平台经寄存器传）│
│  返回地址           │ ← 函数返回后继续执行的位置
│  保存的栈基址 rbp   │
│  局部变量           │
│  ……               │
└───────────────────┘ ← 栈顶（x86 上向低地址增长）
低地址
```

`fact(3)` 递归过程中，栈上会同时存在 `fact(3)`、`fact(2)`、`fact(1)` 三个栈帧，各有自己的 `n`。返回时栈帧依次弹出。

**用 gdb 观察**：`bt` 命令可显示整条调用链：
```
#0  fact (n=1) at fact.c:4
#1  fact (n=2) at fact.c:5
#2  fact (n=3) at fact.c:5
#3  main () at fact.c:10
```

### 5.4 栈溢出

栈空间有限（Linux 默认 8 MB，Windows 默认 1 MB）。

```c
int f(int n) { return f(n + 1) + 1; }   // 无终止条件 → 段错误（stack overflow）
```
递归深度太大（如递归遍历 100 万节点的链表）也会溢出。大数组不要放在栈上（局部大数组 `int a[10000000]` 同样会爆栈）。

### 5.5 递归的效率问题：斐波那契

```c
int fib(int n) { return n <= 2 ? 1 : fib(n - 1) + fib(n - 2); }
```
```
              fib(5)
            /        \
        fib(4)       fib(3)
       /     \       /    \
   fib(3)  fib(2) fib(2) fib(1)
   /   \
fib(2) fib(1)           ← 大量重复计算
```
时间复杂度 O(2ⁿ)，`fib(40)` 约需 3.3 亿次调用。

**改进 ① 迭代**（O(n)）
```c
long long fib_iter(int n)
{
    long long a = 1, b = 1;
    for (int i = 3; i <= n; i++) { long long t = a + b; a = b; b = t; }
    return b;
}
```
**改进 ② 记忆化**（把已算过的结果存起来）
```c
long long memo[100];                      // 全局数组，初值全 0

long long fib_memo(int n)
{
    if (n <= 2) return 1;
    if (memo[n] != 0) return memo[n];
    return memo[n] = fib_memo(n - 1) + fib_memo(n - 2);
}
```

### 5.6 递归 vs 迭代

| | 递归 | 迭代 |
|---|---|---|
| 代码 | 简洁，贴近数学定义（树、分治、回溯） | 稍繁琐 |
| 开销 | 函数调用 + 栈空间 | 小 |
| 风险 | 栈溢出、重复计算 | 无 |
| 适用 | 树/图遍历、分治、回溯、递归定义的结构 | 简单线性重复 |

### 5.7 尾递归

递归调用是函数的**最后一个操作**时称**尾递归**，编译器（`-O2`）常可将其优化成循环，不增加栈深。**标准不保证**，不要依赖。

```c
long long fact_tail(int n, long long acc)
{
    if (n <= 1) return acc;
    return fact_tail(n - 1, acc * n);      // 尾调用
}
// 调用：fact_tail(5, 1)
```

### 5.8 间接递归（相互递归）

```c
int is_odd(int n);                         // 需要先声明
int is_even(int n) { return n == 0 ? 1 : is_odd(n - 1); }
int is_odd(int n)  { return n == 0 ? 0 : is_even(n - 1); }
```

## 6. 作用域

**作用域**：标识符在程序中**可以被访问的范围**。

| 作用域 | 范围 | 例子 |
|---|---|---|
| **块作用域** | 从声明处到所在 `{}` 结束 | 局部变量、`for` 中声明的变量 |
| **函数作用域** | 整个函数（**只有标签 label**） | `goto` 标签 |
| **文件作用域** | 从声明处到文件结束 | 全局变量、函数名 |
| **函数原型作用域** | 函数声明的参数列表内 | `int f(int n, int a[n]);` |

### 6.1 局部变量

```c
void f(void)
{
    int x = 1;                  // 局部变量，只能在 f 内使用
    {
        int y = 2;              // 内层块
        x += y;
    }
    // y 在这里不可见
}

for (int i = 0; i < 3; i++) { }
// i 在这里不可见（C99）
```

### 6.2 全局变量

在所有函数之外定义，整个文件（乃至整个程序）可见；**自动初始化为 0**。

```c
int g_count = 0;           // 全局变量

void inc(void) { g_count++; }
```
缺点：任何函数都能改，难追踪、难测试、线程不安全。**少用，必须用时加 `g_` 前缀或限制为 `static`。**

### 6.3 变量遮蔽（Shadowing）

内层同名变量会**遮蔽**外层：

```c
#include <stdio.h>

int x = 10;                     // 全局

int main(void)
{
    printf("%d\n", x);          // 10
    int x = 20;                 // 局部遮蔽全局
    printf("%d\n", x);          // 20
    {
        int x = 30;             // 内层遮蔽外层
        printf("%d\n", x);      // 30
    }
    printf("%d\n", x);          // 20
    return 0;
}
```
`-Wshadow` 可检测遮蔽，建议避免。

### 6.4 形参的作用域

形参属于函数体的最外层块，在函数体内不能再用同名变量在同一层声明：

```c
void f(int n)
{
    int n = 3;        // ✘ 重定义
}
```

### 6.5 初始化与"垃圾值"

| 变量 | 默认初值 |
|---|---|
| 局部（自动）变量 | **不确定** |
| 全局、`static` 变量 | **0** |

## 7. 存储类别

存储类别说明符决定变量的**存储位置、生存期和链接性**。

### 7.1 auto

局部变量的默认类别，几乎不写。（C23 中 `auto` 另有类型推导含义。）

### 7.2 register

建议编译器把变量放进寄存器。现代编译器自行优化，**基本被忽略**；**不能对 `register` 变量取地址**。

### 7.3 static

**两种完全不同的含义**：

**① 修饰局部变量：延长生存期**——变量存放在静态区，**只初始化一次**，函数返回后值仍保留。

```c
#include <stdio.h>

int next_id(void)
{
    static int id = 0;      // 只在第一次调用时初始化（必须是常量表达式）
    return ++id;
}

int main(void)
{
    int a = next_id();
    int b = next_id();
    int c = next_id();
    printf("%d %d %d\n", a, b, c);      // 1 2 3
    return 0;
}
```
> 不要写成 `printf("%d %d %d\n", next_id(), next_id(), next_id());`：实参的求值顺序未指定，输出可能是 `3 2 1`。

**② 修饰全局变量或函数：限制链接性**——只在**本文件**可见（内部链接），避免命名冲突。

```c
static int counter = 0;                // 仅本 .c 文件可见
static void helper(void) { ... }       // 仅本 .c 文件可见
```
**良好的模块化习惯：不对外公开的函数和全局变量一律加 `static`。**

### 7.4 extern

声明"这个变量/函数在别处定义"（不分配内存）。

```c
// config.c
int g_level = 3;               // 定义

// main.c
#include <stdio.h>
extern int g_level;            // 声明：引用其他文件的全局变量

int main(void)
{
    printf("%d\n", g_level);
    return 0;
}
```
```bash
gcc main.c config.c -o app
```
函数声明默认带有 `extern`（可省略）。

### 7.5 多文件示例：计数器模块

```c
// counter.h
#ifndef COUNTER_H
#define COUNTER_H
void counter_inc(void);
int  counter_get(void);
#endif
```
```c
// counter.c
#include "counter.h"

static int count = 0;                  // 私有：外部不可直接访问

void counter_inc(void) { count++; }
int  counter_get(void) { return count; }
```
```c
// main.c
#include <stdio.h>
#include "counter.h"

int main(void)
{
    counter_inc(); counter_inc();
    printf("%d\n", counter_get());     // 2
    return 0;
}
```

## 8. 生存期与链接性

### 8.1 存储期（生存期）

| 存储期 | 何时创建/销毁 | 典型对象 |
|---|---|---|
| **自动** | 进入块时创建，离开时销毁 | 普通局部变量、形参 |
| **静态** | 程序开始到结束 | 全局变量、`static` 变量 |
| **动态（分配）** | `malloc` 到 `free` | 堆内存（第 11 章） |
| **线程** | 线程开始到结束 | `_Thread_local` 变量 |

### 8.2 链接性

| 链接 | 含义 | 例子 |
|---|---|---|
| **外部链接** | 整个程序（所有文件）共享同一个实体 | 全局变量、非 `static` 函数 |
| **内部链接** | 仅本文件内共享 | `static` 全局变量/函数 |
| **无链接** | 只属于自己的作用域 | 局部变量、形参 |

### 8.3 汇总表

| 声明位置与修饰 | 作用域 | 存储期 | 链接性 | 默认初值 |
|---|---|---|---|---|
| 函数内，普通 | 块 | 自动 | 无 | 不确定 |
| 函数内，`static` | 块 | 静态 | 无 | 0 |
| 函数外，普通 | 文件 | 静态 | 外部 | 0 |
| 函数外，`static` | 文件 | 静态 | 内部 | 0 |
| 函数内/外，`extern` | 块/文件 | 静态 | 外部（引用） | —— |

### 8.4 内存区域对应（第 11 章详述）

```
高地址  ┌──────────┐
        │   栈      │ ← 局部变量、形参、返回地址
        │   ↓       │
        │          │
        │   ↑       │
        │   堆      │ ← malloc 分配
        ├──────────┤
        │ .bss     │ ← 未初始化 / 初值 0 的全局、静态变量
        │ .data    │ ← 已初始化的全局、静态变量
        │ .rodata  │ ← 字符串字面量、const 全局
        │ .text    │ ← 代码
低地址  └──────────┘
```

## 9. inline 与 _Noreturn

### 9.1 inline 内联函数（C99）

提示编译器**把函数体展开到调用处**，省去函数调用开销，适合**很短、频繁调用**的函数。

```c
static inline int max2(int a, int b) { return a > b ? a : b; }
```

- 只是**建议**，编译器可以忽略（开启优化时它自己会判断）；
- C 的 `inline` 语义复杂（单独的 `inline` 需要在某个 `.c` 提供外部定义），**头文件里的内联函数写成 `static inline` 最稳妥**；
- 与宏函数相比，有类型检查、无重复求值副作用。

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))
MAX(i++, j++)        // ✘ 参数被求值两次，副作用重复
max2(i++, j++)       // ✔ 内联函数参数只求值一次
```

### 9.2 _Noreturn（C11）

表明函数**永不返回**（如 `exit`、`abort`），帮助编译器优化与警告。

```c
#include <stdlib.h>
#include <stdnoreturn.h>        // 提供 noreturn 宏

noreturn void fatal(const char *msg)
{
    fprintf(stderr, "fatal: %s\n", msg);
    exit(EXIT_FAILURE);
}
```
C23 改用属性写法 `[[noreturn]] void fatal(...)`。

## 10. 可变参数函数

`printf` 能接受任意数量参数，就是可变参数函数。声明：

```c
int printf(const char *fmt, ...);        // ... 表示可变参数
```

### 10.1 stdarg.h 的用法

| 宏/类型 | 作用 |
|---|---|
| `va_list` | 保存可变参数的类型 |
| `va_start(ap, last)` | 初始化，`last` 是最后一个**具名**参数 |
| `va_arg(ap, type)` | 取下一个参数，并指定其类型 |
| `va_end(ap)` | 清理 |
| `va_copy(dst, src)` | 复制 `va_list`（C99） |

### 10.2 例 ①：求若干个整数之和（先给个数）

```c
#include <stdarg.h>
#include <stdio.h>

int sum(int n, ...)
{
    va_list ap;
    va_start(ap, n);
    int s = 0;
    for (int i = 0; i < n; i++)
        s += va_arg(ap, int);
    va_end(ap);
    return s;
}

int main(void)
{
    printf("%d\n", sum(3, 10, 20, 30));       // 60
    printf("%d\n", sum(5, 1, 2, 3, 4, 5));    // 15
    return 0;
}
```

### 10.3 例 ②：平均值（注意类型！）

```c
double average(int n, ...)
{
    va_list ap;
    va_start(ap, n);
    double s = 0;
    for (int i = 0; i < n; i++) s += va_arg(ap, double);
    va_end(ap);
    return n > 0 ? s / n : 0;
}

average(3, 1.0, 2.0, 3.0);     // ✔ 2.0
average(3, 1, 2, 3);           // ✘ 传的是 int，却按 double 读取 → 未定义行为
```

### 10.4 例 ③：包装 printf（日志函数）

```c
#include <stdarg.h>
#include <stdio.h>

void log_msg(const char *level, const char *fmt, ...)
{
    va_list ap;
    va_start(ap, fmt);
    fprintf(stderr, "[%s] ", level);
    vfprintf(stderr, fmt, ap);        // v 系列函数接收 va_list
    fputc('\n', stderr);
    va_end(ap);
}

// log_msg("INFO", "user %s logged in, id=%d", "tom", 42);
```
`vprintf / vfprintf / vsnprintf` 是转发可变参数的标准方式。

### 10.5 重要规则与陷阱

1. 被调用函数**无法知道**实际传了多少个参数、什么类型，必须靠约定：**个数参数**、**哨兵值**（如以 `-1` 或 `NULL` 结尾）、**格式串**（如 `printf`）；
2. **默认实参提升**：`char`、`short` → `int`；`float` → `double`。所以 `va_arg(ap, char)` / `va_arg(ap, float)` 是错的，应写 `int` / `double`；
3. `va_arg` 的类型必须与实际传入类型一致，否则 UB；
4. 至少需要一个具名参数（C23 起不再要求）；
5. 可变参数**没有类型检查**，易出错；GCC 可用 `__attribute__((format(printf, 1, 2)))` 让编译器检查格式串。

## 11. main 函数的参数与返回值

### 11.1 标准形式

```c
int main(void)
int main(int argc, char *argv[])      // 或 char **argv
```

| 参数 | 含义 |
|---|---|
| `argc` | 命令行参数个数（含程序名） |
| `argv` | 字符串数组，`argv[0]` 通常是程序名，`argv[argc]` 为 `NULL` |

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("argc = %d\n", argc);
    for (int i = 0; i < argc; i++)
        printf("argv[%d] = %s\n", i, argv[i]);
    return 0;
}
```
```bash
$ ./demo hello 42 "a b"
argc = 4
argv[0] = ./demo
argv[1] = hello
argv[2] = 42
argv[3] = a b
```

### 11.2 实战：命令行加法器

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 3) {
        fprintf(stderr, "用法：%s <整数> <整数>\n", argv[0]);
        return 1;
    }

    char *end;
    long a = strtol(argv[1], &end, 10);
    if (*end != '\0') { fprintf(stderr, "无效数字：%s\n", argv[1]); return 1; }
    long b = strtol(argv[2], &end, 10);
    if (*end != '\0') { fprintf(stderr, "无效数字：%s\n", argv[2]); return 1; }

    printf("%ld\n", a + b);
    return 0;
}
```
命令行参数永远是**字符串**，需用 `strtol / strtod` 转换（第 9 章）。复杂选项解析可用 POSIX 的 `getopt`。

### 11.3 返回值

- `main` 返回值是**程序的退出状态**，交给操作系统/调用者（shell 的 `$?`）；
- `0` 或 `EXIT_SUCCESS` 表示成功，非零（如 `EXIT_FAILURE`）表示失败；
- `return n;` 在 `main` 中等价于 `exit(n);`；
- 在 C99 及以后，`main` 末尾省略 `return` 等价于 `return 0;`。

```c
#include <stdlib.h>
if (error) exit(EXIT_FAILURE);     // 任何函数里都可以直接退出整个程序
```

## 12. 函数设计原则

1. **单一职责**：一个函数只做一件事，名字应能说明（动词开头：`read_config`、`is_prime`、`compute_area`）；
2. **短小**：一屏内能看完；过长就拆分；
3. **参数不要太多**（≤ 4 个为宜），多了用结构体；
4. **只读参数加 `const`**（指针参数）：`size_t my_strlen(const char *s)`；
5. **明确的错误处理约定**：返回错误码，或 `NULL`，并用注释说明；
6. **避免依赖全局变量**，让函数成为"输入 → 输出"的纯粹映射，便于测试；
7. **先写原型**：把声明放头文件，作为模块接口；
8. **检查输入参数**：对来自外部的指针/长度做校验（或用 `assert` 断言内部约定）；
9. **命名一致**：如 `module_action`（`list_push`、`list_pop`）。

示例：
```c
/* 在数组 a[0..n-1] 中查找 key，找到返回下标，找不到返回 -1。 */
int find_index(const int *a, int n, int key)
{
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}
```

## 13. 常见错误

| 错误 | 现象 | 修正 |
|---|---|---|
| 调用前未声明 | 隐式声明警告/错误 | 加原型或 `#include` |
| 原型与定义不一致 | 链接/运行错误 | 保持同步，通过头文件共享 |
| 非 void 函数缺 `return` | 返回垃圾值 | 保证所有路径返回 |
| 返回局部变量地址 | 悬空指针 | 改用 static/堆/输出参数 |
| 以为形参修改会影响实参 | 值未变 | 传指针 |
| `sizeof(arr)` 用在数组形参上 | 得到指针大小 | 另传长度 |
| 无限递归 / 递归过深 | 栈溢出 | 保证终止条件；改迭代 |
| 可变参数类型不匹配 | UB | 按提升后类型取（`int`、`double`） |
| 头文件里定义全局变量 | 重复定义链接错误 | 头文件只 `extern` 声明，`.c` 中定义 |
| 局部大数组 | 栈溢出 | 用 `static` 或堆 |
| `static` 局部变量用非常量初始化 | 编译错误 | 只能用常量表达式 |
| 宏函数参数副作用 | 重复求值 | 用 `static inline` 函数 |

## 14. 本章小结与练习

### 14.1 知识要点回顾

- 函数 = 返回类型 + 名字 + 形参 + 函数体；使用前必须**声明**；无参数写 `(void)`。
- **C 只有值传递**；要修改外部变量就传地址；数组传参会退化为指针。
- 返回值：所有路径都要 `return`；**不要返回局部变量地址**。
- 递归 = 终止条件 + 递归关系；底层靠栈帧；注意栈溢出与重复计算。
- 作用域：块 / 文件 / 函数 / 函数原型；内层遮蔽外层。
- `static`：局部（持久）；全局/函数（内部链接）；`extern`：引用外部定义。
- 存储期：自动、静态、动态、线程；链接性：外部、内部、无。
- 可变参数：`va_list / va_start / va_arg / va_end`；类型被提升；无类型检查。
- `main(int argc, char *argv[])`：命令行参数是字符串；返回值是退出状态。

### 14.2 练习题

**基础**
1. 编写函数 `int max3(int a, int b, int c)`，返回三者最大值。
2. 编写 `bool is_prime(int n)`，并用它输出 1~100 的素数。
3. 编写 `int digit_sum(int n)`，返回各位数字之和（用循环与递归各写一次）。
4. 编写 `void print_triangle(int n, char ch)` 输出 n 行三角形。
5. 写一个命令行程序，把所有参数相加（`./sum 1 2 3` 输出 6），参数非法时报错。

**理解**
6. 预测输出：
   ```c
   int f(int x) { static int c = 0; c += x; return c; }
   int main(void) {
       int a = f(1);
       int b = f(2);
       int c = f(3);
       printf("%d %d %d\n", a, b, c);
   }
   ```
7. 指出下列代码的错误：
   ```c
   int *get(void) { int arr[3] = {1, 2, 3}; return arr; }
   void inc(int n) { n++; }
   int sq(int x) { if (x > 0) return x * x; }
   ```
8. 手画 `fact(4)` 调用过程中栈帧的变化。
9. 为什么 `average(3, 1, 2, 3)`（`average` 内用 `va_arg(ap, double)`）会出错？

**进阶**
10. 用递归实现：求数组之和、反转字符串、判断回文串、求 `C(n, m)` 组合数（`C(n,m) = C(n-1,m-1) + C(n-1,m)`）。
11. 计算 `fib(45)`：分别用朴素递归、记忆化递归、迭代实现，并用 `clock()` 比较耗时。
12. 实现全排列：输出 `1 2 3` 的所有排列（提示：交换法递归）。
13. 实现 `int my_printf(const char *fmt, ...)`，支持 `%d %c %s %%`（用 `putchar` 输出，不使用 `printf`）。
14. 设计一个 `stack` 模块（多文件）：`stack_push / stack_pop / stack_empty`，内部数组用 `static` 隐藏。
15. 用递归解决"爬楼梯"：每次走 1 或 2 阶，n 阶楼梯有多少种走法？并与斐波那契比较。

### 14.3 参考答案（部分）

**第 6 题**：`1 3 6`。`static` 局部变量 `c` 只初始化一次，累加：1 → 3 → 6。

**第 7 题**：
- `get` 返回局部数组的地址，函数返回后失效；
- `inc` 修改的是形参副本，无法影响实参，应传指针：`void inc(int *n) { (*n)++; }`；
- `sq` 在 `x <= 0` 时没有 `return`。

**第 9 题**：`1, 2, 3` 是 `int` 常量，而 `va_arg(ap, double)` 按 `double` 读取，类型与大小都不一致，是未定义行为。应传 `1.0, 2.0, 3.0`。

**第 12 题（参考）**
```c
#include <stdio.h>

static void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

static void permute(int *a, int n, int k)
{
    if (k == n) {
        for (int i = 0; i < n; i++) printf("%d ", a[i]);
        putchar('\n');
        return;
    }
    for (int i = k; i < n; i++) {
        swap(&a[k], &a[i]);       // 选一个数放到第 k 位
        permute(a, n, k + 1);     // 递归排剩下的
        swap(&a[k], &a[i]);       // 回溯：恢复
    }
}

int main(void)
{
    int a[] = {1, 2, 3};
    permute(a, 3, 0);
    return 0;
}
```
输出 6 种排列：`123 132 213 231 321 312`。

**第 13 题（参考）**
```c
#include <stdarg.h>
#include <stdio.h>

static void put_int(int n)
{
    if (n < 0) { putchar('-'); if (n == -2147483647 - 1) { fputs("2147483648", stdout); return; } n = -n; }
    if (n >= 10) put_int(n / 10);
    putchar('0' + n % 10);
}

void my_printf(const char *fmt, ...)
{
    va_list ap;
    va_start(ap, fmt);
    for (const char *p = fmt; *p; p++) {
        if (*p != '%') { putchar(*p); continue; }
        switch (*++p) {
        case 'd': put_int(va_arg(ap, int)); break;
        case 'c': putchar(va_arg(ap, int)); break;       // char 被提升为 int
        case 's': { const char *s = va_arg(ap, const char *);
                    while (*s) putchar(*s++); break; }
        case '%': putchar('%'); break;
        default:  putchar('%'); putchar(*p);
        }
    }
    va_end(ap);
}
```

**第 15 题**：`ways(n) = ways(n-1) + ways(n-2)`，`ways(1)=1, ways(2)=2`——本质就是斐波那契数列。
