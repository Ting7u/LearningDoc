# C23（ISO/IEC 9899:2024）

> 原名 C2x，`__STDC_VERSION__ == 202311L`。C11 之后最大的一次更新，明显吸收了 C++ 的许多好用特性，同时清理了历史包袱。

## 新特性总览

**类型与关键字**
- `nullptr` / `nullptr_t`
- `bool` `true` `false` 成为关键字
- `constexpr` 对象
- `auto` 类型推导
- `typeof` / `typeof_unqual`
- `_BitInt(N)` 任意位宽整数
- 枚举可指定底层类型
- `_Decimal32/64/128` 十进制浮点（可选）

**字面量与语法**
- 二进制字面量 `0b`，数字分隔符 `'`
- 空初始化器 `{}`
- 属性 `[[...]]`
- `static_assert` 可省略消息
- 标签可放在声明/块尾之前
- 函数定义中参数可不命名
- `()` 等价 `(void)`；删除 K&R 老式函数定义
- `u8` 字符常量、`char8_t`

**预处理**
- `#embed`
- `#elifdef` / `#elifndef`
- `#warning`
- `__has_include`、`__has_embed`、`__has_c_attribute`
- `__VA_OPT__`

**标准库**
- `<stdbit.h>`、`<stdckdint.h>`
- `memset_explicit`、`memccpy`、`strdup`、`strndup`
- `free_sized`、`free_aligned_sized`
- `unreachable()`
- 位精确整数宽度宏（`INT_WIDTH` 等）

**清理**
- 强制补码表示整数
- 移除三字符序列（trigraphs）
- 移除 K&R 函数定义
- `realloc(p, 0)` 变为未定义行为

## 示例

### `nullptr`

```c
int *p = nullptr;                 // 比 NULL 类型更安全
nullptr_t n = nullptr;

void f(int *);
f(nullptr);

// 与 _Generic 搭配，能区分 nullptr 与整数 0
```

### `bool/true/false` 关键字

```c
// 不再需要 #include <stdbool.h>
bool ok = true;
```

### `constexpr`

```c
constexpr int N = 100;
int arr[N];                        // 真正的常量表达式
constexpr double PI = 3.14159265358979;
```

> 与 C++ 不同：C23 的 `constexpr` 只能修饰**对象**，不能修饰函数。

### `auto` 类型推导

```c
auto x = 42;           // int
auto y = 3.14;         // double
auto p = &x;           // int *
for (auto it = arr; it < arr + N; ++it) { ... }
```

### `typeof`

```c
int a = 5;
typeof(a) b = 10;               // int

#define SWAP(a, b) do { typeof(a) t = (a); (a) = (b); (b) = t; } while (0)
```

### 二进制字面量与数字分隔符

```c
int flags = 0b1010'0101;
long big  = 1'000'000'000L;
unsigned mask = 0xFF'FF;
printf("%b\n", flags);          // C23 的 printf 支持 %b
```

### `_BitInt(N)`

```c
_BitInt(7)  a = 63;             // 7 位有符号整数
unsigned _BitInt(128) big = 1uwb << 100;   // uwb / wb 为 _BitInt 后缀
```

### 空初始化器

```c
struct S s = {};                // 全部零初始化
int arr[10] = {};
```

### 属性 `[[...]]`

```c
[[nodiscard]] int open_file(const char *);
[[deprecated("use new_api")]] void old_api(void);
[[noreturn]] void die(void);
[[maybe_unused]] static int dbg;

switch (x) {
case 1:
    do_a();
    [[fallthrough]];
case 2:
    do_b();
    break;
}
```

### `static_assert` 无消息

```c
static_assert(sizeof(int) == 4);
```

### 枚举指定底层类型

```c
enum Color : unsigned char { RED, GREEN, BLUE };
enum Big : long long { HUGE_VAL_ = 1LL << 40 };
```

### 参数可不命名 & `()` 即 `(void)`

```c
int f() { return 1; }           // 在 C23 中等价于 f(void)
void g(int, int) { }            // 参数不命名，C23 允许（定义里）
```

### `#embed`：把文件内容直接嵌入数组

```c
const unsigned char icon[] = {
#embed "icon.png"
};
```

### `#elifdef` / `#elifndef` / `#warning`

```c
#ifdef A
...
#elifdef B                      // 等价 #elif defined(B)
...
#endif

#warning "This is deprecated"
```

### `__has_include` / `__has_c_attribute`

```c
#if __has_include(<threads.h>)
#  include <threads.h>
#endif

#if __has_c_attribute(nodiscard)
...
#endif
```

### `__VA_OPT__`

```c
#define LOG(fmt, ...) printf(fmt __VA_OPT__(,) __VA_ARGS__)

LOG("hello\n");                 // 无额外参数也不会多出逗号
LOG("x=%d\n", 1);
```

### `<stdbit.h>`：位操作标准化

```c
#include <stdbit.h>

unsigned x = 0b1011000;
stdc_count_ones(x);             // 3，popcount
stdc_leading_zeros(x);
stdc_first_leading_one(x);
stdc_bit_width(x);
stdc_has_single_bit(x);         // 是否为 2 的幂
```

### `<stdckdint.h>`：检查整数溢出

```c
#include <stdckdint.h>

int r;
if (ckd_add(&r, INT_MAX, 1)) {
    puts("overflow!");
}
if (ckd_mul(&r, a, b)) { ... }
```

### 字符串/内存函数

```c
char *s = strdup("hello");                 // 现在是标准函数
char *t = strndup("hello", 3);             // "hel"

memset_explicit(secret, 0, sizeof secret); // 不会被编译器优化掉，用来擦除密码
free_sized(p, size);                       // 带大小释放，利于分配器优化
```

### `unreachable()`

```c
#include <stddef.h>

switch (v) {
case 0: return 1;
case 1: return 2;
default: unreachable();        // 告诉编译器不可能走到这里
}
```

### UTF-8

```c
char8_t c = u8'a';
const char8_t *s = u8"你好";
```

## 被移除/改变

| 项目 | 变化 |
|---|---|
| K&R 老式函数定义 | 移除 |
| 三字符序列 `??=` 等 | 移除（digraphs 保留） |
| 整数符号表示 | 只允许二进制补码 |
| `realloc(p, 0)` | 变为未定义行为 |
| `ATOMIC_VAR_INIT` | 废弃 |

## 编译

```bash
gcc   -std=c23 main.c     # GCC 14+（旧版用 -std=c2x）
clang -std=c23 main.c     # Clang 18+（旧版用 -std=c2x）
```

> 各编译器对 C23 特性支持程度不一，使用前可查阅其 C status 页面。
