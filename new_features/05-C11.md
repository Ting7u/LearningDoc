# C11（ISO/IEC 9899:2011）

> 原名 C1X，`__STDC_VERSION__ == 201112L`。重点是**并发**、**泛型选择**和**编译期检查**。

## 新特性总览

1. 多线程支持：`<threads.h>`（可选）
2. 原子操作：`_Atomic`、`<stdatomic.h>`（可选）
3. 线程局部存储：`_Thread_local`
4. 泛型选择：`_Generic`
5. 静态断言：`_Static_assert` / `static_assert`
6. 对齐：`_Alignas`、`_Alignof`、`<stdalign.h>`、`aligned_alloc`
7. `_Noreturn` / `<stdnoreturn.h>`
8. 匿名结构体和联合体
9. Unicode：`char16_t`、`char32_t`、`u8""` `u""` `U""`、`<uchar.h>`
10. 删除 `gets`
11. 边界检查接口 Annex K（可选，`*_s` 函数）
12. `fopen` 的 `"x"` 独占创建模式
13. `quick_exit`、`at_quick_exit`
14. `timespec_get`
15. `CMPLX` 等复数构造宏
16. VLA 变为可选特性（`__STDC_NO_VLA__`）
17. 标准化内存模型

## 示例

### `_Generic`：编译期按类型分派

```c
#define type_name(x) _Generic((x), \
    int:    "int",                 \
    double: "double",              \
    char*:  "char*",               \
    default:"other")

printf("%s\n", type_name(3));      // int
printf("%s\n", type_name(3.14));   // double

// 实现类型安全的"泛型"数学函数
#define abs_g(x) _Generic((x), int: abs, long: labs, double: fabs)(x)
```

### 静态断言

```c
#include <assert.h>

static_assert(sizeof(int) >= 4, "int must be at least 4 bytes");
_Static_assert(sizeof(void*) == 8, "64-bit required");
```

### 匿名结构体/联合体

```c
struct Value {
    int type;
    union {                // 匿名，成员直接访问
        int    i;
        double d;
    };
};

struct Value v = { .type = 1, .i = 42 };
printf("%d\n", v.i);       // 不必写 v.u.i
```

### 对齐

```c
#include <stdalign.h>

alignas(32) char buf[64];
size_t a = alignof(double);
void *p = aligned_alloc(64, 128);   // size 须是 alignment 的倍数
```

### `_Noreturn`

```c
#include <stdnoreturn.h>

noreturn void die(const char *msg) {
    fputs(msg, stderr);
    exit(1);
}
```

### 线程（`<threads.h>`）

```c
#include <threads.h>
#include <stdio.h>

int worker(void *arg) {
    printf("hello from thread %d\n", *(int*)arg);
    return 0;
}

int main(void) {
    thrd_t t;
    int id = 1;
    thrd_create(&t, worker, &id);
    thrd_join(t, NULL);

    static mtx_t m;
    mtx_init(&m, mtx_plain);
    mtx_lock(&m);
    /* 临界区 */
    mtx_unlock(&m);
}
```

### 原子操作与线程局部存储

```c
#include <stdatomic.h>

_Atomic int counter = 0;
atomic_fetch_add(&counter, 1);       // 线程安全自增

_Thread_local int tls_var = 0;       // 每个线程各有一份
```

### Unicode 字符串

```c
#include <uchar.h>

const char     *s8  = u8"你好";   // UTF-8
const char16_t *s16 = u"你好";    // UTF-16
const char32_t *s32 = U"你好";    // UTF-32
```

### `fopen` 独占模式

```c
FILE *f = fopen("lock.txt", "wx");   // 文件已存在则失败，用于避免竞态
```

### 其他

```c
#include <complex.h>
double complex z = CMPLX(1.0, 2.0);   // 比 1.0 + 2.0*I 更精确（处理 inf/nan）

struct timespec ts;
timespec_get(&ts, TIME_UTC);
```

## 被移除

- **`gets()`**：永远不安全，用 `fgets` 替代
