# C89 / C90（ANSI C / ISO C）

> ANSI 于 1989 年发布（X3.159-1989），ISO 于 1990 年采纳为 ISO/IEC 9899:1990。二者内容基本相同，所以叫 C89 或 C90。这是第一个官方标准。

## 新特性总览

1. 函数原型（参数类型检查）
2. **`void`** 类型与 `void *`
3. `const`、`volatile` 限定符
4. **`enum`** 枚举
5. **`signed`**、`long double`、`unsigned` 后缀（`U`/`L`/`UL`）
6. 字符串字面量拼接
7. 预处理增强：`#`、`##`、`#elif`、`#error`、`#pragma`、`defined`
8. 变参函数标准化（`<stdarg.h>`）
9. 结构体可整体赋值、按值传参/返回
10. 标准库统一（`<stddef.h>` `<limits.h>` `<float.h>` `<locale.h>` `<assert.h>` `<errno.h>` `<signal.h>` `<setjmp.h>` 等）
11. 宽字符、多字节字符基础支持

## 示例

### 函数原型

```c
int add(int a, int b);          /* 原型：编译器检查实参 */

int main(void) {
    add(1, 2);
    /* add(1, 2, 3);  编译错误 */
    return 0;
}

int add(int a, int b) { return a + b; }
```

### `void` 与 `void *`

```c
void *p = malloc(100);   /* 通用指针，无需强转（C 中） */
void log_msg(void);      /* 无返回值、无参数 */
```

### `const` 和 `volatile`

```c
const int MAX = 100;
const char *s = "hello";       /* 指向常量的指针 */
volatile int *reg;             /* 每次都从内存读，禁止优化，用于硬件寄存器 */
```

### 枚举

```c
enum Color { RED, GREEN = 5, BLUE };   /* RED=0, GREEN=5, BLUE=6 */
enum Color c = BLUE;
```

### 字符串拼接

```c
printf("Hello, "
       "World!\n");     /* 相邻字符串自动合并 */
```

### 预处理：`#` 字符串化与 `##` 拼接

```c
#define STR(x)     #x
#define CAT(a, b)  a##b

printf("%s\n", STR(hello));   /* "hello" */
int CAT(var, 1) = 10;         /* int var1 = 10; */

#if defined(DEBUG)
#  error "Debug build not allowed"
#elif defined(FOO)
...
#endif
```

### 变参函数

```c
#include <stdarg.h>

int sum(int n, ...) {
    va_list ap;
    int i, total = 0;          /* C89：变量必须在块开头声明 */
    va_start(ap, n);
    for (i = 0; i < n; i++)
        total += va_arg(ap, int);
    va_end(ap);
    return total;
}

/* sum(3, 10, 20, 30) == 60 */
```

### 结构体整体赋值

```c
struct Point { int x, y; };
struct Point a = {1, 2};
struct Point b = a;          /* 整体拷贝，K&R 中不一定支持 */
```

## C89 的限制（后续版本改进）

- 变量必须在块开头声明
- 只支持 `/* */` 注释
- 没有 `long long`、`bool`、`inline`
- 隐式 int 与隐式函数声明仍被允许（C99 才移除）
