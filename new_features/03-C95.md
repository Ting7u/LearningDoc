# C95（ISO/IEC 9899/AMD1:1995，Amendment 1）

> 对 C90 的一次小修订，又称 **C94 / AMD1**。主要面向国际化（宽字符）和键盘兼容。宏 `__STDC_VERSION__` 值为 `199409L`。

## 新特性

### 1. `<iso646.h>`：运算符的可读拼写

为缺少 `& | ^ ~ ! {` 等字符的键盘提供替代名。

```c
#include <iso646.h>

if (a and b or not c) { ... }   /* 等价于 (a && b || !c) */
x xor_eq y;                      /* x ^= y */
```

| 宏 | 含义 | 宏 | 含义 |
|---|---|---|---|
| `and` | `&&` | `bitand` | `&` |
| `or` | `\|\|` | `bitor` | `\|` |
| `not` | `!` | `compl` | `~` |
| `not_eq` | `!=` | `xor` | `^` |
| `and_eq` | `&=` | `or_eq` / `xor_eq` | `\|=` / `^=` |

### 2. 双字符（Digraphs）

```c
%:include <stdio.h>      /* 等价于 #include */

int main(void)
<%
    int a<:3:> = <% 1, 2, 3 %>;   /* int a[3] = {1,2,3}; */
%>
```

| digraph | 等价 |
|---|---|
| `<:` `:>` | `[` `]` |
| `<%` `%>` | `{` `}` |
| `%:` `%:%:` | `#` `##` |

### 3. 宽字符支持库

- `<wchar.h>`：宽字符 I/O 与字符串（`wprintf`、`wcslen`、`fgetws`…）
- `<wctype.h>`：宽字符分类（`iswalpha`、`towupper`…）

```c
#include <wchar.h>

wchar_t s[] = L"你好";
wprintf(L"%ls, len=%zu\n", s, wcslen(s));
```

### 4. 其他

- 新增 `__STDC_VERSION__` 宏（`199409L`）
- 一些格式化函数的扩展（如 `%lc` / `%ls`）

## 小结

C95 变化不大，但为 C99 的大规模国际化和 Unicode 支持铺了路。
