# C 语言占位符（格式说明符）完全总结

C语言里说的"占位符"，正式名称是**格式说明符（Format Specifier / Conversion Specification）**，主要用在`printf`系列（输出）和`scanf`系列（输入）函数里，格式是`%[flags][width][.precision][length]conversion`。下面按功能分类详细梳理。

---

## 一、基础类型占位符

### 1. 整数类型

| 占位符  | 含义                          | 对应类型           | 示例                          |
| ---- | --------------------------- | -------------- | --------------------------- |
| `%d` | 有符号十进制整数                    | `int`          | `printf("%d", 42);` → `42`  |
| `%i` | 有符号十进制整数（与`%d`几乎等价，输出时完全一样） | `int`          | `printf("%i", 42);` → `42`  |
| `%u` | 无符号十进制整数                    | `unsigned int` | `printf("%u", 42u);` → `42` |
| `%o` | 无符号八进制（不带前缀`0`）             | `unsigned int` | `printf("%o", 8);` → `10`   |
| `%x` | 无符号十六进制，小写字母                | `unsigned int` | `printf("%x", 255);` → `ff` |
| `%X` | 无符号十六进制，大写字母                | `unsigned int` | `printf("%X", 255);` → `FF` |

> ⚠️ `%d`和`%i`在**输出**（`printf`）时完全等价；但在**输入**（`scanf`）时不同：`%i`会自动识别`0x`前缀为十六进制、`0`前缀为八进制，而`%d`一律按十进制解析。

### 2. 浮点数类型

| 占位符 | 含义 | 对应类型 | 示例 |
|--------|------|----------|------|
| `%f` | 十进制小数形式，默认6位小数 | `double`（`printf`中`float`会自动提升为`double`） | `printf("%f", 3.14);` → `3.140000` |
| `%e` | 科学计数法，小写`e` | `double` | `printf("%e", 12345.6789);` → `1.234568e+04` |
| `%E` | 科学计数法，大写`E` | `double` | `printf("%E", 12345.6789);` → `1.234568E+04` |
| `%g` | 自动选择`%f`或`%e`中更短的一种，去除多余的0 | `double` | `printf("%g", 0.0001234);` → `0.0001234` |
| `%G` | 同`%g`，但科学计数法用大写`E` | `double` | `printf("%G", 123456789.0);` → `1.23457E+08` |
| `%a` | 十六进制浮点数（C99新增，较少用） | `double` | `printf("%a", 1.0);` → `0x1p+0` |
| `%A` | 同`%a`，大写形式 | `double` | — |

### 3. 字符与字符串

| 占位符 | 含义 | 对应类型 | 示例 |
|--------|------|----------|------|
| `%c` | 单个字符 | `char`（在可变参数中会被提升为`int`） | `printf("%c", 'a');` → `a` |
| `%s` | 字符串（以`\0`结尾的`char`数组） | `char *` | `printf("%s", "hello");` → `hello` |

### 4. 指针

| 占位符 | 含义 | 对应类型 | 示例 |
|--------|------|----------|------|
| `%p` | 指针地址，格式由实现定义（通常是十六进制） | `void *` | `printf("%p", (void*)&x);` → `0x7ffee3a1c` |

### 5. 特殊

| 占位符 | 含义 |
|--------|------|
| `%%` | 输出一个字面的`%`符号本身 |
| `%n` | **危险占位符**：把目前为止已输出的字符数写入对应的`int*`参数。因安全风险（可被利用做格式化字符串攻击），现代编译器/系统库常默认禁用或警告，**不建议使用** |

## 二、长度修饰符（Length Modifier）

长度修饰符放在占位符字母前面，用于指定参数的具体大小（因为可变参数`...`在传递时会发生默认类型提升，所以需要显式指定）。

| 修饰符 | 配合整数占位符 | 配合浮点占位符 | 对应类型 |
|--------|----------------|----------------|----------|
| `hh` | `%hhd` `%hhu` 等 | — | `signed/unsigned char` |
| `h` | `%hd` `%hu` 等 | — | `short` |
| （无） | `%d` `%u` 等 | `%f` `%e` 等 | `int` / `double` |
| `l` | `%ld` `%lu` 等 | `%lf`（`scanf`中读`double`用，`printf`中`%lf`等价于`%f`） | `long` |
| `ll` | `%lld` `%llu` 等 | — | `long long` |
| `L` | — | `%Lf` `%Le` 等 | `long double` |
| `j` | `%jd` | — | `intmax_t` / `uintmax_t` |
| `z` | `%zu`（最常用，配合`sizeof`） | — | `size_t` |
| `t` | `%td` | — | `ptrdiff_t` |

**常见组合示例：**

```c
long a = 100000L;
printf("%ld\n", a);          // long

long long b = 10000000000LL;
printf("%lld\n", b);         // long long

size_t s = sizeof(int);
printf("%zu\n", s);          // size_t，配合sizeof的标准写法

unsigned short c = 300;
printf("%hu\n", c);          // unsigned short
```

> ⚠️ `%zu`是C99引入的，专门为`sizeof`的返回类型`size_t`设计，比强转成`unsigned long`再用`%lu`更规范、更可移植。

## 三、格式控制：标志、宽度、精度

完整语法：`%[flags][width][.precision][length]conversion`

### 1. 标志（Flags）

| 标志 | 作用 | 示例 |
|------|------|------|
| `-` | 左对齐（默认右对齐） | `printf("%-5d|", 42);` → `42   |` |
| `+` | 正数强制显示`+`号 | `printf("%+d", 42);` → `+42` |
| `空格` | 正数前补一个空格（占位对齐用） | `printf("% d", 42);` → ` 42` |
| `0` | 用`0`而非空格填充宽度 | `printf("%05d", 42);` → `00042` |
| `#` | 备用形式：`%#o`加前缀`0`，`%#x`加前缀`0x`，`%#f`强制显示小数点 | `printf("%#x", 255);` → `0xff` |

### 2. 宽度（Width）

指定输出的**最小**字符宽度，不够则按标志补齐（默认补空格）。

```c
printf("[%5d]\n", 42);     // [   42]  宽度5，右对齐
printf("[%-5d]\n", 42);    // [42   ]  宽度5，左对齐
printf("[%*d]\n", 5, 42);  // [   42]  用*表示宽度由参数动态传入
```

### 3. 精度（Precision）

用`.`加数字表示，含义因类型而异：

| 类型 | 精度的含义 | 示例 |
|------|-----------|------|
| `%f` | 小数点后位数（默认6） | `printf("%.2f", 3.14159);` → `3.14` |
| `%s` | 最多输出的字符数 | `printf("%.3s", "hello");` → `hel` |
| `%d`等整数 | 最少输出的数字位数，不足前面补0 | `printf("%.5d", 42);` → `00042` |
| `%g` | 有效数字总位数 | `printf("%.3g", 3.14159);` → `3.14` |

同样支持`*`动态指定：

```c
printf("%.*f\n", 2, 3.14159);  // 3.14，精度由参数传入
```

## 四、`printf` vs `scanf` 中占位符的区别

`scanf`系列（输入函数）用的占位符和`printf`基本一致，但有几点关键区别：

```c
int a;
double b;
char str[20];
char c;

scanf("%d", &a);      // 注意：必须传地址 &a
scanf("%lf", &b);      // 读double必须用%lf（这点和printf不同！printf读double用%f即可）
scanf("%s", str);      // 数组名本身就是地址，不用加&
scanf(" %c", &c);      // %c前加空格可以跳过之前残留的换行符
```

| 占位符 | `printf`（输出）中读取的类型 | `scanf`（输入）中要求的类型 |
|--------|------------------------------|------------------------------|
| `%f` | `double`（`float`自动提升） | `float*` |
| `%lf` | 等价于`%f`（`double`） | `double*`（**必须**，不能用`%f`） |
| `%Lf` | `long double` | `long double*` |

> 这是新手最容易踩的坑之一：`printf`里`%f`和`%lf`没区别，但`scanf`里读`double`变量**必须**写`%lf`，写`%f`是未定义行为。

## 五、C99/C11 新增的固定宽度整数占位符

如果用了`<stdint.h>`里的固定宽度整数类型（如`int32_t`），建议配合`<inttypes.h>`提供的宏来打印，而不是自己猜测该用`%d`还是`%ld`：

```c
#include <stdint.h>
#include <inttypes.h>

int32_t  a = 100;
int64_t  b = 10000000000;
uint32_t c = 300;

printf("%" PRId32 "\n", a);   // 打印int32_t
printf("%" PRId64 "\n", b);   // 打印int64_t
printf("%" PRIu32 "\n", c);   // 打印uint32_t
```

常用宏一览：

| 宏 | 含义 |
|----|------|
| `PRId8` / `PRId16` / `PRId32` / `PRId64` | 有符号整数对应位宽 |
| `PRIu8` / `PRIu16` / `PRIu32` / `PRIu64` | 无符号整数对应位宽 |
| `PRIx32` / `PRIx64` | 十六进制（小写） |

这样写的好处是**跨平台可移植**——不同平台上`int32_t`底层可能是`int`也可能是`long`，用这些宏能自动适配，不用自己判断。

## 六、速查表（最常用的一小撮）

对新手来说，日常够用的其实就这几个：

```c
%d      int
%u      unsigned int
%f      float / double
%c      char
%s      字符串
%p      指针
%x      十六进制
%ld     long
%lld    long long
%zu     size_t（sizeof的结果）
%%      字面的%号
```

## 七、一个综合示例

```c
#include <stdio.h>

int main(void) {
    int    a = -42;
    unsigned u = 42;
    double d = 3.14159;
    char   c = 'A';
    char   s[] = "hello";
    void  *p = &a;

    printf("%d\n", a);          // -42
    printf("%+d\n", a);         // -42（负数本身带符号，+对负数无影响）
    printf("%5d|\n", a);        //   -42|
    printf("%-5d|\n", a);       // -42  |
    printf("%u\n", u);          // 42
    printf("%.2f\n", d);        // 3.14
    printf("%10.2f\n", d);      //       3.14
    printf("%c\n", c);          // A
    printf("%s\n", s);          // hello
    printf("%.3s\n", s);        // hel
    printf("%p\n", p);          // 0x7ffee...(具体地址)
    printf("%%\n");             // %

    return 0;
}
```

---

## 小结

- **类型对应要严格匹配**：占位符和参数类型不匹配是C里最常见、也最危险的bug之一（编译器通常只给警告，不报错，运行时行为未定义）。
- **`scanf`读`double`必须用`%lf`**，这是和`printf`最大的不同点，务必记住。
- 涉及固定宽度整数类型（`int32_t`等）时，优先用`<inttypes.h>`的`PRI`系列宏，而不是手动猜测长度修饰符。
