## 2.1 文件系统结构

类 Unix 系统只有**一棵目录树**，根是 `/`，所有文件都挂在这棵树上（不像 Windows 有 C:、D: 盘符）。

```
/
├── bin      基础命令（现代系统中常是 /usr/bin 的链接）
├── etc      系统配置文件
├── home     普通用户的主目录（macOS 上是 /Users）
│   └── alice
├── tmp      临时文件
├── usr      用户程序和库
├── var      经常变化的数据，如日志
├── dev      设备文件
└── proc     进程与内核信息（Linux 特有）
```

### 几个特殊的路径符号

| 符号 | 含义 |
|------|------|
| `/` | 根目录；路径开头的 `/` 表示绝对路径 |
| `~` | 当前用户的主目录（由 Shell 展开） |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `-` | 仅用于 `cd -`，表示上一次所在的目录 |

### 绝对路径与相对路径

- **绝对路径**：从 `/` 开始，无论你在哪里都指向同一个位置，如 `/home/alice/notes.txt`
- **相对路径**：从**当前目录**出发，如 `docs/a.txt`、`../b.txt`、`./run.sh`

假设当前在 `/home/alice`：

| 想访问的位置 | 绝对路径 | 相对路径 |
|-------------|---------|---------|
| 自己目录下的 docs | `/home/alice/docs` | `docs` 或 `./docs` |
| 上一级 | `/home` | `..` |
| 同级的 bob 目录 | `/home/bob` | `../bob` |

### 隐藏文件

名字以 `.` 开头的文件是**隐藏文件**，普通的 `ls` 不显示，例如 `.bashrc`、`.gitignore`。

## 2.2 浏览与导航：`pwd`、`cd`、`ls`

### `pwd`：我在哪

```bash
pwd
# /home/alice/shell-lab
```

### `cd`：切换目录

```bash
cd /tmp           # 绝对路径
cd ..             # 上一级
cd ../..          # 上两级
cd ~              # 回主目录
cd                # 不带参数，同样回主目录
cd -              # 回到上一次所在的目录（来回切换很方便）
cd ~/shell-lab    # 主目录下的 shell-lab
```

### `ls`：列出目录内容

```bash
ls                # 列出当前目录
ls /tmp           # 列出指定目录
ls -l             # 长格式，显示详细信息
ls -a             # 显示所有文件（包括隐藏文件）
ls -la            # 两者合并
ls -lh            # -h：文件大小用 K / M / G 显示，更易读
ls -lt            # 按修改时间排序（新的在前）
ls -R             # 递归列出子目录
ls -d */          # 只列出目录本身
```

### 读懂 `ls -l` 的输出

```
-rw-r--r--  1 alice staff  1234 Nov 22 10:00 notes.txt
drwxr-xr-x  2 alice staff  4096 Nov 22 10:05 docs
```

（以上为示例，具体格式和列会因系统而略有不同。）

| 部分 | 含义 |
|------|------|
| 第 1 个字符 | 文件类型：`-` 普通文件，`d` 目录，`l` 符号链接 |
| 后 9 个字符 `rw-r--r--` | 权限：属主、属组、其他人，各自的读（r）、写（w）、执行（x）。第 9 章详细讲 |
| `1`、`2` | 硬链接数（初学可先不管） |
| `alice` | 属主 |
| `staff` | 属组 |
| `1234` | 大小（字节，用 `-h` 则换算为 K/M/G） |
| `Nov 22 10:00` | 最后修改时间 |
| `notes.txt` | 文件名 |

## 2.3 文件与目录操作

### `touch`：创建空文件 / 更新时间戳

```bash
touch a.txt              # 不存在则创建空文件
touch a.txt b.txt c.txt  # 一次创建多个
touch a.txt              # 已存在则只更新修改时间，不改内容
```

### `mkdir`：创建目录

```bash
mkdir docs                    # 创建一个目录
mkdir a b c                   # 一次创建多个
mkdir -p project/src/utils    # -p：连同不存在的父目录一起创建；已存在也不报错
```

不加 `-p` 时，如果父目录不存在会报错：

```bash
mkdir x/y/z
# mkdir: cannot create directory 'x/y/z': No such file or directory
```

### `cp`：复制

```bash
cp a.txt b.txt            # 复制文件（b.txt 已存在会被覆盖！）
cp a.txt docs/            # 复制到目录里，文件名不变
cp a.txt b.txt docs/      # 多个文件复制到目录
cp -r docs docs_backup    # -r：递归复制目录
cp -i a.txt b.txt         # -i：覆盖前询问
cp -p a.txt b.txt         # -p：保留权限、时间等属性
```

规则：复制**目录**必须加 `-r`。

### `mv`：移动 / 重命名

`mv` 一个命令两种用途：

```bash
mv a.txt b.txt            # 重命名（同一目录下改名）
mv a.txt docs/            # 移动到 docs 目录
mv a.txt docs/c.txt       # 移动并改名
mv docs docs_old          # 重命名目录（目录不需要 -r）
mv -i a.txt b.txt         # 覆盖前询问
```

### `rm`：删除（⚠️ 谨慎）

```bash
rm a.txt             # 删除文件
rm -i a.txt          # 删除前询问
rm -r docs           # -r：递归删除目录及其内容
rm -rf docs          # -f：强制，不询问，文件不存在也不报错
rmdir empty_dir      # 只能删除空目录
```

> ⚠️ **重要**：命令行的 `rm` **没有回收站**，删了基本就找不回来。
>
> 养成习惯：
> 1. 先用 `ls` 看看要删的是什么，确认无误再 `rm`
> 2. 新手阶段多用 `rm -i`
> 3. 使用 `rm -rf` 时，**反复检查路径**，尤其是带变量或通配符的时候。
>    例如 `rm -rf $DIR/` 如果变量 `DIR` 是空的，就变成了 `rm -rf /`，后果严重。
>    （后面第 10 章会讲怎样用 `set -u` 等机制预防。）

### 综合例子：搭一个项目目录

```bash
cd ~/shell-lab
mkdir -p myproject/{src,docs,tests}      # {} 是花括号展开，见 2.6
touch myproject/src/main.c myproject/docs/README.md
cp myproject/docs/README.md myproject/README.md
mv myproject/tests myproject/test        # 重命名
ls -R myproject
```

## 2.4 查看文件内容：`cat`、`less`、`head`、`tail`

先准备一个有内容的文件：

```bash
seq 1 100 > numbers.txt     # 生成 1~100，每行一个数，写入文件（> 在第 3 章讲）
```

### `cat`：一次性输出全部内容

```bash
cat numbers.txt         # 输出全部
cat -n numbers.txt      # -n：显示行号
cat a.txt b.txt         # 依次输出多个文件（cat 的本义就是 concatenate 拼接）
```

适合看**短文件**；长文件会一下刷屏。

### `less`：分页查看（长文件首选）

```bash
less numbers.txt
```

进入后的常用按键：

| 按键 | 作用 |
|------|------|
| `空格` / `f` | 向下翻一页 |
| `b` | 向上翻一页 |
| `↑` `↓` 或 `j` `k` | 逐行滚动 |
| `g` / `G` | 跳到开头 / 结尾 |
| `/关键字` | 向下搜索，`n` 下一个，`N` 上一个 |
| `q` | 退出 |

> `less` 的这套按键和 `man` 的翻页是一样的，学会一次两处通用。

### `head` / `tail`：看开头 / 结尾

```bash
head numbers.txt          # 默认前 10 行
head -n 3 numbers.txt     # 前 3 行
tail numbers.txt          # 默认最后 10 行
tail -n 3 numbers.txt     # 最后 3 行
tail -f app.log           # -f：持续跟踪文件新增内容，常用于看实时日志（Ctrl+C 退出）
```

组合取「第 11 到 20 行」要用到管道，第 3 章会讲：

```bash
head -n 20 numbers.txt | tail -n 10
```

## 2.5 通配符（Globbing）

通配符让你用「模式」一次匹配多个文件。**注意：通配符是由 Shell 展开的，不是由命令展开的。**
也就是说，`ls *.txt` 中，`ls` 收到的已经是展开后的文件名列表（`a.txt b.txt ...`）。

准备实验环境：

```bash
cd ~/shell-lab
mkdir glob-test && cd glob-test
touch a.txt b.txt c.log img1.png img2.png img10.png .hidden
```

### 四种常用通配符

| 通配符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `*` | 匹配**任意长度**的任意字符（含空） | `ls *.txt` | `a.txt b.txt` |
| `?` | 匹配**恰好一个**任意字符 | `ls img?.png` | `img1.png img2.png`（不含 img10.png） |
| `[]` | 匹配括号里的**任意一个**字符 | `ls img[12].png` | `img1.png img2.png` |
| `{}` | 花括号展开（枚举，bash/zsh 特性） | `ls {a,b}.txt` | `a.txt b.txt` |

`[]` 的更多写法：

```bash
ls img[0-9].png        # 范围：img0.png ~ img9.png
ls [ab].txt            # a.txt 或 b.txt
ls [!a]*.txt           # 取反：不以 a 开头的 .txt（bash 里 [^a] 也可以）
```

### 花括号展开的特点

`{}` 严格来说是**展开**（生成字符串），不依赖文件是否存在：

```bash
echo {a,b,c}                 # a b c
echo file{1,2,3}.txt         # file1.txt file2.txt file3.txt
echo {1..5}                  # 1 2 3 4 5
echo {a..e}                  # a b c d e
mkdir -p proj/{src,docs,tests}
cp config.yml{,.bak}         # 展开为 cp config.yml config.yml.bak（快速备份）
```

### 容易踩的坑

1. **隐藏文件不会被 `*` 匹配**：

   ```bash
   ls *          # 看不到 .hidden
   ls -A         # 用 -A 才能列出隐藏文件（不含 . 和 ..）
   ```

2. **没有匹配项时**，bash 默认会把模式原样传给命令：

   ```bash
   ls *.xyz
   # ls: cannot access '*.xyz': No such file or directory
   ```

   （zsh 默认的行为不同，会直接报 `no matches found`。）

3. **加引号会关闭通配符**：

   ```bash
   ls "*.txt"    # 去找一个字面上叫 *.txt 的文件
   ```

4. **不要用 `rm -rf .*`**：在一些版本的 bash 中，`.*` 会匹配到 `.` 和 `..`，很危险。

5. **文件名含空格**时，需要加引号或转义（引号规则第 5 章详细讲）：

   ```bash
   touch "my file.txt"
   rm "my file.txt"       # 或：rm my\ file.txt
   ```

## 2.6 获取帮助：`man`、`--help`、`help`

### `--help`：快速看用法

```bash
ls --help
cp --help
```

> macOS 自带的是 BSD 版命令，部分命令不支持 `--help`，这时用 `man`。

### `man`：查看完整手册

```bash
man ls          # 打开 ls 的手册（用 less 的按键操作，q 退出）
man -k copy     # 按关键字搜索相关手册（等价于 apropos copy）
```

### 手册分章节

`man` 的手册分为不同章节，同名条目可能出现在多个章节：

| 章节 | 内容 |
|------|------|
| 1 | 用户命令（Shell 命令） |
| 2 | 系统调用 |
| 3 | C 库函数 |
| 5 | 文件格式与配置 |
| 8 | 系统管理命令 |

> 对学 C 的你会很熟悉：`man 3 printf` 看的是 C 库函数 `printf`，
> 而 `man 1 printf` 看的是 Shell 命令 `printf`；`man 2 open` 看的是系统调用 `open`。

### `help` 与 `type`：针对内建命令

内建命令（如 `cd`）没有独立的 man 页面，用 `help`：

```bash
help cd         # bash 中查看内建命令的帮助
type cd         # 判断命令类型（第 1 章讲过）
```

## 2.7 提升效率：命令历史与 Tab 补全

### Tab 补全

- 输入命令或路径的前几个字符，按 `Tab` 自动补全
- 有多个候选时，按两次 `Tab` 列出所有可能
- 能补全：命令名、文件/目录名；安装了补全脚本后还能补全选项

### 命令历史

```bash
history            # 列出历史命令（带编号）
history | tail     # 只看最近的几条（用到管道）
!!                 # 重复上一条命令
!42                # 执行历史编号为 42 的命令
sudo !!            # 常用：上条命令权限不够，加 sudo 重新执行
```

另外：

- `↑` / `↓`：翻看历史命令
- `Ctrl + R`：**反向搜索历史**，输入关键字即可，按 `Enter` 执行，按 `Esc` 或 `Ctrl+G` 取消（强烈推荐养成习惯）

### 常用快捷键（readline 编辑）

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + C` | 中断当前正在运行的命令 |
| `Ctrl + D` | 在空行上表示输入结束（退出 Shell） |
| `Ctrl + L` | 清屏（等同于 `clear`） |
| `Ctrl + A` / `Ctrl + E` | 光标跳到行首 / 行尾 |
| `Ctrl + U` | 删除光标前面的整行内容 |
| `Ctrl + W` | 删除光标前的一个单词 |
| `Ctrl + R` | 搜索历史命令 |

## 本章小结

- 目录树从 `/` 开始；`~` 是主目录，`.` 当前目录，`..` 上级目录；理解绝对路径与相对路径的区别。
- 导航用 `pwd`、`cd`、`ls`；`ls -lah` 最常用，要会读 `ls -l`。
- 创建：`touch`、`mkdir -p`；复制：`cp`（目录要 `-r`）；移动/重命名：`mv`；删除：`rm`（**没有回收站**）。
- 查看文件：短文件 `cat`，长文件 `less`，头尾用 `head` / `tail`，实时日志 `tail -f`。
- 通配符 `*` `?` `[]` 由 Shell 展开；`{}` 是花括号展开；隐藏文件不会被 `*` 匹配。
- 遇事先 `man` 或 `--help`；多用 `Tab` 补全和 `Ctrl + R`。

## 常见问题速查

| 现象 | 可能原因 |
|------|---------|
| `No such file or directory` | 路径写错了，先 `pwd` 和 `ls` 确认；注意大小写 |
| `Permission denied` | 没有对应权限（第 9 章详解） |
| `cp: -r not specified; omitting directory` | 复制目录漏了 `-r` |
| `rm: cannot remove 'x': Is a directory` | 删除目录要加 `-r`，或用 `rmdir`（仅空目录） |
| 文件名含空格导致命令出错 | 给文件名加引号：`rm "my file.txt"` |
| 命令不知道怎么用 | `命令 --help`、`man 命令` |
