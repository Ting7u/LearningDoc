# 第 5 章　变量与引用

## 本章目标

- 会定义和使用变量，区分「Shell 变量」与「环境变量」
- **彻底搞懂单引号、双引号、不加引号的区别**（Shell 最容易出错的地方）
- 会用命令替换 `$(...)` 和算术运算 `$(( ))`
- 掌握常用的参数展开：默认值、截取、替换、长度
- 会用数组和关联数组

> 本章以 **bash** 为准。标注「bash 特性」的内容在 POSIX sh（如 dash）里不一定可用。

---

## 5.1 变量的定义与使用

```bash
name="Alice"          # 定义（赋值）
echo $name            # 使用：在变量名前加 $
echo "${name}"        # 推荐写法：加花括号，边界更清晰
```

### 三条铁律

1. **等号两边不能有空格**

   ```bash
   name="Alice"      # ✅
   name = "Alice"    # ❌ Shell 会把 name 当成命令，参数是 = 和 Alice
   # bash: name: command not found
   ```

2. **使用时加 `$`，赋值时不加**

   ```bash
   count=5           # 赋值：不加 $
   echo $count       # 取值：加 $
   ```

3. **变量没有类型，本质上都是字符串**（算术运算时才会被当成数字）

   ```bash
   x=10
   y=20
   echo $x$y         # 1020（只是字符串拼接）
   ```

> **对比 C 语言**：C 的变量有类型、要先声明；Shell 变量不需要声明、没有类型，
> 未定义的变量取值时默认是**空字符串**（而不是报错）。

### 变量命名规则

- 由字母、数字、下划线组成，**不能以数字开头**
- 区分大小写：`Name` 和 `name` 是两个变量
- 习惯：环境变量/常量用大写（`PATH`、`MAX_RETRY`），脚本内的普通变量用小写

### 花括号 `${}` 的作用：划清变量名边界

```bash
name="log"
echo "$name_backup"      # 空！Shell 把 name_backup 当成了变量名
echo "${name}_backup"    # log_backup
```

### 删除变量、只读变量

```bash
unset name               # 删除变量
readonly PI=3.14         # 只读：之后再修改会报错
```

### 特殊变量（先认识几个，第 6、7 章还会详细讲）

| 变量 | 含义 |
|------|------|
| `$?` | 上一条命令的退出状态码 |
| `$$` | 当前 Shell 的进程号（PID） |
| `$0` | 脚本名 |
| `$1`~`$9` | 位置参数 |
| `$RANDOM` | 随机整数 0~32767（bash 特性） |

## 5.2 Shell 变量与环境变量

- **Shell 变量**：只在当前 Shell 进程里有效
- **环境变量**：用 `export` 导出后，会被**子进程继承**

验证：

```bash
X=1
bash -c 'echo "[$X]"'      # 输出 []   子进程看不到 X

export X
bash -c 'echo "[$X]"'      # 输出 [1]  导出后子进程能看到
```

> **对比 C 语言**：环境变量就是 C 里 `getenv()` 能读到的东西，
> 子进程继承环境变量，就像 `fork + exec` 时把 `environ` 传了下去。

### 只对一条命令临时设置变量

```bash
FOO=bar bash -c 'echo $FOO'     # 输出 bar
echo "[$FOO]"                    # 输出 []  当前 Shell 里并没有 FOO
```

### 查看环境变量

```bash
env                  # 列出所有环境变量
printenv HOME        # 查看某一个
echo $HOME $USER $PWD $SHELL $PATH
```

常见环境变量：

| 变量 | 含义 |
|------|------|
| `HOME` | 用户主目录 |
| `USER` | 当前用户名 |
| `PWD` | 当前目录 |
| `PATH` | 查找命令的目录列表（冒号分隔） |
| `SHELL` | 默认 Shell |
| `LANG` | 语言环境 |

### 修改 PATH

```bash
export PATH="$HOME/bin:$PATH"     # 在原有 PATH 前面添加一个目录
```

## 5.3 引用（Quoting）：重点中的重点

### 先理解 Shell 如何处理一行命令

在运行命令之前，Shell 会先对这一行做一系列**展开**，其中和引号密切相关的两步是：

1. **变量展开**：把 `$name` 换成它的值
2. **单词拆分（word splitting）和通配符展开（globbing）**：
   不加引号的展开结果会按空白（空格、Tab、换行）拆成多个词，并且 `*`、`?` 会被替换成匹配的文件名

**引号的作用，就是控制这些展开是否发生。**

### 三种写法对比

| 写法 | 变量展开 `$var` | 命令替换 `$(…)` | 单词拆分 / 通配符 | 反斜杠转义 |
|------|:---:|:---:|:---:|:---:|
| 单引号 `'...'` | ❌ 不展开，原样输出 | ❌ | ❌ | ❌（一切都是字面） |
| 双引号 `"..."` | ✅ 展开 | ✅ | ❌ 不拆分、不通配 | 仅对 `$` `` ` `` `"` `\` 有效 |
| 不加引号 | ✅ | ✅ | ✅ **会拆分、会通配** | ✅ |

### 单引号：全部原样输出

```bash
name="Alice"
echo '$name'              # $name
echo 'cost: $5 * 2'       # cost: $5 * 2
```

> 单引号里**不能再出现单引号**。需要的话，改用双引号包裹：`echo "it's"`。

### 双引号：展开变量，但不拆分

```bash
name="Alice"
echo "Hello, $name"            # Hello, Alice
echo "Today: $(date +%F)"      # 命令替换也会执行
echo "price: \$5"              # price: $5   用 \ 转义 $
echo "say \"hi\""              # say "hi"
```

### 不加引号：最容易出事

**问题 1：空白被压缩**

```bash
msg="a   b    c"
echo $msg          # a b c        （被拆成三个词，echo 用单个空格连接）
echo "$msg"        # a   b    c   （保持原样）
```

**问题 2：文件名含空格（非常危险）**

```bash
file="my file.txt"
rm $file           # ❌ 实际执行 rm my file.txt，删除两个文件：my 和 file.txt
rm "$file"         # ✅ 只删除 my file.txt
```

**问题 3：通配符被意外展开**

```bash
x="*"
echo $x            # 展开成当前目录下所有文件名
echo "$x"          # 输出字面的 *
```

**问题 4：变量为空时参数"消失"**

```bash
empty=""
[ $empty = "a" ]       # ❌ 展开后变成 [ = "a" ]，报错
[ "$empty" = "a" ]     # ✅ 展开后是 [ "" = "a" ]
```

### 黄金法则

> **使用变量时，默认加双引号：`"$var"`、`"$(cmd)"`、`"$@"`。**
> 只有在你明确**需要**单词拆分或通配符时，才不加引号。

### 反斜杠 `\`

```bash
echo hello\ world        # 转义空格，hello world 作为一个参数
echo "a\\b"              # a\b
ls long_command \
   --option              # 行尾的 \ 表示续行
```

### `$'...'`：ANSI-C 风格引用（bash 特性）

可以在里面写 `\n`、`\t` 等转义序列：

```bash
echo $'line1\nline2'     # 输出两行
printf '%s\n' $'a\tb'    # a    b（中间是制表符）
```

### 引号嵌套小技巧

```bash
echo "He said: 'hi'"            # 双引号里可以放单引号
echo 'He said: "hi"'            # 单引号里可以放双引号
echo "Path: '$HOME'"            # 双引号里的变量照常展开
```

## 5.4 命令替换：`$(...)`

把命令的**标准输出**当作值，嵌入到别处：

```bash
today=$(date +%F)                    # 2026-11-23 之类
echo "Today is $today"

lines=$(wc -l < /etc/passwd)
echo "passwd has $lines lines"

echo "当前目录名: $(basename "$(pwd)")"       # 可以嵌套，里面也要加引号
```

要点：

- **推荐 `$(...)`，不推荐反引号 `` `...` ``**：后者嵌套困难、可读性差。
- 命令替换会**去掉输出末尾的换行**。
- 外面加双引号防止拆分：`files="$(ls)"`；用在参数位置时写成 `"$(cmd)"`。
- 注意：有些系统（如 macOS）的 `wc -l` 输出会带前导空格，用于字符串比较时要小心；
  作为数字参与算术运算则没问题。

## 5.5 算术运算

Shell 变量默认是字符串，做整数运算要用专门语法。

### `$(( ))`：算术展开（取值）

```bash
echo $((3 + 4))            # 7
a=10; b=3
echo $((a + b))            # 13（括号里的变量可以省略 $）
echo $((a / b))            # 3   整数除法，没有小数
echo $((a % b))            # 1   取余
echo $((2 ** 10))          # 1024  幂运算
echo $(( (a + b) * 2 ))    # 26
sum=$((a + b))             # 把结果赋给变量
```

支持的运算符和 C 语言基本一致：`+ - * / % ** << >> & | ^ ~ ! && || < > <= >= == !=` 以及三目运算符 `?:`。

### `(( ))`：算术命令（做运算、做判断）

```bash
i=0
((i++))                    # 自增
((i += 5))                 # 复合赋值
echo $i                    # 6

if ((i > 5)); then echo "big"; fi      # 用作条件，C 风格的比较
```

> ⚠️ **注意退出状态与 C 相反**：`(( ))` 里表达式的值**非 0 → 退出状态 0（成功/真）**，
> 值为 0 → 退出状态 1（失败/假）。所以 `i=0; ((i++))` 这条命令的退出状态是 1（因为表达式取值是旧值 0）。
> 当脚本开启 `set -e` 时，这个细节会引发"脚本莫名退出"，第 10 章会再讲。

### 浮点数

Shell 不支持小数运算，需要借助 `awk` 等工具：

```bash
awk 'BEGIN {printf "%.2f\n", 10 / 3}'      # 3.33
echo "scale=2; 10/3" | bc                   # 3.33（前提是系统装有 bc）
```

### 前导 0 的坑

`$(( ))` 里以 0 开头的数字会被当作**八进制**：

```bash
echo $((010))          # 8
echo $((08))           # 报错：08 不是合法八进制
echo $((10#08))        # 8：用 10# 前缀强制按十进制解析
```

处理从日期（如 `08` 月）里取出的数字时经常碰到。

## 5.6 参数展开（Parameter Expansion）

`${变量 ...}` 的各种写法，可以在**不调用外部命令**的情况下完成字符串处理。

### 默认值

| 写法 | 含义 |
|------|------|
| `${var:-默认}` | 如果 var **未设置或为空**，**返回**默认值（不修改 var） |
| `${var:=默认}` | 如果未设置或为空，**赋值**为默认值并返回 |
| `${var:+替代}` | 如果 var **已设置且非空**，返回替代值，否则返回空 |
| `${var:?消息}` | 如果未设置或为空，打印消息并**报错退出**（脚本中） |

```bash
echo "Hello, ${name:-World}"     # name 没设置时输出 Hello, World
unset name
echo "${name:=Bob}"              # Bob，同时 name 被设置为 Bob
echo "$name"                     # Bob
: "${CONFIG:?必须设置 CONFIG 变量}"   # 未设置时报错并退出（: 是空命令，用来触发展开）
```

> 去掉冒号（如 `${var-默认}`）则只判断「是否未设置」，不判断「是否为空」。

### 长度

```bash
s="hello"
echo ${#s}               # 5
```

### 截取子串（bash 特性）

```bash
s="abcdefgh"
echo "${s:2}"            # cdefgh   从下标 2 开始到结尾（下标从 0 开始）
echo "${s:2:3}"          # cde      从下标 2 开始取 3 个字符
echo "${s: -3}"          # fgh      从末尾数 3 个（注意冒号后有空格，否则会被当作默认值语法）
```

### 去掉前缀 / 后缀（非常常用）

| 写法 | 含义 |
|------|------|
| `${var#模式}` | 从**开头**删除**最短**匹配 |
| `${var##模式}` | 从开头删除**最长**匹配 |
| `${var%模式}` | 从**结尾**删除**最短**匹配 |
| `${var%%模式}` | 从结尾删除**最长**匹配 |

记忆：`#` 在键盘上位于 `$` 的左边 → 管**前面**；`%` 位于右边 → 管**后面**。

```bash
path="/home/alice/report.tar.gz"

echo "${path##*/}"       # report.tar.gz   去掉最长的 */ → 得到文件名（相当于 basename）
echo "${path%/*}"        # /home/alice     去掉最短的 /* → 得到目录（相当于 dirname）
echo "${path##*.}"       # gz              取最后一个扩展名
echo "${path%.gz}"       # /home/alice/report.tar   去掉 .gz 后缀
echo "${path%%.*}"       # /home/alice/report       从第一个点起全部去掉
echo "${path#*/}"        # home/alice/report.tar.gz 去掉开头最短的 */（即开头的 /）
```

经典用法：批量改扩展名

```bash
for f in *.txt; do
    mv -- "$f" "${f%.txt}.bak"
done
```

### 替换（bash 特性）

```bash
s="a-b-c"
echo "${s/-/_}"          # a_b-c   替换第一个
echo "${s//-/_}"         # a_b_c   替换全部
echo "${s/#a/X}"         # X-b-c   只替换开头匹配的
echo "${s/%c/Z}"         # a-b-Z   只替换结尾匹配的
```

### 大小写转换（bash 4 及以上）

```bash
s="Hello"
echo "${s^^}"            # HELLO
echo "${s,,}"            # hello
```

> macOS 自带的 `/bin/bash` 版本较老（长期是 3.2），不支持 `^^`、`,,`、关联数组等 bash 4 特性。
> 用 `bash --version` 检查你的版本；在脚本里使用这些特性前要确认运行环境。

## 5.7 数组

### 索引数组（bash 特性）

```bash
fruits=(apple "banana split" cherry)     # 含空格的元素要加引号

echo "${fruits[0]}"          # apple             下标从 0 开始
echo "${fruits[1]}"          # banana split
echo "${fruits[@]}"          # 所有元素（保持各元素独立）
echo "${#fruits[@]}"         # 3                 元素个数
echo "${!fruits[@]}"         # 0 1 2             所有下标

fruits+=(date)               # 追加元素
fruits[5]="fig"              # 指定下标赋值（中间可以有空洞）
unset 'fruits[1]'            # 删除某个元素（引号防止被当作通配符）
echo "${fruits[@]:1:2}"      # 切片：从下标 1 开始取 2 个元素
```

### 遍历数组

```bash
for f in "${fruits[@]}"; do      # ← 注意：必须写成 "${arr[@]}"
    echo "[$f]"
done
```

- `"${arr[@]}"`：每个元素独立保留（含空格的元素不会被拆开），**遍历时用这个**
- `${arr[@]}`（不加引号）：元素会被再次拆分，容易出错
- `$arr`：只代表**第一个元素**（bash）

### 数组的实用场景：安全地保存文件列表

```bash
files=(*.txt)                    # 通配符展开的结果直接存入数组
echo "共 ${#files[@]} 个文件"
cp -- "${files[@]}" backup/
```

比 `files=$(ls *.txt)` 安全得多，因为后者会因为空格丢失边界。

> 注意：zsh 的数组下标默认从 **1** 开始，行为与 bash 有差异。本教程以 bash 为准。

### 关联数组（bash 4 及以上）

```bash
declare -A age                   # 必须先声明
age[alice]=30
age[bob]=25

echo "${age[alice]}"             # 30
echo "${!age[@]}"                # 所有键（顺序不保证）
echo "${#age[@]}"                # 2

for k in "${!age[@]}"; do
    echo "$k -> ${age[$k]}"
done
```

> **对比 C 语言**：数组下标默认从 0 开始与 C 一致；关联数组类似其他语言的哈希表/字典，C 标准库里没有现成的对应物。

## 5.8 综合例子

```bash
#!/usr/bin/env bash

# 根据文件路径生成备份文件名
src="${1:-/etc/hostname}"
dir="${src%/*}"                     # 目录部分
file="${src##*/}"                   # 文件名部分
stamp="$(date +%Y%m%d)"
backup="/tmp/${file}.${stamp}.bak"

echo "源文件目录: $dir"
echo "源文件名:   $file"
echo "备份到:     $backup"

# 统计 .txt 文件数量
txts=(*.txt)
echo "当前目录有 ${#txts[@]} 个 txt 文件（如果没有匹配，这里可能显示 1，原因见练习）"
```

## 本章小结

- 赋值 `name=value`，等号两边不能有空格；使用时 `$name` 或 `${name}`。
- `export` 让变量传给子进程；`VAR=x cmd` 只对这一条命令生效。
- **引号三种行为**：单引号原样输出；双引号展开但不拆分；不加引号会拆分和通配。**使用变量默认加双引号。**
- `$(cmd)` 取命令输出；`$((expr))` 做整数运算；浮点用 `awk`/`bc`。
- 参数展开：`${v:-默认}`、`${#v}`、`${v#前缀}`、`${v%后缀}`、`${v/旧/新}`。
- 数组用 `"${arr[@]}"` 遍历；关联数组需要 bash 4+。

### 参考答案

```bash
# 1
a=5; b=3
echo $((a+b)) $((a-b)) $((a*b)) $((a/b)) $((a%b))     # 8 2 15 1 2

# 2
# echo $x      → a b      （拆分后用单空格连接）
# echo "$x"    → a   b    （保持原样）
# echo '$x'    → $x       （不展开）

# 4
path="/var/log/nginx/access.log"
echo "${path##*/}"        # access.log
echo "${path%/*}"         # /var/log/nginx
echo "${path##*.}"        # log
f="${path##*/}"; echo "${f%.*}"     # access

# 5
echo "${s//-/_}"          # hello_world_shell

# 6
echo "Hello, ${NAME:-stranger}"

# 7
colors=(red green "dark blue")
echo "${#colors[@]}"      # 3
for c in "${colors[@]}"; do echo "[$c]"; done

# 8
# 没有匹配时，bash 默认把 *.txt 原样保留，数组里就有 1 个元素 "*.txt"，所以个数是 1。
# 判断是否真的存在：[ -e "${files[0]}" ]；或者开启 shopt -s nullglob，让无匹配时展开为空。

# 10
# 前导 0 被当作八进制，8 不是合法八进制数字。改成 echo $((10#08))。
```

## 常见问题速查

| 现象 | 原因 |
|------|------|
| `command not found`（赋值时） | 等号两边多了空格 |
| 变量输出为空 | 变量名写错，或写成 `$name_x` 导致边界错误，改用 `${name}_x` |
| 文件名带空格时命令出错 | 变量没加双引号 |
| `*` 被意外展开 | 没加引号，或需要加引号阻止通配 |
| 子脚本读不到变量 | 变量没有 `export` |
| `value too great for base` | 数字有前导 0，被当作八进制 |
| `bad substitution` | 在 sh/dash 里使用了 bash 特性（如 `${s//a/b}`、`${s^^}`） |
