# 第 4 章　文本处理工具

## 本章目标

- 掌握基础文本工具：`cut`、`sort`、`uniq`、`wc`、`tr`
- 会用 `grep` 搜索，并掌握基本的正则表达式
- 会用 `find` 查找文件，用 `xargs` 把结果交给其他命令
- 入门 Shell 的「三剑客」中的 `sed`（文本替换/编辑）和 `awk`（按字段处理）

> 前置知识：第 3 章的管道和重定向。本章的工具几乎都是「过滤器」：
> 读 stdin（或文件），处理后写 stdout，然后用 `|` 串起来。

## 4.0 准备练习数据

后面所有例子都基于下面两个文件。先把它们创建出来：

```bash
mkdir -p ~/shell-lab/ch04 && cd ~/shell-lab/ch04

cat > scores.csv <<'EOF'
name,class,score
Alice,A,85
Bob,B,72
Carol,A,91
Dave,B,68
Eve,A,78
EOF

cat > access.log <<'EOF'
192.168.1.10 - - [22/Nov/2026:10:00:01] "GET /index.html" 200 1024
192.168.1.11 - - [22/Nov/2026:10:00:05] "GET /about.html" 404 512
192.168.1.10 - - [22/Nov/2026:10:01:12] "POST /login" 200 256
192.168.1.12 - - [22/Nov/2026:10:02:30] "GET /index.html" 200 1024
192.168.1.11 - - [22/Nov/2026:10:03:41] "GET /missing" 404 512
192.168.1.10 - - [22/Nov/2026:10:04:00] "GET /index.html" 500 0

```

`access.log` 按空格切分后的字段：

| 字段 | 内容 |
|:---:|------|
| `$1` | IP 地址 |
| `$4` | 时间（带 `[`） |
| `$5` | 请求方法（带前导引号），如 `"GET` |
| `$6` | 请求路径（带结尾引号），如 `/index.html"` |
| `$7` | 状态码 |
| `$8` | 响应字节数 |

## 4.1 基础文本工具

### `cut`：按列截取

```bash
cut -d, -f1 scores.csv         # -d 指定分隔符，-f 指定第几列 → name Alice Bob ...
cut -d, -f1,3 scores.csv       # 第 1 和第 3 列
cut -d, -f2- scores.csv        # 第 2 列到最后
cut -c1-3 scores.csv           # 按字符位置：每行前 3 个字符
cut -d: -f1 /etc/passwd        # 取出所有用户名
```

局限：分隔符只能是**单个字符**，且连续多个空格不会被合并。
遇到「不规则空白分隔」的文本，用 `awk` 更合适。

### `sort`：排序

```bash
sort words.txt                 # 默认按字典序（逐字符比较）
sort -r words.txt              # 倒序
sort -n numbers.txt            # 按数值排序（否则 10 会排在 2 前面）
sort -u words.txt              # 排序并去重
sort -t, -k3,3n scores.csv     # -t 指定分隔符，-k3,3 只按第 3 列排序，n 表示数值
sort -t, -k3,3nr scores.csv    # 第 3 列数值倒序
```

> 对比：`sort` 默认是字符串比较，所以 `10` 排在 `2` 前面，数字排序必须加 `-n`。

`sort` 的结果可能受**语言环境（locale）**影响（比如大小写、中文的排序规则）。
需要稳定的字节序时，可以这样：

```bash
LC_ALL=C sort file.txt
```

跳过表头排序的写法：

```bash
tail -n +2 scores.csv | sort -t, -k3,3nr
```

输出：

```
Carol,A,91
Alice,A,85
Eve,A,78
Bob,B,72
Dave,B,68
```

`tail -n +2` 表示「从第 2 行开始输出」，用来去掉表头。

### `uniq`：去重（只处理相邻的重复行）

```bash
uniq words.txt             # 只合并"相邻"的重复行
sort words.txt | uniq      # 所以通常要先 sort
sort words.txt | uniq -c   # -c：在每行前面加上出现次数
sort words.txt | uniq -d   # -d：只显示有重复的行
sort words.txt | uniq -u   # -u：只显示没有重复的行
```

### 经典组合：统计频次排行

```bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn
```

输出：

```
      3 192.168.1.10
      2 192.168.1.11
      1 192.168.1.12
```

（`uniq -c` 前面的空格对齐方式在不同系统上可能略有差异。）

### `wc`：统计

```bash
wc -l scores.csv        # 行数（输出：6 scores.csv）
wc -w scores.csv        # 单词数
wc -c scores.csv        # 字节数
wc -m scores.csv        # 字符数（多字节字符时与 -c 不同）
wc -l < scores.csv      # 只输出数字（没有文件名）
```

### `tr`：字符转换/删除/压缩

`tr` **只从 stdin 读**，不接受文件参数；它处理的是**单个字符**的映射，不是字符串。

```bash
echo "hello" | tr 'a-z' 'A-Z'            # HELLO（小写转大写）
echo "a,b,c" | tr ',' '\n'               # 把逗号换成换行，一行变三行
echo "hello world" | tr -d 'l'           # -d 删除字符：heo word
echo "a    b     c" | tr -s ' '          # -s 压缩连续重复字符：a b c
tr -d '\r' < dos.txt > unix.txt          # 去掉 Windows 的回车符 \r
echo "abc123" | tr -d '[:digit:]'        # 用字符类删除所有数字：abc
```

## 4.2 `grep`：搜索文本

`grep 模式 [文件...]`：输出匹配**模式**的行；没有文件参数时读 stdin。

### 常用选项

```bash
grep "404" access.log          # 含 404 的行
grep -i "get" access.log       # -i：忽略大小写
grep -v "404" access.log       # -v：反向，输出"不匹配"的行
grep -n "POST" access.log      # -n：显示行号
grep -c "404" access.log       # -c：只输出匹配的行数（这里是 2）
grep -w "GET" access.log       # -w：整词匹配
grep -o "[0-9.]*" file         # -o：只输出匹配的部分，而不是整行
grep -q "404" access.log       # -q：安静模式，不输出，只用退出状态表示有没有匹配
grep -A1 "POST" access.log     # -A n：匹配行及其后 n 行
grep -B1 "POST" access.log     # -B n：匹配行及其前 n 行
grep -C1 "POST" access.log     # -C n：前后各 n 行
```

递归搜索目录：

```bash
grep -r "main" .                       # 递归搜索当前目录下所有文件
grep -rn "TODO" src/                   # 递归并显示行号
grep -rl "printf" .                    # -l：只列出包含匹配的文件名
grep -r --include='*.c' "main" .       # 只在 .c 文件中搜索
```

### 退出状态

| 退出码 | 含义 |
|:---:|------|
| 0 | 找到了匹配 |
| 1 | 没有找到匹配 |
| 2 | 出错（如文件不存在） |

这一点在脚本里常用：

```bash
if grep -q "ERROR" app.log; then
    echo "发现错误"
fi
```

### 正则表达式基础

`grep` 默认使用**基本正则（BRE）**，加 `-E` 使用**扩展正则（ERE）**。
初学者建议**一律用 `grep -E`**，元字符更直观。

| 元字符 | 含义 | 例子 |
|:---:|------|------|
| `.` | 任意一个字符 | `a.c` 匹配 `abc`、`a1c` |
| `*` | 前一个字符出现 0 次或多次 | `ab*` 匹配 `a`、`ab`、`abb` |
| `+` | 前一个字符出现 1 次或多次（ERE） | `ab+` 匹配 `ab`、`abb` |
| `?` | 前一个字符出现 0 次或 1 次（ERE） | `colou?r` 匹配 `color`、`colour` |
| `^` | 行首 | `^GET` |
| `$` | 行尾 | `html$` |
| `[abc]` | 方括号内任意一个字符 | `[0-9]` 匹配任意数字 |
| `[^abc]` | 不在方括号内的任意一个字符 | `[^0-9]` |
| `a\|b`（表格转义，实际写作 `a|b`） | 或（ERE） | `cat\|dog` 匹配 `cat` 或 `dog`，命令里写 `grep -E 'cat|dog'` |
| `( )` | 分组（ERE） | `(ab)+` |
| `{n,m}` | 重复 n 到 m 次（ERE） | `[0-9]{1,3}` |
| `\` | 转义元字符 | `\.` 匹配字面上的点 |

> 注意表中「或」一行：在 `grep -E` 里直接写 `cat|dog` 即可，不需要反斜杠。

常用字符类（写在方括号里）：

| 字符类 | 含义 |
|--------|------|
| `[:digit:]` | 数字 |
| `[:alpha:]` | 字母 |
| `[:alnum:]` | 字母和数字 |
| `[:space:]` | 空白字符 |
| `[:upper:]` / `[:lower:]` | 大写 / 小写字母 |

写法：`[[:digit:]]+`（外面还要再套一层方括号）。

### 正则例子

```bash
grep -E '^192\.168\.1\.10' access.log            # 以 192.168.1.10 开头的行
grep -E ' (404|500) ' access.log                 # 状态码为 404 或 500
grep -E '"(GET|POST) ' access.log                # GET 或 POST 请求
grep -E '[0-9]{3} [0-9]+$' access.log            # 以"3位数字 空格 数字"结尾的行
grep -E '^[[:digit:]]+' file                     # 以数字开头
```

> 经验：**正则表达式总是用单引号括起来**，防止 Shell 提前解释其中的 `*`、`$`、`?` 等字符。

### 固定字符串：`grep -F`

当要搜索的内容含有很多特殊字符，又不需要正则功能时，用 `-F`（按字面匹配）：

```bash
grep -F "a.b*c" file       # 把 . 和 * 当普通字符
```

`grep -P`（Perl 正则）只在部分平台的 grep 上可用，不保证可移植，本教程不用。

## 4.3 `find`：查找文件

`grep` 是按**文件内容**找，`find` 是按**文件属性**（名字、类型、大小、时间等）找。

```
find [起始目录...] [条件] [动作]
```

### 按名称、类型

```bash
find . -name '*.c'              # 在当前目录下递归找所有 .c 文件
find . -iname 'readme*'         # -iname：忽略大小写
find /tmp -type f               # 只找普通文件（f 文件，d 目录，l 符号链接）
find . -type d -name 'src'      # 名为 src 的目录
```

> **重要**：`-name` 的模式必须**加引号**。否则 `*.c` 会先被 Shell 展开成当前目录里的文件名，
> 导致 find 收到的不是你想要的模式。

### 按大小、时间

```bash
find . -size +1M                # 大于 1 MB 的文件（-size -1M 是小于；GNU 还支持 k、G 等后缀）
find . -mtime -7                # 最近 7 天内修改过的文件
find . -mtime +7                # 修改时间超过 7 天的文件
find . -mmin -30                # 最近 30 分钟内修改过的文件
```

关于 `-mtime +7`：时间是按「整天」向下取整来比较的，所以 `+7` 实际指**至少 8 天以前**。
不需要精确边界时可以忽略这点，需要时请在本机用小文件试验。

### 限制深度、组合条件

```bash
find . -maxdepth 1 -name '*.txt'                  # 只看当前目录这一层，不递归
find . -name '*.c' -o -name '*.h'                 # 或：.c 或 .h
find . \( -name '*.c' -o -name '*.h' \) -type f   # 括号分组（要转义），再与其他条件"且"
find . -type f ! -name '*.log'                    # ! 取反：不是 .log 的文件
```

`find` 的多个条件默认是「且」；`-o` 是「或」；括号用来改变优先级，括号前要加反斜杠。
`-maxdepth` 建议放在其他条件之前（有些版本会对位置给出警告）。

### 对结果执行动作

```bash
find . -name '*.tmp' -print                  # 打印（默认动作，可省略）
find . -name '*.tmp' -delete                 # 直接删除（谨慎，先用 -print 预览）
find . -name '*.c' -exec wc -l {} \;         # 对每个文件执行一次命令，{} 代表当前文件
find . -name '*.c' -exec wc -l {} +          # 把多个文件合并成一次命令调用（效率更高）
```

> ⚠️ 删除类操作的安全做法：**先把 `-delete`/`-exec rm` 换成 `-print` 看一遍结果，确认无误再执行。**
> 另外，`-delete` 与其他条件的先后顺序会影响效果（它会对此前已匹配的结果生效），
> 写的时候不要把它放在条件前面。

## 4.4 `xargs`：把 stdin 变成命令的参数

回忆第 3 章：`rm`、`cp` 这类命令**不读 stdin**，所以 `find ... | rm` 是行不通的。
`xargs` 的作用就是：**读取 stdin，把内容拼成参数，再调用命令**。

```bash
echo "a b c" | xargs echo                  # 相当于运行：echo a b c
find . -name '*.tmp' | xargs rm            # 相当于：rm 文件1 文件2 ...
```

### 常用选项

```bash
echo "a b c" | xargs -n 1                  # -n 1：每次只传 1 个参数，分成 3 次调用，得到三行
echo "a b c" | xargs -n 2                  # 每次 2 个参数
ls *.txt | xargs -I{} cp {} {}.bak         # -I{}：指定占位符，每个输入分别替换进命令
```

### ⚠️ 文件名带空格的问题

默认 xargs 按**空白字符**分割输入，所以名字里有空格的文件会被拆成多个参数，导致误操作。
安全做法：用 `\0`（空字符）作分隔符：

```bash
find . -name '*.tmp' -print0 | xargs -0 rm
```

- `find -print0`：输出时用 `\0` 分隔
- `xargs -0`：读取时用 `\0` 分隔

`-print0` 和 `-0` 要成对使用。凡是处理文件名的 `find | xargs`，都建议这样写。

### 输入为空时

GNU 版本的 xargs 在没有输入时仍会运行一次命令，可以加 `-r` 避免；
其他版本（如 macOS 自带）的行为可能不同，以本机 `man xargs` 为准。

### `find -exec` 与 `xargs` 怎么选？

| | `find -exec cmd {} +` | `find -print0 \| xargs -0 cmd` |
|---|---|---|
| 处理含空格的文件名 | 安全 | 安全（需配合 `-print0` / `-0`） |
| 灵活性 | 只能接 find | 可以接任何产生输入的命令 |
| 写法 | 相对固定，记得转义 `\;` | 更像管道，易读 |

## 4.5 `sed`：流编辑器

`sed` 逐行读取输入，按指令编辑后输出。最常用的是**替换**。

### 替换：`s/旧/新/`

```bash
echo "hello world" | sed 's/world/shell/'          # hello shell
echo "a a a" | sed 's/a/b/'                        # b a a   （默认每行只替换第一个）
echo "a a a" | sed 's/a/b/g'                       # b b b   （g：全局替换）
sed 's/,/ | /g' scores.csv                         # 把逗号换成 " | "
```

分隔符不一定是 `/`，路径里有 `/` 时可以换成 `#` 等：

```bash
echo "/usr/bin" | sed 's#/usr#/opt#'               # /opt/bin
```

### 使用分组和反向引用

用 `-E` 启用扩展正则；`&` 代表整个匹配到的内容，`\1`、`\2` 代表第 1、2 个括号分组：

```bash
echo "2026-11-22" | sed -E 's/([0-9]+)-([0-9]+)-([0-9]+)/\3\/\2\/\1/'   # 22/11/2026
echo "abc" | sed 's/b/[&]/'                                              # a[b]c
```

### 按行号/模式选择行

```bash
sed -n '2p' scores.csv              # -n 配合 p：只打印第 2 行（-n 表示不自动打印每一行）
sed -n '2,4p' scores.csv            # 打印第 2~4 行
sed -n '$p' scores.csv              # 打印最后一行
sed '1d' scores.csv                 # 删除第 1 行（去表头）
sed '/^$/d' file                    # 删除空行
sed '/404/d' access.log             # 删除含 404 的行
sed -n '/POST/p' access.log         # 只打印含 POST 的行（相当于 grep）
sed 's/[[:space:]]*$//' file        # 去掉每行末尾的空白
```

### 多条指令

```bash
sed -e 's/A/X/' -e 's/B/Y/' scores.csv
sed 's/A/X/; s/B/Y/' scores.csv
```

### 原地修改文件：`-i`

```bash
sed -i.bak 's/old/new/g' file.txt     # 直接修改文件，并保留备份 file.txt.bak
```

⚠️ **平台差异**：GNU sed（Linux）里可以写 `sed -i 's/a/b/' file`，
而 macOS 自带的 BSD sed 要求 `-i` 后面必须跟备份后缀参数（可以是空字符串 `-i ''`）。
写法 `-i.bak`（后缀紧贴 `-i`）两边通常都可用，建议这样写，
并且在你的机器上先拿一个小文件测试再批量使用。

> 提醒：`sed` 默认**不会**修改原文件，只是把结果输出到屏幕；不加 `-i` 时，
> 想保存要自己重定向到新文件（不要重定向回原文件，见第 3 章的陷阱）。

## 4.6 `awk`：按字段处理文本

> **C 语言类比**：`awk` 的语法很像 C（花括号、`if`、`for`、`printf`、`++`），
> 对你来说上手会比较快。

`awk` 的基本结构：

```
awk '模式 { 动作 }' 文件
```

对每一行：如果满足**模式**，就执行**动作**。省略模式表示对所有行执行；省略动作表示打印整行。

### 内置变量

| 变量 | 含义 |
|------|------|
| `$0` | 整行 |
| `$1`、`$2`... | 第 1、2... 个字段 |
| `NF` | 当前行的字段数 |
| `$NF` | 最后一个字段 |
| `NR` | 当前行号（从输入开始累计） |
| `FS` | 输入字段分隔符（默认是空白） |
| `OFS` | 输出字段分隔符 |

### 基础用法

```bash
awk '{print $1}' access.log                  # 打印每行第 1 个字段（IP）
awk '{print $1, $7}' access.log              # 打印 IP 和状态码（逗号会输出为一个空格）
awk '{print NR, $0}' scores.csv              # 加行号
awk '{print $NF}' access.log                 # 每行的最后一个字段
awk -F, '{print $1, $3}' scores.csv          # -F, 指定逗号为分隔符
awk -F, '{print $1 " scored " $3}' scores.csv   # 字符串拼接：直接并排写
```

### 带条件的处理

```bash
awk '$7 == 404' access.log                         # 状态码等于 404 的行
awk '$7 >= 400 {print $1, $7}' access.log          # 状态码 >= 400，只打印 IP 和状态码
awk -F, 'NR > 1 && $3 >= 80 {print $1, $3}' scores.csv   # 跳过表头，成绩 >= 80
awk '/POST/' access.log                            # 含 POST 的行（正则匹配）
awk '$6 ~ /index/' access.log                      # 第 6 个字段匹配 index
```

输出示例（成绩 ≥ 80）：

```
Alice 85
Carol 91
```

### BEGIN 和 END：开始前、结束后

- `BEGIN { ... }`：在读第一行**之前**执行一次
- `END { ... }`：读完所有行**之后**执行一次

```bash
# 求平均分（NR - 1 排除表头）
awk -F, 'NR > 1 {sum += $3} END {print "平均分:", sum / (NR - 1)}' scores.csv
```

输出：

```
平均分: 78.8
```

```bash
# 统计总字节数
awk '{bytes += $8} END {print bytes}' access.log          # 3328
```

### 关联数组：分组统计

awk 的数组下标可以是字符串，非常适合分组统计：

```bash
# 统计每种状态码出现的次数
awk '{count[$7]++} END {for (code in count) print code, count[code]}' access.log
```

输出（**遍历顺序不保证**，不同实现可能不同）：

```
200 3
404 2
500 1
```

```bash
# 每个班级的平均分
awk -F, 'NR > 1 {sum[$2] += $3; n[$2]++}
         END {for (c in sum) printf "%s %.1f\n", c, sum[c] / n[c]}' scores.csv
```

输出（顺序同样不保证）：

```
A 84.7
B 70.0
```

### 格式化输出：`printf`

```bash
awk -F, 'NR > 1 {printf "%-8s %3d\n", $1, $3}' scores.csv
```

`printf` 的格式串与 C 的完全一致（`%s`、`%d`、`%f`、`%-8s` 等）；注意 awk 的 `printf` 不会自动换行，需要自己写 `\n`。

### 向 awk 传入 Shell 变量

```bash
min=80
awk -F, -v min="$min" 'NR > 1 && $3 >= min {print $1}' scores.csv
```

用 `-v 变量名=值` 传入，不要把 Shell 变量直接拼在 awk 程序的单引号里。

> awk 有多个实现（如 gawk、mawk、BSD awk），本章只用各实现通用的基本功能。
> 一些高级功能（如排序函数）仅限 gawk，不在这里展开。

## 4.7 综合实战：日志分析

用 `access.log` 回答几个问题：

**1. 访问次数最多的 IP（前 2 名）**

```bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -n 2
```

**2. 所有 404 请求访问了哪些路径**

```bash
awk '$7 == 404 {print $6}' access.log | tr -d '"' | sort -u
```

输出：

```
/about.html
/missing
```

**3. 每个 IP 产生的流量字节数**

```bash
awk '{bytes[$1] += $8} END {for (ip in bytes) print ip, bytes[ip]}' access.log | sort
```

**4. 错误率（状态码 >= 400 的请求占比）**

```bash
awk '{total++} $7 >= 400 {err++} END {printf "%.1f%%\n", err / total * 100}' access.log
```

输出：`50.0%`（6 条请求中有 3 条是 404 或 500）。

## 4.8 工具选择速查

| 想做的事 | 首选工具 |
|---------|---------|
| 按分隔符取某几列（简单情形） | `cut` |
| 排序、去重、统计频次 | `sort`、`uniq -c` |
| 统计行数/字数 | `wc` |
| 字符替换、删除、压缩 | `tr` |
| 找出包含某内容的行 | `grep` |
| 找文件（按名字/时间/大小） | `find` |
| 把一批结果交给另一个命令处理 | `xargs` 或 `find -exec` |
| 文本替换、删行、取行范围 | `sed` |
| 按字段处理、条件过滤、计算、分组统计 | `awk` |

经验：能用 `grep`/`cut` 解决的就别上 `awk`，需要计算或分组统计时再用 `awk`。

## 本章小结

- 过滤器工具通过管道串联：`cut` / `sort` / `uniq` / `wc` / `tr`，其中 `uniq` 只处理**相邻**重复行，通常要先 `sort`。
- `grep -E` 配合正则表达式搜索，**模式用单引号括起来**，退出状态可用于脚本判断。
- `find` 按属性找文件，`-name` 的模式要加引号；删除前先 `-print` 预览。
- `xargs` 把 stdin 变成参数；处理文件名用 `find -print0 | xargs -0`。
- `sed 's/旧/新/g'` 做替换；`-n` 配合 `p` 取行；`-i` 有平台差异。
- `awk` 按字段处理：`$1`、`NF`、`NR`、`BEGIN/END`、关联数组，写法类似 C。

用本章准备的 `scores.csv` 和 `access.log`：

1. 只输出 `scores.csv` 中所有学生的姓名（不含表头）。
2. 按成绩从高到低输出所有学生（不含表头）。
3. 统计 `access.log` 中有多少行包含 `GET`。
4. 找出请求了 `/index.html` 的所有 IP（去重）。
5. 用 `sed` 把 `scores.csv` 里的逗号全部换成制表符，并输出到屏幕。
6. 用 `awk` 输出 `scores.csv` 中班级为 `A` 且成绩大于 80 的学生姓名。
7. 用 `awk` 计算 `scores.csv` 的最高分（提示：用一个变量记录当前最大值）。
8. 在 `~/shell-lab` 下用 `find` 找出所有 `.txt` 文件，并统计一共有多少个。
9. 用 `find` 和 `xargs`（带 `-print0` 和 `-0`）对 `~/shell-lab` 下所有 `.txt` 文件执行 `wc -l`。
10. 统计 `access.log` 中状态码为 200 的请求总字节数。

### 参考答案

```bash
# 1
tail -n +2 scores.csv | cut -d, -f1
# 2
tail -n +2 scores.csv | sort -t, -k3,3nr
# 3
grep -c "GET" access.log
# 4
grep "/index.html" access.log | awk '{print $1}' | sort -u
# 5
sed 's/,/\t/g' scores.csv      # 注意：\t 在 GNU sed 中可用；BSD sed 可能不支持，可改用 tr ',' '\t'
# 6
awk -F, 'NR > 1 && $2 == "A" && $3 > 80 {print $1}' scores.csv
# 7
awk -F, 'NR > 1 && $3 > max {max = $3} END {print max}' scores.csv
# 8
find ~/shell-lab -name '*.txt' | wc -l
# 9
find ~/shell-lab -name '*.txt' -print0 | xargs -0 wc -l
# 10
awk '$7 == 200 {sum += $8} END {print sum}' access.log
```

参考答案要点：

- 第 4 题：`/index.html` 实际在日志里是带结尾引号的（`/index.html"`），用 `grep` 做子串匹配即可，不受影响。
- 第 5 题：这是一个平台差异的例子，遇到不支持 `\t` 时 `tr ',' '\t'` 是更通用的替代。
- 第 7 题：未初始化的 awk 变量默认为 0（比较时按数值处理），所以成绩全为正数时这样写没问题。
- 第 10 题：200 的行为 1024 + 256 + 1024 = 2304。

## 常见问题速查

| 现象 | 可能原因 |
|------|---------|
| `uniq` 没有去重 | 重复行不相邻，先 `sort` |
| `sort -n` 后顺序仍不对 | 目标列没有指定，加 `-k` 与 `-t` |
| `grep` 搜不到含特殊字符的内容 | 字符被当成正则，用 `-F` 或转义 |
| `find -name *.c` 行为奇怪 | 忘了给模式加引号，被 Shell 提前展开 |
| `xargs rm` 误删/报错 | 文件名含空格，改用 `-print0 \| xargs -0` |
| `sed -i` 在 macOS 报错 | BSD sed 要求备份后缀参数，用 `-i.bak` 并先测试 |
| awk 输出顺序每次不同 | `for (k in arr)` 的遍历顺序不保证，需要时再用 `sort` 排序 |
