# 第 6 章　条件判断与流程控制

## 本章目标

- 理解退出状态码：Shell 里「0 表示成功」，和 C 的真假正好相反
- 掌握 `&&`、`||` 的短路组合
- 会用 `test`、`[ ]`、`[[ ]]` 做字符串、数值、文件判断
- 会用 `if`、`case`、`for`、`while`、`until`、`break`、`continue`

---

## 6.1 退出状态码与逻辑组合

### 每个命令都有退出状态码

命令结束时会返回一个 0~255 的整数，叫**退出状态码**（exit status）。

- **0 表示成功**
- **非 0 表示失败**（不同数字代表不同的错误原因，具体含义由命令自己定义）

用 `$?` 查看**上一条命令**的退出状态：

```bash
ls /tmp
echo $?                  # 0

ls /nonexistent
echo $?                  # 非 0（具体数字取决于 ls 的实现，如 1 或 2）

grep -q "root" /etc/passwd
echo $?                  # 0 表示找到，1 表示没找到
```

> ⚠️ **与 C 语言正好相反**：C 里 `0` 是假、非 0 是真；
> Shell 里"状态码 0"表示成功，在 `if` 里相当于**真**，非 0 相当于**假**。
> 这是因为"成功只有一种，失败有很多种"，所以用 0 表示成功，用不同非 0 值表示不同错误。
>
> 另外，`(( ))` 算术命令是按 C 的风格判断的（表达式值非 0 才算真），上一章讲过，不要混淆。

`$?` 每执行一条命令就会被刷新。如果后面还要用，先保存起来：

```bash
grep -q "foo" file.txt
rc=$?                    # 立即保存
echo "grep 返回了 $rc"
```

### `true`、`false`、`exit`

```bash
true;  echo $?           # 0
false; echo $?           # 1
```

脚本里用 `exit n` 以状态码 n 结束（类似 C 的 `exit(n)`）。不指定时，脚本的状态码是**最后一条执行的命令**的状态码。

### `&&`、`||`、`;`、`!`

| 写法 | 含义 |
|------|------|
| `A ; B` | 先 A 后 B，不管 A 成不成功 |
| `A && B` | A **成功**才执行 B |
| `A \|\| B` | A **失败**才执行 B |
| `! A` | 对 A 的状态取反 |

```bash
mkdir -p build && cd build                      # 创建成功才进入
cd /some/dir || echo "进入目录失败" >&2           # 失败才报错
[ -f config.txt ] || touch config.txt           # 不存在才创建
```

失败后退出脚本，常见写法：

```bash
cd /some/dir || { echo "cd 失败" >&2; exit 1; }
```

花括号 `{ ...; }` 把多条命令合成一组（注意 `{` 后要有空格，最后一条命令后要有分号或换行）。

### ⚠️ `A && B || C` 不等于 if-else

```bash
[ -f a.txt ] && echo "存在" || echo "不存在"
```

如果 `[ -f a.txt ]` 成立，但 `echo "存在"` 因某种原因失败（返回非 0），也会执行 `echo "不存在"`。
简单场景无所谓，重要逻辑请使用正式的 `if`。

## 6.2 条件测试

`if` 判断的其实是**一条命令的退出状态**，而 `[` 本身就是一个命令（与 `test` 等价）。
所以才有那些让人困惑的空格规则。

```bash
test -f a.txt           # 等价于
[ -f a.txt ]            # [ 是命令，] 是它的最后一个参数
```

### `[ ]` 的格式要点

```bash
[ "$a" = "$b" ]         # ✅ [ 后和 ] 前必须有空格；= 两边必须有空格
["$a" = "$b"]           # ❌ [: command not found
[ "$a"="$b" ]           # ❌ 变成只有一个参数，永远为真
```

### 字符串测试

| 写法 | 含义 |
|------|------|
| `[ "$a" = "$b" ]` | 相等（POSIX 写法是单个 `=`；bash 的 `[ ]` 也接受 `==`） |
| `[ "$a" != "$b" ]` | 不相等 |
| `[ -z "$a" ]` | 字符串为**空**（长度为 0） |
| `[ -n "$a" ]` | 字符串**非空** |

### 数值测试（注意：不是 `=`、`>`、`<`）

| 写法 | 含义 |
|------|------|
| `[ "$a" -eq "$b" ]` | 等于（equal） |
| `[ "$a" -ne "$b" ]` | 不等于 |
| `[ "$a" -lt "$b" ]` | 小于（less than） |
| `[ "$a" -le "$b" ]` | 小于等于 |
| `[ "$a" -gt "$b" ]` | 大于（greater than） |
| `[ "$a" -ge "$b" ]` | 大于等于 |

```bash
[ 10 = 10.0 ]     # 假：字符串比较，"10" 和 "10.0" 不同
[ 10 -eq 10 ]     # 真：数值比较
```

> 在 `[ ]` 里，`<` 和 `>` 会被 Shell 当成**重定向**符号，会悄悄创建文件！
> 数值比较用 `-lt`/`-gt`，或者改用 `(( ))` 与 `[[ ]]`。

### 文件测试

| 写法 | 含义 |
|------|------|
| `-e 路径` | 存在（文件或目录） |
| `-f 路径` | 是普通文件 |
| `-d 路径` | 是目录 |
| `-L 路径` | 是符号链接 |
| `-r` / `-w` / `-x` | 可读 / 可写 / 可执行 |
| `-s 路径` | 文件存在且大小大于 0 |

```bash
file="notes.txt"
[ -e "$file" ] && echo "存在"
[ -d /tmp ] && echo "/tmp 是目录"
[ -x ./run.sh ] || echo "run.sh 不可执行"
```

### 逻辑组合

```bash
[ -f a.txt ] && [ -r a.txt ]           # 且：推荐写法，用两个 [ ] 加 &&
[ -f a.txt ] || [ -d a.txt ]           # 或
[ ! -f a.txt ]                         # 非
```

`[ A -a B ]` 和 `[ A -o B ]` 虽然存在，但在参数复杂时有歧义，**不推荐**。

### `[ ]` 的两个经典陷阱

**陷阱 1：变量不加引号，且为空**

```bash
x=""
[ $x = "a" ]        # 展开后是 [ = "a" ]，报错 unary operator expected
[ "$x" = "a" ]      # ✅
```

**陷阱 2：`-n` 不加引号**

```bash
x=""
[ -n $x ] && echo "非空"      # ❌ 会输出"非空"！展开后是 [ -n ]，单个参数只要非空字符串就算真
[ -n "$x" ] && echo "非空"    # ✅ 不输出
```

### `[[ ]]`：bash 的增强版（bash/zsh 特性，非 POSIX）

- 不做单词拆分，变量即使为空/含空格，**不加引号也不会出错**（但仍建议加）
- 支持 `&&`、`||` 直接写在里面
- 支持**模式匹配**和**正则匹配**
- `<`、`>` 可以直接做字符串比较，不会被当作重定向

```bash
[[ -f $file && -r $file ]]         # 逻辑运算在内部完成
[[ $name == A* ]]                  # 模式匹配：以 A 开头（右边不加引号，才是通配符）
[[ $file == *.txt ]]               # 以 .txt 结尾
[[ "$name" == "A*" ]]              # 右边加引号：当作字面字符串，匹配的是 "A*" 本身
[[ $s =~ ^[0-9]+$ ]]               # 正则匹配：全是数字
[[ "apple" < "banana" ]]           # 字符串字典序比较
```

### `(( ))`：数值比较的 C 风格写法

```bash
a=5; b=3
if (( a > b )); then echo "a 更大"; fi
if (( a % 2 == 1 )); then echo "奇数"; fi
```

### 选择建议

| 场景 | 推荐 |
|------|------|
| 需要可移植（可能在 sh/dash 下运行） | `[ ]`，并严格给变量加引号 |
| 只用 bash | 字符串/文件判断用 `[[ ]]`，数值判断用 `(( ))` |

## 6.3 `if` 语句

### 基本结构

```bash
if 条件命令; then
    命令...
elif 条件命令; then
    命令...
else
    命令...
fi
```

`if` 后面可以是**任何命令**，只看它的退出状态：

```bash
if grep -q "root" /etc/passwd; then
    echo "找到 root"
fi

if ! ping -c 1 -W 1 127.0.0.1 > /dev/null 2>&1; then     # ping 的 -W 选项在不同系统含义略有差异
    echo "网络不通"
fi
```

### 例子 1：判断文件

```bash
file="${1:-notes.txt}"

if [ ! -e "$file" ]; then
    echo "文件不存在: $file" >&2
    exit 1
elif [ -d "$file" ]; then
    echo "$file 是目录"
elif [ -s "$file" ]; then
    echo "$file 是非空文件"
else
    echo "$file 是空文件"
fi
```

### 例子 2：成绩分级

```bash
score=85
if [ "$score" -ge 90 ]; then
    echo "A"
elif [ "$score" -ge 80 ]; then
    echo "B"
elif [ "$score" -ge 60 ]; then
    echo "C"
else
    echo "D"
fi
```

### 例子 3：检查参数个数

```bash
if [ $# -ne 2 ]; then
    echo "用法: $0 <源> <目标>" >&2
    exit 2
fi
```

## 6.4 `case` 语句

`case` 用**模式**匹配一个值，对应 C 的 `switch`，但更强大：

```bash
case "$value" in
    模式1)  命令... ;;
    模式2|模式3)  命令... ;;
    *)      默认命令... ;;
esac
```

- 模式支持通配符 `*`、`?`、`[ ]`，用 `|` 表示"或"
- 每个分支以 `;;` 结束（相当于 C 里自动带了 `break`，**不会"穿透"到下一分支**）
- `*)` 放在最后，相当于 `default`

```bash
case "$1" in
    start)
        echo "启动服务"
        ;;
    stop|halt)
        echo "停止服务"
        ;;
    restart)
        echo "重启服务"
        ;;
    "")
        echo "缺少参数" >&2
        exit 1
        ;;
    *)
        echo "未知命令: $1" >&2
        exit 1
        ;;
esac
```

按文件扩展名处理：

```bash
case "$file" in
    *.tar.gz|*.tgz) echo "gzip 压缩包" ;;
    *.zip)          echo "zip 压缩包" ;;
    *.[ch])         echo "C 源码或头文件" ;;
    *)              echo "未知类型" ;;
esac
```

交互确认（`y` / `n`）：

```bash
read -r -p "确认继续？[y/N] " ans      # -p 显示提示语（bash 特性）
case "$ans" in
    [yY]|[yY][eE][sS]) echo "继续" ;;
    *)                 echo "取消"; exit 0 ;;
esac
```

## 6.5 `for` 循环

### 遍历一组值

```bash
for i in 1 2 3; do
    echo "第 $i 次"
done

for name in alice bob carol; do
    echo "Hello, $name"
done
```

### 遍历文件（通配符）

```bash
for f in *.txt; do
    echo "处理 $f"
done
```

> ⚠️ 如果没有任何文件匹配 `*.txt`，bash 默认会把 `*.txt` 原样当成一个值，循环体会执行一次。
> 稳妥写法：循环体开头加一行判断：
>
> ```bash
> for f in *.txt; do
>     [ -e "$f" ] || continue
>     echo "处理 $f"
> done
> ```

批量改扩展名（上一章的参数展开派上用场了）：

```bash
for f in *.txt; do
    [ -e "$f" ] || continue
    mv -- "$f" "${f%.txt}.bak"
done
```

### 数字序列

```bash
for i in {1..5}; do echo "$i"; done          # 花括号展开（bash/zsh）
for i in $(seq 1 5); do echo "$i"; done      # seq 命令（常见系统都有，但不属于 POSIX 标准）
```

> `{1..$n}` 是**不能**用变量的（花括号展开发生在变量展开之前）。需要变量作上限时，用 `seq` 或下面的 C 风格。

### C 风格 `for`（bash 特性）

```bash
for ((i = 0; i < 5; i++)); do
    echo "i = $i"
done
```

### 遍历数组

```bash
fruits=(apple "banana split" cherry)
for f in "${fruits[@]}"; do
    echo "[$f]"
done
```

### 遍历命令行参数

```bash
for arg in "$@"; do      # 省略 in "$@" 时，for 默认也遍历位置参数
    echo "参数: $arg"
done
```

### ⚠️ 不要用 `for` 遍历 `$(cat file)` 或 `$(ls)`

```bash
for line in $(cat file.txt); do ...     # ❌ 按空白拆分，一行里有空格就被拆成多个词
```

按行读取文件应该用 `while read`（见下）。

## 6.6 `while` 和 `until` 循环

### `while`：条件为真时重复

```bash
count=1
while [ "$count" -le 5 ]; do
    echo "count = $count"
    count=$((count + 1))
done
```

死循环：

```bash
while true; do
    echo "运行中..."
    sleep 1
done          # 按 Ctrl+C 中断
```

### `until`：条件为**假**时重复（与 `while` 相反）

```bash
n=0
until [ "$n" -ge 3 ]; do
    echo "n = $n"
    n=$((n + 1))
done
```

### 逐行读取文件：`while read`

```bash
while IFS= read -r line; do
    echo "读到: $line"
done < file.txt
```

写法解释：

- `read -r line`：读一行存入 `line`；`-r` 表示不处理反斜杠转义，**几乎总是应该加上**
- `IFS=`：清空分隔符，防止行首行尾的空白被吞掉
- `done < file.txt`：把整个循环的标准输入重定向到文件

如果文件**最后一行没有换行符**，`read` 会返回失败，最后一行被漏掉。保险写法：

```bash
while IFS= read -r line || [ -n "$line" ]; do
    echo "读到: $line"
done < file.txt
```

### 按分隔符切分字段

把 CSV 每一行拆成多个变量：

```bash
# scores.csv 见第 4 章
while IFS=, read -r name class score; do
    [ "$name" = "name" ] && continue          # 跳过表头
    if [ "$score" -ge 90 ]; then grade=A
    elif [ "$score" -ge 80 ]; then grade=B
    elif [ "$score" -ge 70 ]; then grade=C
    else grade=D
    fi
    echo "$name $score $grade"
done < scores.csv
```

输出：

```
Alice 85 B
Bob 72 C
Carol 91 A
Dave 68 D
Eve 78 C
```

> 提示：不要写成 `cat file | while read ...`。管道右边的循环在**子 Shell**里运行，
> 循环里改变的变量在循环结束后会丢失，第 7 章会详细解释。直接用 `done < file`。

## 6.7 `break` 和 `continue`

和 C 语言一样：

- `break`：跳出整个循环
- `continue`：跳过本次循环剩余部分，进入下一轮
- `break n` / `continue n`：对嵌套循环，跳出/继续外面第 n 层

```bash
for i in {1..10}; do
    [ $((i % 2)) -eq 0 ] && continue       # 跳过偶数
    [ "$i" -gt 7 ] && break                # 超过 7 就结束
    echo "$i"
done
# 输出: 1 3 5 7
```

## 6.8 综合例子

### 例子 1：1 到 100 求和

```bash
sum=0
for ((i = 1; i <= 100; i++)); do
    sum=$((sum + i))
done
echo "总和: $sum"        # 5050
```

### 例子 2：FizzBuzz

```bash
for i in {1..15}; do
    if (( i % 15 == 0 )); then echo "FizzBuzz"
    elif (( i % 3 == 0 )); then echo "Fizz"
    elif (( i % 5 == 0 )); then echo "Buzz"
    else echo "$i"
    fi
done
```

### 例子 3：重试直到成功

```bash
max=5
attempt=1
until curl -fsS -o /dev/null https://example.com; do      # 命令成功才结束循环
    if [ "$attempt" -ge "$max" ]; then
        echo "重试 $max 次仍然失败" >&2
        exit 1
    fi
    echo "第 $attempt 次失败，2 秒后重试..."
    attempt=$((attempt + 1))
    sleep 2
done
echo "成功"
```

### 例子 4：统计目录下各类文件数量

```bash
files=0; dirs=0; others=0
for item in ./*; do
    [ -e "$item" ] || continue
    if [ -f "$item" ]; then files=$((files + 1))
    elif [ -d "$item" ]; then dirs=$((dirs + 1))
    else others=$((others + 1))
    fi
done
echo "文件: $files, 目录: $dirs, 其他: $others"
```

## 本章小结

- 退出状态码：**0 成功（真）、非 0 失败（假）**，和 C 相反；`$?` 取上一条命令的状态。
- `&&`、`||` 做短路组合，但 `A && B || C` 不等于 if-else。
- `[ ]` 是命令，空格不能省，变量必须加引号；数值比较用 `-eq -lt -gt` 等；`[[ ]]`、`(( ))` 更方便但只限 bash 等。
- `if` 判断的是命令的退出状态，所以可以直接把 `grep -q ...` 等命令放在条件位置。
- `case` 是模式匹配的多分支，分支以 `;;` 结束，不会穿透。
- 循环：`for`（遍历列表/文件/数组）、`while`、`until`；按行读文件用 `while IFS= read -r line; do ...; done < file`。

## 练习

1. 写一个脚本，接收一个文件名参数：不存在则报错退出（状态码 1），是目录则提示"这是目录"，否则输出"文件大小"（可用 `wc -c < "$file"`）。
2. 写脚本判断一个整数是奇数还是偶数，要求使用 `case` 或 `if`（参数通过 `$1` 传入，没传参数时给出用法提示）。
3. 用 `for` 把当前目录下所有 `.log` 文件改名为 `.log.old`，要考虑没有匹配文件的情况。
4. 用 `while` 读取 `/etc/passwd`（或你自己建的类似文件，用 `:` 分隔），输出每个用户名和它的登录 Shell（第 1 和最后一个字段）。
5. 用 `case` 实现一个小脚本：参数是 `start`、`stop`、`status` 时分别输出对应提示，其他情况输出用法并退出状态码 1。
6. 写一个"猜数字"小游戏：预设答案（或用 `$((RANDOM % 100 + 1))`），循环读取输入，提示"大了/小了/猜对了"。
7. 解释为什么 `[ -n $x ]` 在 `x` 为空时仍然为真，应如何修改。
8. 输出 1~100 中所有能被 7 整除的数，遇到大于 50 的数就结束。

### 参考答案要点

```bash
# 1
file="$1"
if [ ! -e "$file" ]; then echo "不存在" >&2; exit 1
elif [ -d "$file" ]; then echo "这是目录"
else echo "大小: $(wc -c < "$file") 字节"
fi

# 2
n="$1"
[ -z "$n" ] && { echo "用法: $0 <整数>" >&2; exit 2; }
if (( n % 2 == 0 )); then echo "偶数"; else echo "奇数"; fi

# 3
for f in *.log; do
    [ -e "$f" ] || continue
    mv -- "$f" "$f.old"
done

# 4
while IFS=: read -r user _ _ _ _ _ shell; do
    echo "$user $shell"
done < /etc/passwd

# 6（核心部分）
answer=$((RANDOM % 100 + 1))
while true; do
    read -r -p "猜一个 1~100 的数: " g
    if [ "$g" -lt "$answer" ]; then echo "小了"
    elif [ "$g" -gt "$answer" ]; then echo "大了"
    else echo "猜对了"; break
    fi
done

# 8
for i in {1..100}; do
    [ "$i" -gt 50 ] && break
    (( i % 7 == 0 )) && echo "$i"
done
```

- 第 7 题：`[ -n $x ]` 展开后是 `[ -n ]`，单个参数时只要它是非空字符串（这里是 `-n` 这两个字符）就判定为真；应写成 `[ -n "$x" ]`。

## 常见问题速查

| 现象 | 原因 |
|------|------|
| `[: missing ]` / `[: command not found` | `[` 后或 `]` 前少了空格 |
| `unary operator expected` | 变量为空且没加引号 |
| `integer expression expected` | 用 `-eq` 等比较了非整数（如空串或带小数） |
| `[ a > b ]` 悄悄创建了名为 b 的文件 | `>` 被当作重定向，改用 `-gt`/`[[ ]]`/`(( ))` |
| `syntax error near unexpected token 'fi'` / `'done'` | `then`/`do` 前缺少分号或换行，或关键字配对错误 |
| `for` 遍历文件时出现字面的 `*.txt` | 没有匹配文件，加 `[ -e "$f" ] \|\| continue` |
