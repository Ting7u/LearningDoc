# Linux 操作系统学习笔记：快捷键 + 文件类型 + 目录结构

> 本文档整理了 Linux 日常使用中最常用的快捷键(按功能分类),并附上文件类型与系统目录结构，作为系统编程学习的配套速查表。

---

## 一、Shell / Bash 命令行快捷键（Readline 快捷键）

这些快捷键在几乎所有基于 GNU Readline 的场景下都生效：bash、zsh、Python 的 REPL、MySQL 客户端等。

### 1. 光标移动

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `Ctrl + A` | 光标移到行首 | 输错了命令开头的选项，快速跳回行首修改 |
| `Ctrl + E` | 光标移到行尾 | 命令写到一半想在末尾追加参数 |
| `Alt + B` | 向左跳一个单词 | 在 `git commit -m "fix bug"` 中快速跳到 `commit` |
| `Alt + F` | 向右跳一个单词 | 同上，反方向 |
| `Ctrl + F` / `→` | 光标右移一个字符 | 精细调整光标位置 |
| `Ctrl + B` / `←` | 光标左移一个字符 | 同上 |

### 2. 文本编辑 / 删除

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `Ctrl + U` | 删除光标到行首的所有内容 | 命令写错了想整行重来（保留光标右边部分） |
| `Ctrl + K` | 删除光标到行尾的所有内容 | 命令后半段不要了 |
| `Ctrl + W` | 删除光标前一个单词 | 打错了最后一个参数，如 `ls -la /hoem` → `Ctrl+W` 删掉 `/hoem` 重打 |
| `Alt + D` | 删除光标后一个单词 | 和 Ctrl+W 相反方向 |
| `Ctrl + H` | 删除光标前一个字符（等同 Backspace） | |
| `Ctrl + D` | 删除光标处一个字符；行为空时表示退出终端/EOF | 在空命令行按 `Ctrl+D` 可以直接退出当前 shell |
| `Ctrl + Y` | 粘贴上一次被 Ctrl+U/K/W 删除的内容（yank） | 误删后想恢复 |
| `Ctrl + T` | 交换光标前两个字符 | 打字手误后快速纠正，如 `sl` → `ls` |

### 3. 历史命令

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `↑` / `↓` | 上一条 / 下一条历史命令 | 重复执行刚才的命令 |
| `Ctrl + R` | 反向搜索历史命令（增量搜索） | 输入 `Ctrl+R` 后打 `ssh`，会自动跳到最近一条含 ssh 的历史命令；再按一次 `Ctrl+R` 跳到更早的匹配 |
| `Ctrl + G` | 退出历史搜索，不使用匹配结果 | 搜索到一半发现不是想要的 |
| `!!` | 重复执行上一条命令 | `sudo !!`：上一条命令因权限不够失败，直接加 sudo 重跑 |
| `!$` | 上一条命令的最后一个参数 | `mkdir /tmp/test` 之后 `cd !$` 直接进入 `/tmp/test` |
| `!字符串` | 执行历史中最近一条以该字符串开头的命令 | `!vim` 重新执行最近一次 vim 命令 |

### 4. 进程与任务控制

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `Ctrl + C` | 发送 SIGINT，终止当前前台进程 | 一个脚本陷入死循环，`Ctrl+C` 强制中断 |
| `Ctrl + Z` | 发送 SIGTSTP，将当前进程挂起到后台（暂停） | vim 编辑中临时想执行别的命令，`Ctrl+Z` 挂起后用 `fg` 恢复 |
| `Ctrl + D` | 发送 EOF（文件结束符） | 在 `cat` 命令等待标准输入时，按 `Ctrl+D` 结束输入 |
| `Ctrl + S` | 暂停终端输出（锁屏） | 输出刷屏太快想暂停看一下 |
| `Ctrl + Q` | 恢复终端输出 | 配合 Ctrl+S 使用 |
| `Ctrl + L` | 清屏（等同 `clear` 命令，但不清历史） | 屏幕太乱想清空 |

### 5. 自动补全

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `Tab` | 自动补全命令/路径/参数 | 输入 `cd /us` 按 Tab 补全为 `/usr/` |
| `Tab Tab`（连按两次） | 列出所有可能的补全项 | 不确定补全歧义时查看候选列表 |

## 二、Vim 编辑器快捷键

Vim 是 Linux 系统编程中最常用的编辑器之一，核心是**模式切换**。

### 1. 模式切换

| 快捷键       | 作用                 |
| --------- | ------------------ |
| `i`       | 从普通模式进入插入模式（光标前插入） |
| `a`       | 插入模式（光标后插入）        |
| `o` / `O` | 插入模式（在下方/上方新建一行）   |
| `Esc`     | 回到普通模式             |
| `:`       | 进入命令模式（底部命令行）      |
| `v`       | 进入可视模式（字符选择）       |
| `V`       | 进入可视行模式（整行选择）      |
|           |                    |

### 2. 移动（普通模式下）

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `h j k l` | 左 下 上 右 | 不用方向键即可移动光标 |
| `w` / `b` | 跳到下一个/上一个单词开头 | 快速跨单词移动 |
| `0` / `$` | 跳到行首 / 行尾 | |
| `gg` / `G` | 跳到文件开头 / 结尾 | 快速定位到文件头尾 |
| `:数字 + Enter` | 跳转到指定行号 | `:42` 跳到第 42 行 |
| `Ctrl + F` / `Ctrl + B` | 向下/向上翻一屏 | 浏览长文件 |

### 3. 编辑

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `dd` | 删除当前行（剪切） | |
| `yy` | 复制当前行 | |
| `p` / `P` | 在光标后/前粘贴 | 配合 dd/yy 移动整行代码 |
| `x` | 删除光标处一个字符 | |
| `u` | 撤销上一步操作 | 改错了快速撤回 |
| `Ctrl + R` | 重做（撤销的撤销） | |
| `.` | 重复上一次编辑操作 | 连续多次执行同一修改 |
| `dw` | 删除一个单词 | |
| `cw` | 修改一个单词（删除并进入插入模式） | |

### 4. 查找与替换

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `/关键词` | 向下查找 | `/error` 查找日志里的 error |
| `?关键词` | 向上查找 | |
| `n` / `N` | 跳到下一个/上一个匹配 | |
| `:%s/old/new/g` | 全文替换 old 为 new | 批量替换变量名 |
| `:s/old/new/g` | 当前行替换 | |

### 5. 保存与退出

| 快捷键 | 作用 |
|---|---|
| `:w` | 保存 |
| `:q` | 退出（无修改时） |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | 强制退出，不保存修改 |

## 三、tmux 会话管理快捷键（可选，适合服务器远程操作）

tmux 让你在一个终端窗口内管理多个会话，即使断网也能保持进程运行，系统编程/远程开发常用。

| 快捷键 | 作用 | 示例场景 |
|---|---|---|
| `tmux new -s 名字` | 创建新命名会话 | `tmux new -s dev` |
| `Ctrl+B` 然后 `d` | 分离（detach）当前会话，程序继续在后台运行 | SSH 断线也不影响服务器上跑的编译任务 |
| `tmux attach -t 名字` | 重新连接到指定会话 | 回到之前分离的 `dev` 会话 |
| `Ctrl+B` 然后 `%` | 垂直分屏 | 一边写代码一边看日志 |
| `Ctrl+B` 然后 `"` | 水平分屏 | |
| `Ctrl+B` 然后 方向键 | 在分屏窗格间切换 | |
| `Ctrl+B` 然后 `c` | 新建窗口（类似浏览器新标签页） | |
| `Ctrl+B` 然后 数字键 | 切换到对应编号的窗口 | |

## 四、Linux 文件类型

用 `ls -l` 第一列的首字符区分：

| 符号 | 类型 | 说明 |
|---|---|---|
| `-` | 普通文件 | 文本、二进制程序、压缩包等常规文件 |
| `d` | 目录 | directory，存储文件名到 inode 的映射 |
| `l` | 符号链接 | symbolic link，类似快捷方式，指向另一路径 |
| `b` | 块设备文件 | block device，按块随机读写，如硬盘 `/dev/sda` |
| `c` | 字符设备文件 | character device，按字符流顺序读写，如 `/dev/tty`、`/dev/null` |
| `p` | 命名管道 | named pipe / FIFO，用于进程间通信 |
| `s` | 套接字文件 | socket，用于本地 IPC，如 `/var/run/docker.sock` |

验证命令：

```bash
ls -l /dev | head       # 查看设备文件类型
file /bin/ls            # 查看具体文件类型
stat /etc/passwd        # 查看 inode 层面详细信息
```

## 五、Linux 系统目录结构（遵循 FHS 标准）

| 目录 | 作用 |
|---|---|
| `/` | 根目录，所有目录的起点 |
| `/bin` | 基本用户命令（ls、cp、mv），多数发行版已软链接到 `/usr/bin` |
| `/sbin` | 系统管理命令（reboot、fdisk），通常需 root 权限 |
| `/boot` | 启动相关文件，内核镜像、GRUB 配置 |
| `/dev` | 设备文件，代表硬件设备（如 `/dev/sda`、`/dev/tty`） |
| `/etc` | 系统配置文件（`/etc/passwd`、`/etc/fstab` 等） |
| `/home` | 普通用户家目录，如 `/home/alice` |
| `/root` | root 用户家目录（区别于 `/` 根目录） |
| `/lib`、`/lib64` | 系统启动和基本命令所需的共享库文件（.so） |
| `/media` | 可移动介质（U盘、光盘）自动挂载点 |
| `/mnt` | 临时手动挂载文件系统的挂载点 |
| `/opt` | 第三方/可选软件包安装目录 |
| `/proc` | 虚拟文件系统，反映内核和进程实时状态（如 `/proc/cpuinfo`） |
| `/sys` | 虚拟文件系统，暴露内核对象和设备驱动信息 |
| `/run` | 运行时数据（PID 文件、socket），重启后清空 |
| `/tmp` | 临时文件，通常重启后清空 |
| `/usr` | 用户级程序和数据，系统最大的目录树 |
| `/usr/bin` | 大多数用户命令 |
| `/usr/lib` | 对应程序的库文件 |
| `/usr/local` | 本地手动编译安装的软件，不受包管理器管理 |
| `/usr/share` | 与体系结构无关的共享数据（文档、图标、man 手册） |
| `/var` | 经常变化的数据，如日志（`/var/log`）、邮件、缓存、数据库文件 |
| `/srv` | 系统提供服务的数据（web、FTP 服务器数据目录） |

**记忆技巧**：`/etc` 管"配置"、`/var` 管"变化的数据"、`/usr` 管"用户程序"、`/proc` 和 `/sys` 是"内核的窗口"而非真实磁盘文件。

## 六、基础命令：创建、查看、更新、删除、安装

这些是命令行下最基础、最高频使用的命令（不是快捷键，是完整命令），按用途分类。

### 1. 创建目录 / 文件

| 命令 | 作用 | 示例 |
|---|---|---|
| `mkdir 目录名` | 创建目录 | `mkdir project` |
| `mkdir -p a/b/c` | 递归创建多级目录（父目录不存在也会自动创建） | `mkdir -p project/src/utils` |
| `touch 文件名` | 创建空文件；若文件已存在则更新其修改时间 | `touch main.rs` |
| `touch a.txt b.txt` | 一次创建多个文件 | |

### 2. 查看文件与目录内容

| 命令 | 作用 | 示例 |
|---|---|---|
| `ls` | 列出当前目录内容 | `ls -l`（详细信息）、`ls -a`（含隐藏文件）、`ls -lh`（人类可读大小） |
| `pwd` | 显示当前所在目录路径 | |
| `cat 文件` | 打印文件全部内容到终端 | `cat main.rs` |
| `less 文件` | 分页查看文件（可上下翻页，`q` 退出） | 看大文件、日志时优于 cat |
| `head -n 20 文件` | 查看文件前 20 行 | `head -n 5 log.txt` |
| `tail -n 20 文件` | 查看文件末尾 20 行 | 看日志最新内容 |
| `tail -f 文件` | 实时追踪文件末尾新增内容 | `tail -f /var/log/syslog`（监控实时日志） |
| `tree` | 以树状图显示目录结构（部分系统需先安装） | `tree -L 2`（只显示两层深度） |
| `file 文件` | 判断文件的具体类型 | `file a.out` |
| `wc -l 文件` | 统计文件行数 | 统计代码行数 |

### 3. 复制、移动、重命名、删除

| 命令 | 作用 | 示例 |
|---|---|---|
| `cp 源 目标` | 复制文件 | `cp a.txt b.txt` |
| `cp -r 源目录 目标目录` | 递归复制整个目录 | `cp -r project project_backup` |
| `mv 源 目标` | 移动文件/目录，同时也用于重命名 | `mv old.txt new.txt`（重命名）；`mv a.txt ~/docs/`（移动） |
| `rm 文件` | 删除文件 | `rm a.txt` |
| `rm -r 目录` | 递归删除目录及其内容 | `rm -r build/` |
| `rm -rf 目录` | 强制递归删除，不询问确认（**危险，谨慎使用**） | `rm -rf node_modules` |
| `rmdir 目录` | 删除**空**目录 | 目录不为空时会报错 |

### 4. 更新与升级（以 Debian/Ubuntu 的 apt 为例）

| 命令 | 作用 | 示例 |
|---|---|---|
| `sudo apt update` | 更新软件包索引（不升级软件本身，只是刷新"有哪些新版本可用"的列表） | 装新软件前通常先执行这条 |
| `sudo apt upgrade` | 升级所有已安装的软件包到最新版本 | |
| `sudo apt full-upgrade` | 升级并智能处理依赖变化（可能删除/替换包） | |
| `sudo apt list --upgradable` | 查看哪些包有可用更新 | |

> 其他发行版对应命令：CentOS/RHEL/Fedora 用 `yum` 或 `dnf`（如 `sudo dnf update`）；Arch 用 `pacman`（如 `sudo pacman -Syu`）。

### 5. 安装与卸载软件

| 命令 | 作用 | 示例 |
|---|---|---|
| `sudo apt install 包名` | 安装软件包 | `sudo apt install vim` |
| `sudo apt install -y 包名` | 安装时自动确认，不用手动按 y | 脚本/自动化场景常用 |
| `sudo apt remove 包名` | 卸载软件包，保留配置文件 | `sudo apt remove vim` |
| `sudo apt purge 包名` | 卸载软件包并删除配置文件 | |
| `sudo apt autoremove` | 清理不再需要的依赖包 | 卸载软件后常用来清理残留 |
| `apt search 关键词` | 搜索可安装的软件包 | `apt search python3` |
| `dpkg -l` | 列出所有已安装的包（Debian 系） | |

### 6. 查看进程与系统状态

| 命令             | 作用                              | 示例                                     |
| -------------- | ------------------------------- | -------------------------------------- |
| `ps aux`       | 查看当前所有进程                        | 配合 `grep` 查特定进程：`ps aux \| grep nginx` |
| `top` / `htop` | 实时查看进程、CPU、内存占用（htop 更友好，需单独安装） |                                        |
| `kill PID`     | 结束指定进程（发送 SIGTERM）              | `kill 1234`                            |
| `kill -9 PID`  | 强制结束进程（发送 SIGKILL，无法被忽略）        | 进程无响应时使用                               |
| `df -h`        | 查看磁盘空间使用情况                      |                                        |
| `du -sh 目录`    | 查看指定目录占用的磁盘空间                   | `du -sh /var/log`                      |
| `free -h`      | 查看内存使用情况                        |                                        |

### 7. 权限与用户相关

| 命令 | 作用 | 示例 |
|---|---|---|
| `chmod 权限 文件` | 修改文件权限 | `chmod +x run.sh`（加可执行权限）；`chmod 755 script.sh` |
| `chown 用户:组 文件` | 修改文件所有者 | `sudo chown alice:alice file.txt` |
| `sudo 命令` | 以管理员权限执行命令 | `sudo apt install vim` |
| `whoami` | 查看当前登录用户 | |

### 8. 查找

| 命令 | 作用 | 示例 |
|---|---|---|
| `find 路径 -name "关键词"` | 按文件名查找文件 | `find . -name "*.rs"`（查找当前目录下所有 .rs 文件） |
| `grep "关键词" 文件` | 在文件内容中搜索关键词 | `grep -r "TODO" src/`（递归搜索目录下所有文件） |
| `which 命令名` | 查看某个命令的可执行文件路径 | `which vim` |

## 七、速查小结

- **命令行编辑**：`Ctrl+A/E` 移动，`Ctrl+U/K/W` 删除，`Ctrl+R` 搜历史
- **进程控制**：`Ctrl+C` 中断，`Ctrl+Z` 挂起，`Ctrl+D` 结束输入/退出
- **Vim**：`i` 进插入，`Esc` 回普通，`:wq` 保存退出，`dd/yy/p` 剪切复制粘贴
- **文件类型**：`-` 普通、`d` 目录、`l` 链接、`b/c` 设备、`p` 管道、`s` 套接字
- **目录记忆**：`/etc` 配置、`/var` 变化数据、`/usr` 用户程序、`/proc`&`/sys` 内核窗口
- **创建**：`mkdir -p` 建目录，`touch` 建文件
- **查看**：`ls -l` 列表，`cat/less` 看内容，`tail -f` 追踪日志
- **增删改**：`cp/mv/rm` 复制移动删除
- **更新安装**：`apt update` 刷新索引，`apt upgrade` 升级，`apt install` 安装
- **进程**：`ps aux`、`top`、`kill -9`
- **权限**：`chmod`、`chown`、`sudo`
- **查找**：`find`（按文件名）、`grep`（按内容）
