# 04 读写锁、自旋锁、屏障

## 一、读写锁 `pthread_rwlock_*`

读写锁允许**多个读者并发**,但**写者独占**。适合"读多写少"的场景(配置表、缓存、路由表)。

### 函数一览

| 函数 | 作用 |
|---|---|
| `PTHREAD_RWLOCK_INITIALIZER` | 静态初始化 |
| `pthread_rwlock_init/destroy` | 动态初始化/销毁 |
| `pthread_rwlock_rdlock` | 加读锁(共享) |
| `pthread_rwlock_wrlock` | 加写锁(独占) |
| `pthread_rwlock_tryrdlock / trywrlock` | 非阻塞版本,失败返回 `EBUSY` |
| `pthread_rwlock_timedrdlock / timedwrlock` | 超时版本 |
| `pthread_rwlock_unlock` | 解锁(读写锁共用) |
| `pthread_rwlockattr_setkind_np` | (GNU)设置读者/写者优先策略 |

### 示例:共享配置,多读少写

```c
#include <stdio.h>
#include <unistd.h>
#include <pthread.h>

static pthread_rwlock_t rw = PTHREAD_RWLOCK_INITIALIZER;
static int config_version = 1;

static void *reader(void *arg) {
    long id = (long)arg;
    for (int i = 0; i < 3; i++) {
        pthread_rwlock_rdlock(&rw);              // 多个读者可同时持有
        printf("reader %ld sees version %d\n", id, config_version);
        usleep(100 * 1000);
        pthread_rwlock_unlock(&rw);
        usleep(50 * 1000);
    }
    return NULL;
}

static void *writer(void *arg) {
    (void)arg;
    for (int i = 0; i < 2; i++) {
        usleep(150 * 1000);
        pthread_rwlock_wrlock(&rw);              // 独占:等所有读者退出
        config_version++;
        printf(">>> writer updated to version %d\n", config_version);
        pthread_rwlock_unlock(&rw);
    }
    return NULL;
}

int main(void) {
    pthread_t r[3], w;
    for (long i = 0; i < 3; i++) pthread_create(&r[i], NULL, reader, (void *)i);
    pthread_create(&w, NULL, writer, NULL);
    for (int i = 0; i < 3; i++) pthread_join(r[i], NULL);
    pthread_join(w, NULL);
    pthread_rwlock_destroy(&rw);
    return 0;
}
```

### 注意事项

- **写者饥饿**:若读者源源不断,写者可能一直拿不到锁。glibc 默认偏向读者,可用 `pthread_rwlockattr_setkind_np(&attr, PTHREAD_RWLOCK_PREFER_WRITER_NONRECURSIVE_NP)` 调整。
- **不能升级**:持有读锁时再请求写锁会死锁。需要时先释放读锁再拿写锁,并**重新检查**数据。
- 读写锁自身开销比 mutex 大,临界区很短或写很多时,普通 mutex 反而更快。
- 同一线程重复拿读锁的行为取决于实现,尽量避免。

## 二、自旋锁 `pthread_spin_*`

拿不到锁时**忙等**(循环检查)而不是睡眠。省去了上下文切换,适合**临界区极短**且**多核**的场景。

### 函数一览

| 函数 | 作用 |
|---|---|
| `pthread_spin_init(lock, pshared)` | 初始化,`pshared` 为 `PTHREAD_PROCESS_PRIVATE` 或 `PTHREAD_PROCESS_SHARED` |
| `pthread_spin_destroy` | 销毁 |
| `pthread_spin_lock` | 加锁(忙等) |
| `pthread_spin_trylock` | 尝试加锁,失败返回 `EBUSY` |
| `pthread_spin_unlock` | 解锁 |

### 示例

```c
#include <stdio.h>
#include <pthread.h>

static pthread_spinlock_t spin;
static long counter = 0;

static void *inc(void *arg) {
    (void)arg;
    for (int i = 0; i < 100000; i++) {
        pthread_spin_lock(&spin);
        counter++;                               // 临界区必须极短
        pthread_spin_unlock(&spin);
    }
    return NULL;
}

int main(void) {
    pthread_spin_init(&spin, PTHREAD_PROCESS_PRIVATE);

    pthread_t t[4];
    for (int i = 0; i < 4; i++) pthread_create(&t[i], NULL, inc, NULL);
    for (int i = 0; i < 4; i++) pthread_join(t[i], NULL);

    printf("counter = %ld\n", counter);
    pthread_spin_destroy(&spin);
    return 0;
}
```

### 何时使用 / 不使用

| 适合 | 不适合 |
|---|---|
| 临界区只有几条指令 | 临界区里有系统调用、I/O、malloc、sleep |
| 多核,线程数 ≤ 核数 | 单核机器(持锁线程被抢占后,其它线程空转浪费整个时间片) |
| 对延迟极敏感的底层代码 | 一般业务代码(用 mutex 即可,现代 mutex 在无竞争时也很快) |

> 用户态自旋锁在线程可能被调度器抢占时有风险,Linux 内核里的 spinlock 配合关抢占才安全。普通应用优先用 mutex。

## 三、屏障 `pthread_barrier_*`

屏障让一组线程在某个点**互相等待**,直到所有线程都到达后才一起继续。常用于分阶段并行计算。

### 函数一览

| 函数 | 作用 |
|---|---|
| `pthread_barrier_init(b, attr, count)` | 初始化,`count` 为需要汇合的线程数 |
| `pthread_barrier_wait` | 到达屏障并等待。**恰好一个**线程返回 `PTHREAD_BARRIER_SERIAL_THREAD`,其它返回 `0` |
| `pthread_barrier_destroy` | 销毁 |
| `pthread_barrierattr_*` | 属性(如 pshared) |

屏障可以**重复使用**:所有线程通过后自动重置,可再次作为下一阶段的汇合点。

### 示例:两阶段计算

```c
#include <stdio.h>
#include <unistd.h>
#include <pthread.h>

#define N 4

static pthread_barrier_t barrier;

static void *worker(void *arg) {
    long id = (long)arg;

    usleep((id + 1) * 100 * 1000);               // 各线程阶段 1 耗时不同
    printf("thread %ld finished phase 1\n", id);

    int rc = pthread_barrier_wait(&barrier);     // 等所有线程完成阶段 1
    if (rc == PTHREAD_BARRIER_SERIAL_THREAD)
        printf("--- all done phase 1, merge results (by thread %ld) ---\n", id);

    printf("thread %ld starts phase 2\n", id);
    pthread_barrier_wait(&barrier);              // 屏障可复用
    return NULL;
}

int main(void) {
    pthread_barrier_init(&barrier, NULL, N);

    pthread_t t[N];
    for (long i = 0; i < N; i++) pthread_create(&t[i], NULL, worker, (void *)i);
    for (int i = 0; i < N; i++) pthread_join(t[i], NULL);

    pthread_barrier_destroy(&barrier);
    return 0;
}
```

> `PTHREAD_BARRIER_SERIAL_THREAD` 可以用来选出一个线程做"汇总/合并"之类的串行工作。

## 四、几种同步原语对比

| 原语 | 等待方式 | 并发度 | 典型场景 |
|---|---|---|---|
| mutex | 睡眠 | 1 | 通用互斥 |
| spinlock | 忙等 | 1 | 极短临界区、多核 |
| rwlock | 睡眠 | 多读/单写 | 读多写少 |
| cond | 睡眠(配合 mutex) | - | 等待条件成立 |
| barrier | 睡眠 | - | 多线程阶段性汇合 |
