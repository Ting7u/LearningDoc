# 01 线程管理

## 函数一览

| 函数 | 作用 |
|---|---|
| `pthread_create` | 创建线程 |
| `pthread_join` | 等待线程结束并回收资源,可取返回值 |
| `pthread_detach` | 把线程设为分离状态,结束后自动回收 |
| `pthread_exit` | 终止当前线程 |
| `pthread_self` | 获取当前线程 ID |
| `pthread_equal` | 比较两个线程 ID |
| `pthread_attr_init/destroy` | 初始化/销毁线程属性对象 |
| `pthread_attr_setdetachstate/getdetachstate` | 设置/获取分离状态 |
| `pthread_attr_setstacksize/getstacksize` | 设置/获取栈大小 |
| `pthread_attr_setguardsize` | 设置栈保护页大小 |
| `pthread_attr_setschedpolicy/setschedparam` | 调度策略/优先级 |
| `pthread_tryjoin_np / pthread_timedjoin_np` | (GNU)非阻塞/超时 join |
| `pthread_setname_np / pthread_getname_np` | (GNU)设置/获取线程名,名字最长 15 字符 |
| `sched_yield` | 主动让出 CPU |

## 1. pthread_create

```c
int pthread_create(pthread_t *thread,
                   const pthread_attr_t *attr,
                   void *(*start_routine)(void *),
                   void *arg);
```

- `thread`:输出参数,保存新线程 ID。
- `attr`:属性,传 `NULL` 使用默认值(joinable、默认栈 8MB 左右)。
- `start_routine`:线程入口,签名固定为 `void *f(void *)`。
- `arg`:传给入口函数的唯一参数,多个参数请打包成结构体。
- 返回 `0` 成功,否则返回错误码(如 `EAGAIN` 资源不足)。

## 2. pthread_join:等待并取返回值

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>

static void *square(void *arg) {
    int n = *(int *)arg;
    int *result = malloc(sizeof *result);   // 返回值必须不在线程栈上
    *result = n * n;
    return result;                           // 等价于 pthread_exit(result)
}

int main(void) {
    pthread_t tid;
    int n = 7;

    int rc = pthread_create(&tid, NULL, square, &n);
    if (rc != 0) {
        fprintf(stderr, "pthread_create: %s\n", strerror(rc));
        return 1;
    }

    void *ret;
    pthread_join(tid, &ret);                 // 阻塞直到线程结束
    printf("%d^2 = %d\n", n, *(int *)ret);
    free(ret);
    return 0;
}
```

要点:

- 一个 joinable 线程**必须**被 join 或 detach,否则会泄漏资源(僵尸线程)。
- 同一个线程不能被 join 两次,也不要自己 join 自己(返回 `EDEADLK`)。
- 返回值不要指向线程栈上的局部变量,线程结束后栈已失效。

## 3. 传递参数的正确方式

### 错误示范:传循环变量地址

```c
for (int i = 0; i < 4; i++)
    pthread_create(&tid[i], NULL, worker, &i);   // 错误:所有线程共享同一个 i
```

### 正确做法:每个线程一份独立参数

```c
#include <stdio.h>
#include <pthread.h>

typedef struct {
    int id;
    const char *name;
} task_arg_t;

static void *worker(void *arg) {
    task_arg_t *t = arg;
    printf("worker %d (%s) running\n", t->id, t->name);
    return NULL;
}

int main(void) {
    enum { N = 4 };
    pthread_t tid[N];
    task_arg_t args[N];                      // 生命周期要覆盖线程运行期

    for (int i = 0; i < N; i++) {
        args[i] = (task_arg_t){ .id = i, .name = "demo" };
        pthread_create(&tid[i], NULL, worker, &args[i]);
    }
    for (int i = 0; i < N; i++)
        pthread_join(tid[i], NULL);
    return 0;
}
```

如果线程需要在 `main` 返回后继续使用参数,请 `malloc` 分配,由线程自己 `free`。

## 4. pthread_detach:分离线程

分离线程结束时系统自动回收资源,不能再被 join。适合"发射后不管"的任务。

```c
#include <stdio.h>
#include <unistd.h>
#include <pthread.h>

static void *bg(void *arg) {
    (void)arg;
    pthread_detach(pthread_self());          // 方式一:线程自己 detach
    printf("background job\n");
    return NULL;
}

int main(void) {
    pthread_t tid;
    pthread_create(&tid, NULL, bg, NULL);
    // 方式二:创建者 detach  ->  pthread_detach(tid);
    sleep(1);                                // 简单等待,实际应使用同步机制
    return 0;
}
```

也可以通过属性在创建时直接指定(见第 7 节)。

## 5. pthread_exit 与 main 线程的退出

```c
#include <stdio.h>
#include <unistd.h>
#include <pthread.h>

static void *worker(void *arg) {
    (void)arg;
    sleep(1);
    printf("worker done\n");
    return NULL;
}

int main(void) {
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);
    pthread_exit(NULL);   // main 线程退出,但进程继续运行直到所有线程结束
}                         // 如果这里写 return 0,则整个进程退出,worker 被杀死
```

| 行为 | 效果 |
|---|---|
| 线程函数 `return` | 仅该线程结束(等价于 `pthread_exit`) |
| 线程中调用 `pthread_exit` | 仅该线程结束,会执行清理函数和 TSD 析构 |
| **main** 中 `return` / `exit` | **整个进程**结束,所有线程被终止 |
| 任意线程调用 `exit()` | 整个进程结束 |
| **main** 中 `pthread_exit` | 仅 main 线程结束,进程等其它线程结束后才退出 |

## 6. pthread_self 与 pthread_equal

`pthread_t` 是不透明类型(可能是整数、指针或结构体),**不能用 `==` 比较**。

```c
#include <stdio.h>
#include <pthread.h>

static pthread_t main_tid;

static void *check(void *arg) {
    (void)arg;
    if (pthread_equal(pthread_self(), main_tid))
        printf("I am main thread\n");
    else
        printf("I am another thread\n");
    return NULL;
}

int main(void) {
    main_tid = pthread_self();
    pthread_t t;
    pthread_create(&t, NULL, check, NULL);
    pthread_join(t, NULL);
    check(NULL);
    return 0;
}
```

> 打印线程 ID 可用 Linux 专有的 `gettid()`(`syscall(SYS_gettid)`),它是内核线程号,与 `pthread_t` 不同。

## 7. 线程属性 pthread_attr_t

使用流程:`init` → `set...` → `pthread_create` → `destroy`。

```c
#define _GNU_SOURCE
#include <stdio.h>
#include <pthread.h>

static void *worker(void *arg) {
    (void)arg;
    char buf[64 * 1024];                     // 在栈上用掉 64KB
    buf[0] = 1;
    printf("worker ok, buf[0]=%d\n", buf[0]);
    return NULL;
}

int main(void) {
    pthread_attr_t attr;
    pthread_attr_init(&attr);

    pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_JOINABLE);
    pthread_attr_setstacksize(&attr, 1024 * 1024);   // 1MB,必须 >= PTHREAD_STACK_MIN

    size_t sz;
    pthread_attr_getstacksize(&attr, &sz);
    printf("stack size = %zu\n", sz);

    pthread_t tid;
    pthread_create(&tid, &attr, worker, NULL);
    pthread_attr_destroy(&attr);             // 创建后即可销毁,不影响已创建的线程

    pthread_join(tid, NULL);
    return 0;
}
```

常用属性:

| 属性 | 取值 / 说明 |
|---|---|
| detachstate | `PTHREAD_CREATE_JOINABLE`(默认)/ `PTHREAD_CREATE_DETACHED` |
| stacksize | 栈大小,线程很多时可以调小以节省虚拟内存 |
| stackaddr | 自定义栈地址(不常用,建议用 `pthread_attr_setstack`) |
| guardsize | 栈溢出保护页大小 |
| scope | `PTHREAD_SCOPE_SYSTEM`(Linux 仅支持这个)/ `PTHREAD_SCOPE_PROCESS` |
| inheritsched | 是否继承创建者的调度属性 |
| schedpolicy | `SCHED_OTHER` / `SCHED_FIFO` / `SCHED_RR`(实时策略需 root) |
| schedparam | 优先级 `struct sched_param` |

## 8. 线程命名与超时 join(GNU 扩展)

```c
#define _GNU_SOURCE
#include <stdio.h>
#include <time.h>
#include <errno.h>
#include <unistd.h>
#include <pthread.h>

static void *slow(void *arg) {
    (void)arg;
    pthread_setname_np(pthread_self(), "slow-worker");  // top -H / gdb 中可见
    sleep(3);
    return NULL;
}

int main(void) {
    pthread_t tid;
    pthread_create(&tid, NULL, slow, NULL);

    struct timespec ts;
    clock_gettime(CLOCK_REALTIME, &ts);
    ts.tv_sec += 1;                                      // 最多等 1 秒

    int rc = pthread_timedjoin_np(tid, NULL, &ts);
    if (rc == ETIMEDOUT) {
        printf("1s timeout, still running\n");
        pthread_join(tid, NULL);                         // 继续阻塞等待
    }
    printf("joined\n");
    return 0;
}
```

## 小结

- 创建线程后,**要么 join,要么 detach**。
- 参数生命周期必须覆盖线程使用期,避免传局部变量地址。
- 判断线程 ID 相等用 `pthread_equal`。
- 大量线程时可调小栈,深度递归的线程需要调大栈。
