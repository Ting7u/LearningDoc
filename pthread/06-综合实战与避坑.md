# 06 综合实战与避坑

## 一、实战:简易线程池

综合运用:`pthread_create/join`、`mutex`、`cond`(`signal`/`broadcast`)、优雅关闭。

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <pthread.h>

typedef struct task {
    void (*fn)(void *);
    void *arg;
    struct task *next;
} task_t;

typedef struct {
    pthread_mutex_t mu;
    pthread_cond_t  cv;          // 队列非空 或 shutdown
    task_t *head, *tail;
    pthread_t *threads;
    int nthreads;
    int shutdown;
} pool_t;

static void *worker(void *arg) {
    pool_t *p = arg;
    for (;;) {
        pthread_mutex_lock(&p->mu);
        while (!p->head && !p->shutdown)
            pthread_cond_wait(&p->cv, &p->mu);

        if (!p->head && p->shutdown) {               // 队列已空且要关闭 -> 退出
            pthread_mutex_unlock(&p->mu);
            return NULL;
        }

        task_t *t = p->head;                         // 取出任务
        p->head = t->next;
        if (!p->head) p->tail = NULL;
        pthread_mutex_unlock(&p->mu);                // 执行任务时不持锁

        t->fn(t->arg);
        free(t);
    }
}

pool_t *pool_create(int n) {
    pool_t *p = calloc(1, sizeof *p);
    pthread_mutex_init(&p->mu, NULL);
    pthread_cond_init(&p->cv, NULL);
    p->nthreads = n;
    p->threads = malloc(n * sizeof(pthread_t));
    for (int i = 0; i < n; i++)
        pthread_create(&p->threads[i], NULL, worker, p);
    return p;
}

void pool_submit(pool_t *p, void (*fn)(void *), void *arg) {
    task_t *t = malloc(sizeof *t);
    t->fn = fn; t->arg = arg; t->next = NULL;

    pthread_mutex_lock(&p->mu);
    if (p->tail) p->tail->next = t; else p->head = t;
    p->tail = t;
    pthread_cond_signal(&p->cv);                     // 唤醒一个工作线程
    pthread_mutex_unlock(&p->mu);
}

void pool_destroy(pool_t *p) {
    pthread_mutex_lock(&p->mu);
    p->shutdown = 1;
    pthread_cond_broadcast(&p->cv);                  // 唤醒所有线程让它们检查 shutdown
    pthread_mutex_unlock(&p->mu);

    for (int i = 0; i < p->nthreads; i++)
        pthread_join(p->threads[i], NULL);           // 等所有任务做完

    pthread_mutex_destroy(&p->mu);
    pthread_cond_destroy(&p->cv);
    free(p->threads);
    free(p);
}

/* ---------- 使用 ---------- */
static void job(void *arg) {
    long id = (long)arg;
    printf("job %ld running in thread %lu\n", id, (unsigned long)pthread_self());
    usleep(100 * 1000);
}

int main(void) {
    pool_t *p = pool_create(3);
    for (long i = 0; i < 8; i++)
        pool_submit(p, job, (void *)i);
    pool_destroy(p);                                 // 处理完所有任务后退出
    printf("all jobs done\n");
    return 0;
}
```

设计要点:

1. 队列与 `shutdown` 标志都由同一把锁保护,条件变量只有一个,条件为"有任务或要关闭"。
2. 任务**在锁外执行**,避免一个慢任务阻塞其他线程取任务。
3. 关闭时 `broadcast`,线程先把剩余任务处理完再退出(排空式关闭)。
4. 可扩展:任务返回值/future、有界队列(再加 `not_full` 条件)、动态扩缩线程。

## 二、常见坑与最佳实践

### 1. 创建与生命周期

| 坑 | 说明 / 对策 |
|---|---|
| 传局部变量地址给线程 | 函数返回后栈失效;用堆内存或保证生命周期 |
| 忘记 join/detach | 资源泄漏,线程数上限后 `pthread_create` 返回 `EAGAIN` |
| `main` 里直接 `return` | 其它线程被强制终止;先 join 或用 `pthread_exit` |
| 线程返回栈上地址 | 悬空指针;返回堆内存或写入调用方提供的结构体 |
| 用 `==` 比较 `pthread_t` | 用 `pthread_equal` |
| 用 `perror` 打印错误 | pthread 不设 `errno`,用 `strerror(rc)` |

### 2. 锁

| 坑 | 说明 / 对策 |
|---|---|
| 死锁(循环等待) | 固定加锁顺序;用 `trylock` 回退;一次只持一把锁 |
| 提前 `return` 忘记解锁 | 单出口模式(`goto cleanup`),或用 `pthread_cleanup_push` |
| 持锁时做阻塞操作 | I/O、`sleep`、大量计算都应放在锁外 |
| 锁粒度太粗/太细 | 粗:并发度低;细:易死锁、开销大。先粗后细,以测量为准 |
| 对已销毁的锁操作 / 销毁时有人持有 | 先确保所有线程已 join |
| 只保护写,不保护读 | 读写同一数据都必须加同一把锁(或用原子操作) |
| 拷贝 `pthread_mutex_t` | 锁对象不可拷贝,只能用指针/引用 |

### 3. 条件变量

- 永远在 `while` 里等待;修改条件必须持锁;一个条件变量对应一个谓词和一把锁。
- 不确定时用 `broadcast`。
- 信号发出时没人等待就丢失 → 状态必须保存在变量里。

### 4. 通用建议

1. **能不共享就不共享**:线程私有数据、消息传递(队列)比共享内存+锁更不易出错。
2. **能用原子就用原子**:简单计数、标志位用 `<stdatomic.h>`。
3. 开发期开启 `-fsanitize=thread` 或 `valgrind --tool=helgrind`,CI 里跑 TSan。
4. 线程数不要无限创建:CPU 密集型 ≈ 核数;I/O 密集型可更多;优先线程池。
5. 库函数是否线程安全要看文档:`strtok`、`localtime`、`rand`、`getenv` 等有可重入版本(`strtok_r`、`localtime_r`、`rand_r`)。
6. 日志、`printf` 在 glibc 中本身线程安全(内部加锁),但多次调用之间的输出可能交错。

## 三、函数总表

### 线程管理
| 函数 | 说明 |
|---|---|
| `pthread_create` | 创建线程 |
| `pthread_join` | 等待并回收 |
| `pthread_detach` | 分离 |
| `pthread_exit` | 退出当前线程 |
| `pthread_self` / `pthread_equal` | 获取 / 比较线程 ID |
| `pthread_cancel` | 请求取消 |
| `pthread_attr_*` | 线程属性 |
| `pthread_setname_np` / `pthread_getname_np` | (GNU)线程名 |
| `pthread_tryjoin_np` / `pthread_timedjoin_np` | (GNU)非阻塞/超时 join |

### 互斥锁
| 函数 | 说明 |
|---|---|
| `pthread_mutex_init/destroy` | 初始化/销毁 |
| `pthread_mutex_lock/trylock/timedlock/unlock` | 加锁/尝试/超时/解锁 |
| `pthread_mutexattr_*` | 类型、pshared、robust、protocol 等 |
| `pthread_mutex_consistent` | robust 锁恢复一致 |

### 条件变量
| 函数 | 说明 |
|---|---|
| `pthread_cond_init/destroy` | 初始化/销毁 |
| `pthread_cond_wait/timedwait` | 等待 / 超时等待 |
| `pthread_cond_signal/broadcast` | 唤醒一个 / 全部 |
| `pthread_condattr_*` | 时钟、pshared |

### 读写锁 / 自旋锁 / 屏障
| 函数 | 说明 |
|---|---|
| `pthread_rwlock_init/destroy` | 读写锁初始化/销毁 |
| `pthread_rwlock_rdlock/wrlock/unlock` | 读锁 / 写锁 / 解锁 |
| `pthread_rwlock_try*` / `timed*` | 非阻塞 / 超时 |
| `pthread_spin_init/destroy/lock/trylock/unlock` | 自旋锁 |
| `pthread_barrier_init/wait/destroy` | 屏障 |

### 线程局部与一次性
| 函数 | 说明 |
|---|---|
| `pthread_key_create/delete` | TSD 键 |
| `pthread_setspecific/getspecific` | TSD 读写 |
| `pthread_once` | 一次性初始化 |

### 取消、信号、其它
| 函数 | 说明 |
|---|---|
| `pthread_setcancelstate/setcanceltype/testcancel` | 取消控制 |
| `pthread_cleanup_push/pop` | 清理处理函数(宏) |
| `pthread_sigmask` / `pthread_kill` | 线程信号掩码 / 向线程发信号 |
| `pthread_atfork` | fork 前后回调 |
| `pthread_setaffinity_np` 等 | (GNU)CPU 亲和性 |
| `pthread_setschedparam/getschedparam/setschedprio` | 调度策略/优先级 |
| `pthread_getcpuclockid` | 线程 CPU 时钟 |
