## 1. 整数类型
| 类型          | 说明         | 典型大小     |
| ----------- | ---------- | -------- |
| `char`      | 字符（本质是小整数） | 1 字节     |
| `short`     | 短整型        | 2 字节     |
| `int`       | 整型         | 4 字节     |
| `long`      | 长整型        | 4 或 8 字节 |
| `long long` | 更长整型（C99）  | 8 字节     |
**unsigned** 无符号，只能表示非负数
**signed** 有符号（默认）
## 2. 浮点类型
|类型|说明|典型大小|
|---|---|---|
|`float`|单精度|4 字节|
|`double`|双精度|8 字节|
|`long double`|扩展精度|8、12 或 16 字节|
## 3. 枚举类型

```c
enum Color {
	RED, // 0
	GREEN, // 1
	BLUE, // 2
}

// 也可以自己指定值
enum Level {
	LOW = 10,
	MID = 20,
	HIGH =30,
}

enum Mix { A = 5, B, C }; // B 自动是 6，C 自动是 7

int main(void){
	enum Color a = GREEN; // 等价于 c = 1，但可读性好得多
	return 0;
}
```

编号规则是：从 0 开始，依次加 1
指定了某个值之后，后面没指定的会在它的基础上加 1
### 3.1. 枚举占多少字节？
- **枚举常量**（`RED`、`GREEN` 这些名字）：在 C 里它们的类型就是 `int`，所以相当于 4 字节的整数（`int` 通常是 4 字节）
- **枚举类型本身**（`enum Color` 的变量）：C 标准规定它由编译器选一个能容纳所有枚举值的整数类型，具体选哪个由实现决定

但是，按 C 标准（C23 之前），枚举常量的值必须能放进 `int`，超出就不合法
```c
// 5000000000 超出 32 位 int 的范围
enum Big { A = 5000000000 };   
```
按标准，这是违反约束的写法，编译器应该给出诊断（警告或错误）。至于具体怎么处理，各编译器不同：
- GCC 和 Clang 通常不直接拒绝，只在严格模式（如 `-pedantic`）下警告，然后把它当作扩展接受。这时枚举类型会变大，`sizeof(enum Big)` 可能变成 8
- MSVC则会直接截断为32位，所以依旧是4字节
### 3.2. 指定枚举类型

这个是在C23之后才会有的特性，需要编译器的支持
```c
enum Big : long long
{
    A = 5000000000
};
```
**注意：**
特性比较新，需要编译器支持，如果GCC或者MSVC版本过低，可能报错
## 4. 联合体

先看结构体的内存：
```c
struct S { int i; float f; };
```

| i (4字节) | f (4字节) |  总共8字节
`i` 和 `f` 可以同时存在，互不影响
![[Pasted image 20261003101206.png]]**联合体的核心区别**
```c
union U { int i; float f; };
```

联合体的所有成员**从同一个地址开始，共用同一块内存**
| i / f 共用这 4 字节 | 共 4 字节
![[Pasted image 20261003101357.png]]
任何时刻，这块内存里只存着**一个成员的值**。这就是"联合"的含义：多个成员叠在一起，同一时间只能用其中一个
### 4.1. 联合体的内存多大？

联合体的大小至少等于**最大那个成员**的大小，因为这块内存要能装下任何一个成员
说"至少"，是因为有时编译器会为了对齐补一些字节，所以最终大小以 `sizeof` 为准

```c
union V { char c; int i; double d; };
```

最大的是 `double`（8 字节），所以 `sizeof(union V)` 通常是 8
### 4.2. 写入一个成员会发生什么？

```c
union U { int i; float f; };
union U u; 
u.i = 100; 
u.f = 3.14f; // 这一步写入后，u.i 之前存的 100 就被覆盖了
```

`i` 和 `f` 占同一块内存，写 `f` 就等于改写了这 4 个字节，`i` 里原来的值就没了

如果这时去读 `u.i`，读到的是 `3.14f` 那 4 个字节**按整数重新解释**后的结果，是一个看起来毫无意义的大数。标准允许这种"换个类型解读同一块字节"的读法（C99 之后），但结果依赖具体平台的表示方式，所以不可移植
### 4.3. 怎么知道现在存的是哪个成员？

联合体自己**不会记录**当前存的是哪个成员，所以实际使用时，通常配一个"标记"字段一起用

```c
struct Value {
    int type;          // 0 表示 int，1 表示 float
    union { int i; float f; } data;
};
```

读之前先看 `type`，再决定读 `data.i` 还是 `data.f`。这种写法叫"带标签的联合体"
## 5. 结构体

### 5.1. 定义

```c
// 写法一：typedef 起别名（最常用）
typedef struct Student {
	char name[20];
	int age;
	int score;
} Student;
// 写法二：不用 typedef，每次都要写 struct
struct Student {
	char name[20];
	int age;
	int score;
};
struct Student s; // 必须带 struct 关键字
```

**要点：**
- 结构体定义只是一个类型模板，不占内存，定义变量时才分配空间
- 定义末尾的分号 `;` 不能漏
- 成员可以是任意类型：基本类型、数组、指针、其他结构体
- 结构体内不能包含自己类型的变量，但可以包含指向自己的指针（链表就是这么做的）

```c
typedef struct Node {
	int data;
	// 这里必须写 struct Node，因为别名 Node 还没生效
	struct Node *next;
} Node;
```
### 5.2. 初始化

```c
// 不初始化，成员是随机值（局部变量）
Student s1;                                       
// 按顺序
Student s2 = { "孙晴", 25, 60 };
// 指定成员（C99）                  
Student s3 = { .age = 24, .name = "景甜", .score = 80 };  
// 全部清零（常用）
Student s4 = {0};                                 
```

**要点：**
- 按顺序初始化必须和成员定义顺序一致
- 指定成员初始化不依赖顺序，可读性最好（C++ 里则要求顺序一致，这是 C 和 C++ 的差异）
- 只写了部分成员时，剩下的自动置 0
- `{0}` 是清零的惯用写法
- 全局变量和 `static` 变量不初始化时也会自动为 0，局部变量不会
### 5.3. 访问成员

```c
s1.age = 28;              // 变量用 .
printf("%d", s1.age);

Student *p = &s1;
p->age = 30;              // 指针用 ->
(*p).age = 30;            // 等价写法，但很少这么写
```

口诀：变量用点，指针用箭头。`p->age` 就是 `(*p).age` 的简写
### 5.4. 赋值与拷贝

```c
Student a = { "杨颖", 28, 90 };
Student b;
b = a;     // ✅ 同类型结构体可以整体赋值，逐成员拷贝
```

- 结构体之间可以直接用 `=` 整体赋值，包括里面的数组成员也会被完整拷贝
- 但是不能用 `==` 比较两个结构体，要逐个成员比较（或用 `memcmp`，但有坑，见下文）
### 5.5. 函数传参

```c
// 传值：整个结构体被拷贝一份，修改不影响原变量
void print_by_value(Student s);      
// 传指针：只传地址，高效，可以修改原变量
void print_by_ptr(const Student *s); 
// 也可以作为返回值
Student make_student(void);          
```

- 传值会拷贝整个结构体，结构体大时效率低，通常传指针
- 只读不改时，用 `const Student *` 表示承诺不修改
- 想在函数里修改原结构体，必须传指针
### 5.6. 结构体数组

```c
Student cls[3] = {
    { "杨颖", 28, 90 },
    { "孙晴", 25, 60 },
    { .name = "景甜", .age = 24, .score = 80 },
};
for (int i = 0; i < 3; i++) {
    printf("%s %d %d\n", cls[i].name, cls[i].age, cls[i].score);
}
```

### 5.7. 嵌套结构体

```c
typedef struct { int x, y; } Vec2;
typedef struct {
    Vec2 pos;
    int hp;
} Player;

Player p = { .pos = { .x = 10, .y = 20 }, .hp = 100 };
p.pos.x = 15;   // 一层层用点访问
```
### 5.8. 内存对齐与 sizeof

```c
typedef struct {
    char a;   // 1 字节
    int b;    // 4 字节
    char c;   // 1 字节
} A;
```

`sizeof(A)` 通常是 12，不是 6。因为编译器会在成员之间插入**填充字节**，让每个成员按自己的大小对齐。
- 成员顺序会影响总大小：把大的成员放前面、小的放后面，往往更省空间。
- 不要手动把各成员的 sizeof 相加来算结构体大小，一律用 `sizeof(结构体类型)`。
- 具体填充规则和编译器、平台有关，这里是常见情况。
