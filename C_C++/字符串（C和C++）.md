## 1. C
C 语言里没有内置的 string 类型。所谓字符串，只是一种**约定**：一段连续的 `char`，以 `'\0'`（值为 0 的字符）结尾

```c
// "abc" 在内存中是: 'a' 'b' 'c' '\0' （4 个字节）
```

## 2. C 中常见的几种实现方式
### 2.1. 字符数组（栈上，可修改）

```c
char s[] = "hello"; // 数组大小6，内容被拷贝进来
s[0] = 'H'; // 可以修改
```
### 2.2. 字符串字面量指针（只读）

```c
const char *p = "hello" // 指向程序的只读数据区
// p[0] = 'H', // 未定义行为
```
### 2.3. 堆上分配的字符串

 ```c
 char *s = malloc(6);
 strcpy(s, "hello");
 free(s); // 需要自己释放
 ```
### 2.4. 自定义“带长度”的字符串（需自己实现）

```c
struct Str { char *data; size_t len; size_t cap; };
```
这是 C 里的常见做法，不是语言自带的
## 3. C字符串的特点

- 长度要靠遍历：`strlen` 要从头数到 `\0` ,时间是O(n)
- 不记录容量：拷贝时容易越界，`strcpy`、`strcat`是典型的缓冲区溢出来源
- 不能含`\0`：中间出现`\0` 会被当作结尾，所以不适合存二进制数据
- 没有 `==` 、`+`：比较要用`strcmp`，拼接要用`strcat`，直接写 `a == b` 比较的是地址
- 内存管理全靠自己：谁分配、谁释放、够不够大，都要自己负责
## 4. C++ 的字符串和 C 的区别

|        | C 字符串               | C++ `std::string`        |
| :----- | :------------------ | :----------------------- |
| 本质     | `char` 数组 + `\0` 约定 | 标准库的类                    |
| 长度     | `strlen`，O(n)       | `.size()`，通常 O(1)        |
| 内存管理   | 手动                  | 自动增长、自动释放                |
| 拼接     | `strcat`（要先保证空间足够）  | `a + b`、`a += b`         |
| 比较     | `strcmp`            | `a == b`、`a < b`         |
| 含 `\0` | 不能                  | 可以（它按长度而不是按 `\0` 判断结尾）   |
| 越界安全   | 无保护                 | `.at()` 会检查并抛异常，`[]` 不检查 |
