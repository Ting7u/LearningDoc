**先搞清四个基本概念**
**运算符**：表示一种运算的符号，如 `+`、`*`、`=`
**操作数**：被运算的对象。`3 + 4` 里，`3` 和 `4` 是操作数
**优先级**：一个表达式里有多个运算符时，谁先算
**结合性**：优先级相同的运算符连在一起时，从左往右算还是从右往左算

```c
2 + 3 * 4 // * 优先级高于 +，所以是 2 + (3*4) = 14
10 - 4 - 4 // - 优先级相同，左结合，所以是 (10-4)-3 = 3
a = b = 5 // = 右结合，所以是 a = (b = 5)
```
## 1. 运算符分类
### 1.1. 算术运算符

`+ - * / %`，以及自增自减 `++ --`

```c
7 / 2 // 3 两个整数相除，结果是整数（舍去小数）
7.0 / 2 // 3.5 有一个是浮点数，结果就是浮点数
7 % 2 // 1 取余，只能用于整数
-7 / 2 // -3 C99 起向零截断
-7 % 2 // -1 C99 起余数符号与被除数相同
```

> C89 中负数除法和取余的结果由实现决定，C99 起才固定为向零截断

**`++`/`--` 分前缀和后缀**

```c
int i = 5;
int a = i++; // 后缀：先用 i 的值（a=5），再自增（i=6）
int b = ++i; // 前缀：先自增（i=7），再用（b=7）
```
### 1.2. 关系运算符

`< <= > >= == !=`，结果是 `1`（真）或 `0`（假）
### 1.3. 逻辑运算符

`&& || !`

```c
(a > 0) && (b > 0)   // 与
(a > 0) || (b > 0)   // 或
!(a > 0)             // 非
```

`&&` 和 `||` 有**短路**特性：左边已能决定结果，右边就不再计算

```c
// p 为空时，右边不会执行，所以安全
if(p != NULL && p->x > 0){...}
```

### 1.4. 位运算符

`& | ^ ~ << >>`

```c
5 & 3     // 0101 & 0011 = 0001 = 1   按位与
5 | 3     // 0101 | 0011 = 0111 = 7   按位或
5 ^ 3     // 0101 ^ 0011 = 0110 = 6   按位异或
1 << 3    // 8    左移 3 位，相当于乘 2^3
16 >> 2   // 4    右移 2 位，相当于除以 2^2
```

`~` 是按位取反。常见补码系统上 `~5` 是 `-6`，但这依赖于整数表示。对负数右移的结果由实现决定，移位位数不能为负或不小于类型宽度，否则是未定义行为

### 1.5. 赋值运算符

`=` 以及复合赋值 `+= -= *= /= %= <<= >>= &= ^= |=`

```c
x += 3; // 等价于 x = x + 3
```

### 1.6. 条件运算符 (唯一的三目运算符)

`? :`

```c
int max = (a > b) ? a : b;
```

### 1.7. 逗号运算符

`,` 从左到右依次计算，整个表达式的值是最后一个

```c
int x = (1,2,3); // x = 3
int x = (1 + 2, 2 * 3, 3 + 6); // 9
```

注意：函数参数里的逗号 `f(a, b)` 和 `int a, b;` 里的逗号只是分隔符，不是逗号运算符
### 1.8. 指针与成员相关

`* & -> . [] ()`

```c
int n = 10;
int *p = &n; // & 取地址
*p = 20; // * 解引用
arr[2] // 下标
s.x // 结构体成员
ps->x // 通过指针访问成员，等价于 (*ps).x
```

### 1.9. 其他

`sizeof`、强制类型转换 `(type)`

```c
sizeof(int) // 类型大小，单位是字节（具体数值依平台而定）
(double) 7 / 2 // 3.5，先把 7 转成 double，再除
```
## 2. 优先级表

**从高到底**

| 级别  | 运算符                                                                               | 结合性 |
| --- | --------------------------------------------------------------------------------- | --- |
| 1   | 函数调用 `()`，下标 `[]`，成员 `.` `->`，后缀 `++` `--`                                        | 左到右 |
| 2   | 前缀 `++` `--`，正负号 `+` `-`，逻辑非 `!`，按位取反 `~`，强制类型转换 `(type)`，解引用`*`，取地址 `&`，`sizeof` | 右到左 |
| 3   | 乘 `*`，除 `/`，取余 `%`                                                                | 左到右 |
| 4   | 加 `+`，减 `-`                                                                       | 左到右 |
| 5   | 左移 `<<`，右移 `>>`                                                                   | 左到右 |
| 6   | `<` `<=` `>` `>=`                                                                 | 左到右 |
| 7   | `==` `!=`                                                                         | 左到右 |
| 8   | 按位与 `&`                                                                           | 左到右 |
| 9   | 按位异或 `^`                                                                          | 左到右 |
| 10  | 按位或 `\|`                                                                          | 左到右 |
| 11  | 逻辑与 `&&`                                                                          | 左到右 |
| 12  | 逻辑或 `\|`                                                                          | 左到右 |
| 13  | 条件 `?:`                                                                           | 右到左 |
| 14  | 赋值 `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=`                       | 右到左 |
| 15  | 逗号 `,`                                                                            | 左到右 |
记忆口诀：**单目 > 算术 > 移位 > 关系 > 相等 > 位运算 > 逻辑 > 条件 > 赋值 > 逗号**

## 3. 容易出错的例子

### 3.1. 位运算优先级低于 `==`

```c
if (flags & 0x01 == 0)     // 错！等价于 flags & (0x01 == 0)，即 flags & 0
if ((flags & 0x01) == 0)   // 对
```

### 3.2. 移位优先级低于 `+`

```c
1 << 2 + 1     // 等价于 1 << (2+1) = 8，不是 (1<<2)+1 = 5
```

### 3.3. `*p++` 的含义

```c
*p++ // 后缀 ++ 优先级高于 *，等价于 *(p++)：取 p 指向的值，然后 p 后移
(*p)++ // 先解引用，再让指向的值加 1
```

### 3.4. 连续比较不是数学含义

```c
if (0 < x < 10)  // 等价于 (0 < x) < 10，结果恒为真，因为 (0<x) 只会是 0 或 1
if (0 < x && x < 10) // 对
```

### 3.5. `!` 优先级很高

```c
!a == b      // 等价于 (!a) == b，不是 !(a == b)
```

### 3.6. `&&` 高于 `||`

```c
a || b && c      // 等价于 a || (b && c)
```

这种写法容易读错，建议加括号

### 3.7. 赋值和比较写混

```c
if (x = 5)    // 是赋值，不是比较，条件恒为真。应写 x == 5
```

## 4. 优先级 ≠ 求值顺序

优先级决定的是"表达式怎么分组"，**不决定各操作数先算哪个**

```c
int r = f() + g();   // + 的两边谁先调用，C 标准没有规定
```

更危险的是在同一个表达式里多次修改同一个变量

```c
int i = 1;
int a = i++ + ++i;   // 未定义行为，结果不可预期
i = i++;             // 同样是未定义行为
```

只有少数运算符规定了求值顺序：`&&`、`||`、`?:`、`,`，它们在左右操作数之间有"序列点"。其余情况下，不要在一个表达式里对同一变量多次修改
## 5. 实用建议

- 拿不准就加括号，既避免错误，也方便别人阅读。
- 位运算、移位、比较混用时，一定加括号。
- 不要写依赖求值顺序的表达式
