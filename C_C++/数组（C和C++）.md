**数组：** 一块连续的内存，里面放着*相同类型*的若干个元素，通过下标访问

```c
int a[5]; // 5 个 int，在内存里紧挨着：a[0] a[1] a[2] a[3] a[4]
```

下标从 **0** 开始，最后一个元素是 `a[n-1]`

## 1. C中的数组

### 1.1. 定义：

```c
int a[5]; // 定义，未初始化
```

局部数组未初始化时，内容是随机值。全局或 `static` 数组会被自动置零

### 1.2. 初始化

```c
int a[5] = {1, 2, 3, 4, 5};   // 全部指定
int b[5] = {1, 2};            // 剩下的补 0：1 2 0 0 0
int c[5] = {0};               // 全部为 0
int d[] = {1, 2, 3};          // 省略长度，编译器数出来是 3
```

**C99 起支持指定初始化 ：**

```c
int e[5] = {[2] = 10, [4] = 20}; // 0 0 10 0 20
```

### 1.3. 使用

```c
a[0] = 100; // 写
*(a+0) = 100; // 写

int x = a[2] // 读
int x = *(a+2) // 读

for (int i = 0; i < 5; i++)
{
	printf("%d\n", a[i]);
	printf("%d\n", *(a+i))
}
```

### 1.4. 求元素个数

```c
int n = sizeof(a) / sizeof(a[0]);
```

### 1.5. C数组的特点

- **长度固定**：定义后不能改变
- **不检查越界**：`a[10]` 越界访问是未定义行为，不会报错，可能读到垃圾值，也可能崩溃
- 不能整体赋值或比较

```c
int a[3], b[3];
// a = b;        // 错误
// a == b        // 比较的是地址，不是内容
```

拷贝要用循环或 `memcpy`
- 数组名在多数表达式里会"退化"成指向首元素的指针
### 1.6. 传参时会退化成指针

```c
void f(int a[]) // 这里的 a 实际上是 int *a
{
	// 是指针的大小，不是数组的大小
	sizeof(a);
}
```

**所以，需要把长度传进去**

```c
void f(int *a, int n);
```
### 1.7. 变长数组（VLA）

C99 允许用运行时的变量定义长度

```c
int n = 5;
int a[n];       // C99 的变长数组
```

C11 起 VLA 变成了**可选特性**，有的编译器不支持。它在栈上分配，`n` 太大可能栈溢出。需要运行时长度时，更稳妥的做法是 `malloc`
## 2. 二维数组

```c
int m[2][3] = {{1,2,3}, {4,5,6}};
m[1][2]; // 6
*((*(m+1))+2) // 6
```

内存里是按行连续存放的：1 2 3 4 5 6

## 3. C++中的数组

C++ 保留了 C 风格数组（内置数组），定义、初始化、下标访问的写法基本一样

```c
int a[5] = {1, 2, 3, 4, 5};
int b[5] = {};      // 全部为 0，C++ 允许空花括号
```

同时增加了更方便的选择

### 3.1. `std::array`（C++11，固定长度）

```cpp
#inclue <array>
int main(void)
{
	std::array<int, 5> a = {1,2,3,4,5};
	a.size(); // 5
		a[2]; // 不检查越界
	a.at(2);  // 检查越界，越界抛异常
	for(int x : a){...} // 范围 for
	
	std::array<int, 5> b = a; // 可以整体拷贝
	a == b; // 可以比较内容
}
```

长度固定，不会退化成指针，传参时不丢失长度信息

### 3.2.  `std::vector`（动态长度）

```cpp
#include <vector>
int main(void)
{
	std::vector<int> v = {1,2,3};
	v.push_back(4); // 自动扩容
	v.size(); // 4
}
```

长度只在运行时才知道，或者需要增删元素时，用它

### 3.3. 内置数组也有一些C++的新用法

```cpp
int a[5] = {1,2,3,4,5};
for(int x : a) {...} // 范围 for，对内置数组也使用
std::size(a); // C++17起，在 <iterator> 中
```

## 4. C 和 C++ 数组的区别

|                    | C                                     | C++                          |
| ------------------ | ------------------------------------- | ---------------------------- |
| 内置数组               | 有                                     | 有，写法基本相同                     |
| 变长数组 VLA           | C99 支持，C11 起可选                        | 标准不支持，部分编译器作为扩展提供            |
| 标准库容器              | 无                                     | `std::array`、`std::vector` 等 |
| 范围 for             | 无                                     | 有（C++11）                     |
| 空初始化 `{}`          | C23 之前不是标准写法                          | 可以                           |
| 指定初始化 `[2] = 10`   | C99 支持                                | 不支持这种数组写法                    |
| 用字符串字面量初始化刚好放不下的数组 | `char s[5] = "hello";` 合法（没有结尾的 `\0`） | 同样写法会报错                      |
| 数组长度用 `const` 变量   | `const int n = 5;` 不算常量表达式            | 算常量表达式，可以直接 `int a[n];`      |
最后一行补充说明：在 C 里，`const int n = 5; int a[n];` 在函数内会被当成 VLA，在全局作用域则不合法。C++ 里这样写没有问题

## 5. C中数组无法转为(首元素地址)指针的情况

数组名在表达式里**默认**会自动转换成"指向首元素的指针"。这个转换有三种例外，数组名保持"数组"的身份

1. 作为 `sizeof` 的操作数
2. 作为取地址运算符 `&` 的操作数
3. 作为用来初始化字符数组的字符串字面量（这是字符串字面量本身的例外，不是数组变量的例外）

### 5.1. `sizeof`：得到整个数组的大小

```c
int a[5];
sizeof(a);       // 5 * sizeof(int)，整个数组的字节数
sizeof(a[0]);    // 一个元素的大小
```

如果 `a` 已经退化成指针，`sizeof(a)` 就只是指针的大小

```c
void f(int a[]) {
    sizeof(a);   // 指针的大小，不是数组大小
}
```

这就是为什么 `sizeof(a) / sizeof(a[0])` 只能在定义数组的那个作用域里用

### 5.2. `&`：得到"指向整个数组"的指针

```c
int a[5];
int *p = a;         // a 退化，p 是 int *，指向 a[0]
int (*q)[5] = &a;   // &a 不退化，q 的类型是"指向 5 个 int 的数组的指针"
```

`a` 和 `&a` 的**地址值相同**，但**类型不同**，所以做指针运算时步长不同

```c
a + 1      // 地址增加 sizeof(int)，指向 a[1]
&a + 1     // 地址增加 sizeof(int[5])，跳过整个数组
```

### 5.3. 字符串字面量初始化字符数组

```c
char s[] = "hello";    // s 是数组，6 个字节，内容被拷贝进来
const char *p = "hello";   // 这里字面量退化成指针，p 指向只读区
```

第一行不是"字符串退化成指针再赋值"，而是把字面量的内容逐个拷贝进数组 `s`。所以 `sizeof(s)` 是 6，而 `sizeof(p)` 是指针大小

**C++ 中额外的几种情况**
### 5.4. 引用绑定到数组

```cpp
int a[5];
int (&r)[5] = a;     // r 是数组的引用，不退化
sizeof(r);           // 整个数组的大小
```

### 5.5. 模板按引用接收数组

```cpp
template <size_t N>
void f(int (&arr)[N]) {      // N 会被自动推导为 5
    // 这里 arr 仍然是数组，长度信息保留
}
```

如果模板参数写成按值接收（`T arr`），数组还是会退化

## 6. 对照：会退化 vs 不会退化

```c
int a[5];

int *p = a;            // 退化
a + 1;                 // 退化
*a;                    // 退化，等价于 a[0]
a[2];                  // 下标运算本身就是 *(a+2)，数组先退化
f(a);                  // 传参，退化

sizeof(a);             // 不退化
&a;                    // 不退化
```

## 7. 一个容易误解的点

退化是**数组名的值被转换成指针**，数组本身并没有变成指针。数组是一块真实存在的连续内存，指针是另一个变量，里面存地址

```c
int a[5];
int *p = a;
sizeof(a);    // 20（若 int 为 4 字节）
sizeof(p);    // 指针大小，常见为 8（64 位平台）
// a = p;     // 错误：数组名不是可修改的左值
p = p + 1;    // 可以，p 是变量
```
