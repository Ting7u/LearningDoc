其中 `.data`、`.bss` 常合称**全局区 / 静态区**，`.rodata` 常被叫做**常量区 / 只读数据区**

## 2. 哪些变量在全局区（.data / .bss）

|变量|示例|作用域|
|---|---|---|
|全局变量|`int g = 10;`|整个程序（可被其他文件 `extern` 引用）|
|静态全局变量|`static int g = 10;`|仅当前 `.c` 文件|
|静态局部变量|函数内 `static int n = 0;`|仅当前函数内，但生命周期是整个程序|
```c
int g_init = 10;        // .data（已初始化，非 0）
int g_zero;             // .bss（未初始化）
int g_zero2 = 0;        // 通常也在 .bss（编译器优化，属于实现细节）
static int s_global = 5;// .data

void f(void) {
    static int count = 0;   // 全局区，不在栈上
    count++;
}
```

**.data 与 .bss 的区别：**
- `.data` 存放有初始值的变量，初始值保存在可执行文件里，占文件空间
- `.bss` 只记录"需要多大空间"，程序加载时由系统清零，不占可执行文件的空间

**静态存储期变量的关键特性：**
1. 未显式初始化时自动为 0（指针为 `NULL`），局部变量没有这个待遇。
2. 初始化只发生一次：静态局部变量的 `static int count = 0;` 只在程序启动时初始化，不是每次调用函数都执行。
3. 初始化值必须是常量表达式，不能用运行时才知道的值。
4. 生命周期是整个程序运行期间，函数返回后值依然保留。
## 3. 字符串字面量

```c
char *p   = "hello";    // p 是指针变量；"hello" 在只读区
char arr[] = "hello";   // arr 是数组；内容是从字面量拷贝来的一份
```

>`"hello"` 这段字符串本身存放在**只读区（.rodata）**，修改它是**未定义行为**，通常直接崩溃

```c
char *p = "hello";
p[0] = 'H';     // ❌ 通常段错误 / Access Violation
```

- `char arr[] = "hello";` 则不同：数组是一块可修改的内存，字面量只是用来初始化它的模板。`arr` 在哪个区，取决于它定义在哪里：
    - 定义在函数内 → 栈
    - 定义在函数外（全局）→ .data
- 想用指针指向字面量时，推荐写 `const char *p = "hello";`，这样误改会在编译期报错。
- 相同的字符串字面量，编译器可能合并成一份，也可能不合并，不要依赖这一点。
## 4. const 修饰的变量在哪？

**核心结论：`const` 不决定存放区域，决定区域的是变量的存储期。** `const` 只是告诉编译器"不要通过这个名字修改它"，编译器在条件允许时会把它放进只读区

| 情况         | 示例                              | 常见位置                      |
| ---------- | ------------------------------- | ------------------------- |
| 全局 const   | `const int a = 100;`            | 只读区（.rodata）              |
| 静态 const   | `static const int a = 100;`     | 只读区                       |
| 局部 const   | 函数内 `const int a = 100;`        | 栈（就是普通局部变量，只是编译器禁止你改）     |
| 静态局部 const | 函数内 `static const int a = 100;` | 只读区                       |
| const 指针本身 | `int *const p = &x;`            | 看 `p` 定义在哪：局部在栈，全局在 .data |
**区别：全局 const 与局部 const**

```c
const int g = 100;          // 只读区

int main(void) {
    const int l = 200;      // 栈上
    
    int *pg = (int *)&g;
    *pg = 1;                // ❌ 通常直接崩溃：写只读内存
    
    int *pl = (int *)&l;
    *pl = 1;                // ⚠️ 未定义行为：栈上可能"改成功"，
                            //    但标准不保证，不要这么写
    return 0;
}
```

局部 const 变量"能改"只是碰巧，**标准明确规定修改 const 对象是未定义行为**。编译器还可能把 `l` 直接优化成常数 200，你改了内存，但读取时用的仍是 200

### 4.1. const 与指针的四种组合

```c
int x = 1, y = 2;

const int *p1 = &x;       // 指向常量：*p1 不能改，p1 可以改指向
int const *p2 = &x;       // 同上，const 在 * 左边都是"指向的内容不可改"
int *const p3 = &x;       // 常量指针：p3 不能改指向，*p3 可以改
const int *const p4 = &x; // 两个都不能改
```

口诀：看 `*` 的左右。`const` 在 `*` 左边，管指向的内容；在 `*` 右边，管指针本身

### 4.2. C 与 C++ 的 const 差异

**C 中的 const 变量不是真正的常量表达式**

```c
const int n = 10;
int arr[n];            // C89 ❌；C99 起会被当作变长数组（VLA）
static int x = n;      // ❌ C 中错误：初始化值必须是常量表达式
```

C++ 中 `const int n = 10;` 可以当作常量使用。C 里想要真常量，用 `#define` 或 `enum`

链接性不同： C 中全局 const 默认是外部链接，C++ 中默认是内部链接
## 5. 函数参数在哪？

函数参数属于自动存储期，位于栈上

```c
void f(int a, int *p, Student s) {
    // a、p、s 都是"调用时拷贝出来的副本"，是被调函数自己的局部变量
}
```

### 5.1. 传递方式取决于调用约定（ABI）
- **x64 Windows**：前 4 个整数/指针参数通过寄存器（`RCX、RDX、R8、R9`）传递，更多的参数放栈上
- **x64 Linux（System V）**：前 6 个整数/指针参数通过寄存器传递
- 即使通过寄存器传递，函数内部需要时（如取地址、寄存器不够）也会把它保存到栈上

写代码时，把参数理解为"栈上的局部变量"就够用了

### 5.2. 各种参数的细节

| 参数类型            | 实际发生了什么                                                        |
| --------------- | -------------------------------------------------------------- |
| 基本类型 `int a`    | 拷贝值，修改不影响实参                                                    |
| 指针 `int *p`     | 拷贝的是**地址值**，`p` 本身在栈上，它指向的数据在哪都行（栈、堆、全局区）                      |
| 结构体 `Student s` | **整个结构体被拷贝一份**；结构体较大时，具体传递方式由 ABI 决定（可能放栈上或通过隐藏指针），所以大结构体通常传指针 |
| 数组 `int a[]`    | **退化为指针**，等价于 `int *a`，不会拷贝数组                                  |
| `const` 参数      | 见下                                                             |
### 5.3. 数组参数退化（经典坑）

```c
void f(int a[10]) {
    printf("%zu\n", sizeof(a));   // 打印的是指针大小（8 或 4），不是 40
}
```

`int a[10]` 里的 10 会被编译器忽略。所以传数组时必须另外传长度：`void f(int *a, int n)`

### 5.4. const 修饰参数

```c
void f(const int x);          // const 修饰按值传递的参数
void g(const Student *s);     // const 修饰指针指向的内容
```

- `const int x`：参数依然是栈上的副本，`const` 只是禁止函数内部修改 `x`，对调用者没有任何影响，所以实际很少这么写
- `const Student *s`：这才是最常用的形式，表示"我只读你的数据，不会修改"，同时避免了结构体拷贝

### 5.5. 其他位置的变量

| 变量             | 位置      | 说明                              |
| -------------- | ------- | ------------------------------- |
| 普通局部变量         | 栈       | 函数返回即销毁，不初始化则是垃圾值               |
| 局部数组           | 栈       | 包括 `char arr[] = "hello";`      |
| `register` 变量  | 寄存器或栈   | 只是建议，编译器自行决定，且不能取地址             |
| `malloc` 申请的内存 | 堆       | 需手动 `free`；注意指针变量本身在栈上，指向的内存在堆上 |
| 函数本身           | `.text` | 函数名是代码段的地址                      |

```c
void f(void) {
    int *p = malloc(sizeof(int));  // p 在栈上，*p 在堆上
    *p = 10;
    free(p);
}
```
### 5.6. 总汇总表

| 种类        | 存放区域         | 生命周期      | 未初始化时             |
| --------- | ------------ | --------- | ----------------- |
| 全局变量      | .data / .bss | 整个程序      | 自动为 0             |
| 静态全局变量    | .data / .bss | 整个程序      | 自动为 0             |
| 静态局部变量    | .data / .bss | 整个程序      | 自动为 0             |
| 全局 const  | .rodata      | 整个程序      | （必须初始化）           |
| 字符串字面量    | .rodata      | 整个程序      | —                 |
| 局部变量      | 栈            | 所在代码块     | 垃圾值               |
| 局部 const  | 栈            | 所在代码块     | 垃圾值               |
| 函数参数      | 栈 / 寄存器      | 函数调用期间    | 由实参初始化            |
| malloc 内存 | 堆            | 直到 `free` | 垃圾值（`calloc` 会清零） |
