# 第 1 章 从 C 到 C++

> 目标：知道 C++ 在 C 的基础上改了什么、加了什么，以及哪些 C 的习惯在 C++ 里要改掉。你有 C 基础，所以本章的主线是"差异"。

---

## 1.1 C++ 不是"带类的 C"

C++ 是**多范式**语言，同一个问题可以用不同风格解决：

| 范式 | 在 C++ 中的体现 |
|------|----------------|
| 过程式 | 函数、结构体（和 C 相同） |
| 面向对象 | 类、继承、虚函数（第 6–8 章） |
| 泛型 | 模板、STL（第 9–10 章） |
| 函数式 | lambda、`std::function`、Ranges（第 12、14 章） |

C++ 的一个核心设计取向是**零开销抽象**：你没用到的特性不产生代价，用到的抽象也尽量不比手写更慢（这是对该设计原则的转述，不是原话）。

### 同一个任务，两种风格

任务：拼接两个字符串。

**C 风格**

```c
#include <stdlib.h>
#include <string.h>

char* join(const char* a, const char* b) {
    char* r = malloc(strlen(a) + strlen(b) + 1);
    if (!r) return NULL;
    strcpy(r, a);
    strcat(r, b);
    return r;                 /* 调用者必须记得 free */
}
```

**C++ 风格**

```cpp
#include <string>

std::string join(const std::string& a, const std::string& b) {
    return a + b;             // 内存由 std::string 自己管理
}
```

C++ 版本没有手动内存管理，也不会泄漏。这就是后面第 5 章会讲的 **RAII** 思想的最简单体现。

## 1.2 `bool`

C++ 有内置的 `bool` 类型，取值 `true` / `false`，不需要 `<stdbool.h>`。

```cpp
#include <iostream>

int main() {
    bool ok = true;
    int n = 5;
    bool nonzero = n;                        // 非 0 → true，0 → false

    std::cout << std::boolalpha;             // 让 bool 输出 true/false 而不是 1/0
    std::cout << ok << ' ' << nonzero << '\n';   // true true
    std::cout << sizeof(bool) << '\n';       // 通常是 1，标准未规定具体值
}
```

## 1.3 `nullptr`

C 里用 `NULL`，它在 C++ 中通常被定义成 `0` 或类似的整数形式，会和重载打架：

```cpp
#include <iostream>

void f(int)   { std::cout << "f(int)\n"; }
void f(char*) { std::cout << "f(char*)\n"; }

int main() {
    f(0);          // f(int)
    f(nullptr);    // f(char*)
    // f(NULL);    // 结果取决于编译器对 NULL 的定义：可能二义性报错、也可能选 f(int)
}
```

`nullptr` 的类型是 `std::nullptr_t`，可以隐式转换成任意指针类型，但**不会**转换成整数。**在 C++ 里表示空指针一律用 `nullptr`。**

## 1.4 `enum class`（强类型枚举）

C 风格 `enum` 有两个问题：枚举名泄漏到外层作用域，且会隐式转成整数。

```cpp
enum Color { Red, Green };
// enum Fruit { Red, Apple };   // 错误：Red 重复定义（名字泄漏到了外层）

int x = Green;                  // 隐式转换成 int，不报错 —— 容易混用
```

`enum class` 解决了这两个问题：

```cpp
#include <cstdint>
#include <iostream>

enum class Light : std::uint8_t { Red, Yellow, Green };   // 可以指定底层类型

int main() {
    Light l = Light::Red;                    // 必须带作用域
    // int x = l;                            // 错误：不能隐式转 int
    int x = static_cast<int>(l);             // 需要显式转换
    std::cout << x << '\n';                  // 0

    if (l == Light::Red) {
        std::cout << "stop\n";
    }
}
```

要点：
- 枚举值要写成 `Light::Red`。
- 不同 `enum class` 之间互不冲突，也不能互相比较。
- 默认底层类型是 `int`，可以用 `: 类型` 指定。
- 新代码优先用 `enum class`。

## 1.5 `using` 与 `typedef`

两者都能起类型别名，`using` 读起来更直观，并且能做 `typedef` 做不到的事。

```cpp
#include <vector>

typedef unsigned long ulong_old;             // 旧写法：名字在最后
using ulong_new = unsigned long;             // 新写法：像赋值，从左往右读

typedef int (*OldFn)(int, int);              // 函数指针：难读
using NewFn = int (*)(int, int);             // 清晰一些

template <typename T>
using Vec = std::vector<T>;                  // 别名模板：typedef 做不到

Vec<int> v;                                  // 等价于 std::vector<int>
```

此外 `using` 还有另外两种用法（见 1.9）：`using std::cout;`（using 声明）和 `using namespace std;`（using 指令）。

## 1.6 引用（`&`）

引用是对象的**别名**。

```cpp
#include <iostream>

void swap_c(int* a, int* b)   { int t = *a; *a = *b; *b = t; }   // C 风格：指针
void swap_cpp(int& a, int& b) { int t = a;  a = b;  b = t; }     // C++ 风格：引用

int main() {
    int x = 1, y = 2;
    swap_c(&x, &y);          // 调用时要取地址
    swap_cpp(x, y);          // 调用时像传值一样写
    std::cout << x << ' ' << y << '\n';   // 两次交换，回到 1 2
}
```

### 引用 vs 指针

| 对比项 | 指针 | 引用 |
|--------|------|------|
| 必须初始化 | 否（但应该初始化） | **是** |
| 可以为空 | 可以（`nullptr`） | **没有空引用** |
| 可以改指向 | 可以 | **不能**，终身绑定同一个对象 |
| 自身占内存 | 有（是一个对象） | 标准未规定，通常不用关心 |
| 取地址 `&` | 得到指针自己的地址 | 得到被引用对象的地址 |
| 解引用 | 需要 `*` | 不需要 |

最容易搞混的一点：**对引用赋值，是改被引用的对象，而不是让引用重新绑定。**

```cpp
int a = 1, b = 2;
int& r = a;
r = b;                  // 等价于 a = b，a 变成 2；r 仍然绑定 a
```

### `const` 引用

```cpp
#include <iostream>
#include <string>

void print(const std::string& s) {           // 只读，且不拷贝
    std::cout << s << '\n';
}

int main() {
    std::string name = "C++";
    print(name);
    print("temp");                           // 临时对象可以绑定到 const 引用
}
```

`const T&` 可以绑定临时对象，普通 `T&` 不行：

```cpp
// int& r1 = 5;           // 错误
const int& r2 = 5;        // OK
```

### 悬空引用

```cpp
int& bad() {
    int x = 1;
    return x;                 // 返回局部变量的引用 → 调用结束后 x 已销毁
}
// int& r = bad();  使用 r 是未定义行为
```

### 传参的经验法则

| 场景 | 写法 |
|------|------|
| 小类型（`int`、`double`、指针等），只读 | `void f(int x)`，按值传 |
| 大对象，只读 | `void f(const T& x)` |
| 需要修改调用者的对象 | `void f(T& x)` |
| 可能"没有对象" | 指针（可为 `nullptr`）或 `std::optional`（第 10 章） |

## 1.7 `const` 的差异

### 1) C++ 的全局 `const` 是真常量，可用于数组大小

```cpp
const int N = 10;
int arr[N];                  // C++ 合法：N 是编译期常量
// 在 C 里，N 不是常量表达式；C89 报错，C99 起 arr 变成变长数组（VLA）
```

### 2) 命名空间作用域的 `const` 默认是内部链接

```cpp
// config.h
const int MAX_USERS = 100;   // 每个包含它的 .cpp 各有一份，不会 multiple definition
```

在 C 里，全局 `const int` 默认是外部链接，放进头文件被多个 `.c` 包含会导致重复定义。C++ 里则没有这个问题。

### 3) 常见指针与 `const` 组合（第 4 章会细讲）

```cpp
int x = 1, y = 2;
const int* p1 = &x;          // 指向常量的指针：不能通过 p1 改 x，但 p1 可以改指向
int* const p2 = &x;          // 常量指针：p2 不能改指向，但可以通过 p2 改 x
const int* const p3 = &x;    // 都不能改
```

记忆方法：从右往左读，`const` 修饰它左边的东西（左边没东西才修饰右边）。

### 4) `constexpr` 预告

```cpp
constexpr int square(int n) { return n * n; }
constexpr int a = square(5);   // 编译期计算
int arr2[a];                   // a 是常量表达式，可以做数组大小
```

## 1.8 `inline` 与 `static`

### `inline`

在 C++ 里，`inline` 的**主要含义**是：允许同一个函数在多个编译单元中有相同的定义，而不违反"单一定义规则"（ODR）。是否真的内联展开由编译器决定，`inline` 只是一个建议。

```cpp
// util.h
#pragma once

inline int twice(int x) { return x * 2; }    // 放在头文件里没问题
```

没有 `inline` 就会在多个 `.cpp` 都包含 `util.h` 时报 `multiple definition`（见第 0 章）。

C++17 起变量也可以是 `inline`：

```cpp
// config.h
inline int g_counter = 0;                    // 多个编译单元共享同一个变量，不会重复定义
```

### `static` 的几种含义

```cpp
#include <iostream>

static int file_private = 0;                 // ① 文件作用域：内部链接，别的 .cpp 看不见

int next_id() {
    static int id = 0;                       // ② 函数内 static：只初始化一次，生命周期到程序结束
    return ++id;
}

int main() {
    std::cout << next_id() << next_id() << next_id() << '\n';   // 123
}
```

③ 类内的 `static` 成员属于类本身而非某个对象，第 6 章再讲。

C++ 里想要"文件内部私有"，更推荐用**匿名命名空间**（见 1.9），不过 `static` 仍然合法。

## 1.9 命名空间（`namespace`）

C 靠给函数加前缀（`mylib_init`）避免重名，C++ 用命名空间。

```cpp
#include <iostream>

namespace audio {
    void init() { std::cout << "audio init\n"; }
}

namespace video {
    void init() { std::cout << "video init\n"; }

    namespace codec {                         // 可以嵌套
        void load() { std::cout << "video::codec::load\n"; }
    }
}

int main() {
    audio::init();
    video::init();
    video::codec::load();
}
```

命名空间可以在多个文件、多处重复"打开"，内容会合并。

### `using` 声明 vs `using` 指令

```cpp
using std::cout;              // using 声明：只引入一个名字
using namespace std;          // using 指令：引入整个命名空间的所有名字
```

**建议**：
- **绝不要在头文件里写 `using namespace xxx;`**，会污染所有包含它的文件。
- `.cpp` 文件里也尽量少用 `using namespace std;`，容易和自己的名字冲突；用 `using std::cout;` 或直接写 `std::` 更安全。

### 命名空间别名

```cpp
namespace vc = video::codec;
vc::load();
```

### 匿名命名空间

```cpp
namespace {
    int helper_count = 0;                     // 只在当前文件可见（内部链接）
    void helper() { ++helper_count; }
}
```

作用与文件级 `static` 类似，是 C++ 更推荐的写法。

## 1.10 `iostream` 与 `std::string`

### 输出与输入

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age = 0;

    std::cout << "name? ";
    std::cin >> name;                         // 读到空白字符为止
    std::cout << "age? ";
    std::cin >> age;

    std::cout << "Hello, " << name << ", " << age << " years old\n";
}
```

- `std::cout` 输出，`<<` 可以连着写。
- `std::cin` 输入，`>>` 会自动按变量类型解析，不需要格式串。
- 读取整行：`std::getline(std::cin, line);`（注意：`cin >> x` 之后缓冲区里还留着换行，紧接着 `getline` 会读到空行，需要先清掉）。
- 判断输入是否成功：

```cpp
int x;
if (!(std::cin >> x)) {
    std::cout << "输入不是整数\n";
}
```

### `'\n'` 和 `std::endl`

`std::endl` = 换行 + **刷新缓冲区**。频繁刷新会慢，一般用 `'\n'` 就够了。

### 和 `printf` 的对比

```cpp
printf("%d\n", 3.5);             // 类型和格式符不匹配 → 未定义行为，编译器最多警告
std::cout << 3.5 << '\n';        // 流会根据类型选择正确的输出方式，类型安全
```

| 对比项 | `printf` | `iostream` |
|--------|----------|------------|
| 类型安全 | 否 | 是 |
| 支持自定义类型 | 否 | 可以（重载 `<<`，第 7 章） |
| 格式控制 | 格式串简洁 | 操纵符（`std::hex`、`std::setw` 等）较啰嗦 |

较新的标准提供了格式化输出的新方案：C++20 的 `std::format`、C++23 的 `std::print`，兼顾类型安全与简洁的格式串（具体编译器版本的支持程度请自行确认）。

### 性能小提示

```cpp
std::ios::sync_with_stdio(false);   // 关闭与 C stdio 的同步，输入输出大数据时更快
std::cin.tie(nullptr);              // 解除 cin 与 cout 的绑定
```

关闭同步后，**不要再混用** `printf` 和 `cout`，输出顺序可能乱。

### `std::string` vs `char*`

```cpp
#include <iostream>
#include <string>

int main() {
    std::string a = "hello";
    std::string b = " world";

    std::string c = a + b;                    // 直接拼接
    std::cout << c << '\n';                   // hello world
    std::cout << c.size() << '\n';            // 11（也可以用 length()）
    std::cout << (a == "hello") << '\n';      // 1：可以直接用 == 比较内容
    std::cout << c.substr(0, 5) << '\n';      // hello
    std::cout << c.find("world") << '\n';     // 6（找不到返回 std::string::npos）

    c += "!";                                 // 追加
    c[0] = 'H';                               // 下标访问
    std::cout << c << '\n';                   // Hello world!

    const char* raw = c.c_str();              // 需要传给 C API 时用 c_str()
    std::cout << raw << '\n';
}
```

| 对比项 | `char*` / `char[]` | `std::string` |
|--------|--------------------|---------------|
| 长度 | 靠 `\0` 结尾，要 `strlen` | 自己记录长度 |
| 拼接/复制 | `strcat`/`strcpy`，要自己保证空间 | `+` / `=`，自动扩容 |
| 比较 | `strcmp` | `==`、`<` 等 |
| 内存管理 | 手动 | 自动 |

字符串字面量 `"abc"` 的类型是 `const char[4]`，不是 `std::string`。

## 1.11 C++ 的四种类型转换

C 风格转换 `(T)x` 太"万能"，能同时做多种性质不同的转换，而且不易搜索。C++ 把它拆成四种：

| 转换 | 用途 | 检查时机 |
|------|------|----------|
| `static_cast<T>` | 相关类型之间的"正常"转换（数值转换、`void*` ↔ `T*`、基类 ↔ 派生类） | 编译期 |
| `dynamic_cast<T>` | 带虚函数的类层次中，安全的向下转型 | 运行期（RTTI） |
| `const_cast<T>` | 去掉/加上 `const`、`volatile` | 编译期 |
| `reinterpret_cast<T>` | 底层的"按另一种类型重新解释"位模式 | 编译期（几乎不检查） |

### `static_cast`

```cpp
#include <cstdlib>
#include <iostream>

int main() {
    double d = 3.99;
    int i = static_cast<int>(d);                       // 3，截断而非四舍五入
    std::cout << i << '\n';

    void* vp = std::malloc(sizeof(int));
    int* ip = static_cast<int*>(vp);                   // C++ 不允许 void* 隐式转 T*，必须显式
    *ip = 7;
    std::cout << *ip << '\n';
    std::free(vp);
}
```

### `dynamic_cast`

```cpp
#include <iostream>

struct Base {
    virtual ~Base() = default;                         // 必须有虚函数（多态类型），详见第 8 章
};
struct Derived : Base {
    void hello() { std::cout << "Derived::hello\n"; }
};

int main() {
    Derived d;
    Base* pb = &d;

    if (auto* pd = dynamic_cast<Derived*>(pb)) {       // 失败时指针版本返回 nullptr
        pd->hello();
    }
}
```

对引用做 `dynamic_cast` 失败时会抛出 `std::bad_cast` 异常。

### `const_cast`

```cpp
void legacy_print(char* s);                            // 旧 API，参数没写 const，但实际不修改

void demo() {
    const char* msg = "hi";
    legacy_print(const_cast<char*>(msg));              // 前提：函数确实不会修改内容
}

// 危险：如果原对象本身就是 const，通过转换后的指针去修改它是未定义行为
// const int c = 10;
// int* p = const_cast<int*>(&c);
// *p = 20;                                            // 未定义行为
```

### `reinterpret_cast`

```cpp
#include <cstddef>
#include <iostream>

int main() {
    float f = 1.0f;
    auto* bytes = reinterpret_cast<unsigned char*>(&f);   // 以字节视角查看对象：这种用法是允许的
    std::cout << std::hex;
    for (std::size_t i = 0; i < sizeof f; ++i) {
        std::cout << +bytes[i] << ' ';                    // 一元 + 把 unsigned char 提升成 int 再输出
    }
    std::cout << '\n';                                    // 小端机器上常见输出：0 0 80 3f
}
```

但把 `float*` 强转成 `int*` 再解引用，违反"严格别名规则"，属于未定义行为：

```cpp
// float f = 1.0f;
// int bits = *reinterpret_cast<int*>(&f);   // 未定义行为
```

要读取位模式，用 `std::memcpy`，或者 C++20 的 `std::bit_cast`（`<bit>`）。

### 为什么不推荐 C 风格转换

```cpp
const char* s = "hi";
char* p = (char*)s;           // 悄悄去掉了 const，没有任何提示
```

用具名转换，意图一目了然，出了问题可以直接搜索 `const_cast` / `reinterpret_cast`。

## 1.12 `extern "C"`：C 与 C++ 混合编程

第 0 章提到，C++ 会对函数名做**名字改编**以支持重载，而 C 不会。C++ 想调用 C 编译出来的函数，必须告诉编译器"这个函数按 C 的方式找符号"，这就是 `extern "C"`。

### 示例：C++ 调用 C 库

**`clib.h`**

```c
#ifndef CLIB_H
#define CLIB_H

#ifdef __cplusplus
extern "C" {
#endif

int c_add(int a, int b);

#ifdef __cplusplus
}
#endif

#endif
```

**`clib.c`**

```c
#include "clib.h"

int c_add(int a, int b) { return a + b; }
```

**`main.cpp`**

```cpp
#include <iostream>
#include "clib.h"

int main() {
    std::cout << c_add(2, 3) << '\n';     // 5
}
```

构建：C 文件用 C 编译器，C++ 文件用 C++ 编译器，最后用 `g++` 链接：

```bash
gcc -c clib.c -o clib.o
g++ -std=c++17 -c main.cpp -o main.o
g++ main.o clib.o -o app
./app
```

如果去掉头文件里的 `extern "C"`，C++ 会去找改编后的符号，链接时报类似：

```
undefined reference to `c_add(int, int)'
```

`#ifdef __cplusplus` 是标准写法：`__cplusplus` 宏只有 C++ 编译器才定义，所以同一个头文件 C 和 C++ 都能包含。

### 反方向：C 调用 C++ 函数

```cpp
// api.cpp
extern "C" int cpp_add(int a, int b) { return a + b; }
```

限制：`extern "C"` 的接口只能用 C 能表达的东西（基础类型、指针、结构体）。**不能**暴露重载、类、模板、引用，且 `extern "C"` 函数不能同名重载。

### C 标准库头文件

C++ 中可以用 C 标准库，推荐使用 `c` 前缀、无 `.h` 的版本：

```cpp
#include <cstdio>     // 代替 <stdio.h>，名字在 std:: 中（通常也在全局作用域）
#include <cstdlib>
#include <cstring>
#include <cmath>
```

## 1.13 其他需要留意的 C / C++ 差异速查表

| 项目 | C | C++ |
|------|---|-----|
| 字符字面量 `'A'` 的类型 | `int`（`sizeof('A')` 通常是 4） | `char`（`sizeof('A')` 是 1） |
| `void*` → `T*` | 可隐式转换 | 必须显式转换 |
| `int f();` | 参数未指定（C23 起表示无参） | 表示**无参数** |
| 结构体类型名 | `struct S s;`（或 `typedef`） | 直接 `S s;` |
| 全局 `const` 的链接性 | 外部链接 | 内部链接 |
| `goto` 跳过变量初始化 | 允许 | 不允许（编译错误） |
| 新增关键字 | — | `class`、`new`、`delete`、`this`、`template`、`namespace`、`try`/`catch`、`bool`、`nullptr`…（不能再拿来当变量名） |
| 变长数组（VLA） | C99 起支持 | **不是标准 C++**，部分编译器作为扩展提供 |
| 指定初始化器 `{.x = 1}` | C99 | C++20 起支持，且有顺序等限制 |
| `main` | 可以省略 `return` 的版本较多样 | `main` 必须返回 `int`，可省略 `return 0;` |

## 1.14 小结

- C++ 是多范式语言；能用标准库管理资源就不要手动管理。
- 新写法对照：`bool`、`nullptr`、`enum class`、`using`。
- 引用是不可重绑定、不能为空的别名；只读大对象用 `const T&`。
- C++ 的 `const` 更"常量"：能做数组大小，全局默认内部链接。
- `inline` 的核心作用是允许多处相同定义；`static` 有文件私有、函数内持久变量等含义。
- 用命名空间代替前缀，不要在头文件写 `using namespace`。
- 输入输出用 `iostream`，字符串用 `std::string`。
- 四种具名转换替代 C 风格转换：`static_cast` 最常用，`reinterpret_cast` 最危险。
- C/C++ 混合编程：头文件里用 `#ifdef __cplusplus` + `extern "C"`。

## 练习

1. 写 `enum class Weekday { Mon, Tue, ... }`，再写函数 `std::string to_string(Weekday)`，体会不能隐式转换。
2. 实现 `void swap_ptr(int*&, int*&)`（指针的引用），交换两个指针的指向。
3. 在一个头文件里写 `const int LIMIT = 10;`，被两个 `.cpp` 包含，确认能链接成功；再把 `const` 去掉，观察报错。
4. 写两个命名空间，里面各有一个同名函数，用 `using` 声明在函数内部选择其中一个。
5. 用 `reinterpret_cast<unsigned char*>` 打印 `int 1`、`int -1` 的每个字节，推断你机器的字节序。
6. 按 1.12 节完整做一遍 C/C++ 混合编译，并故意去掉 `extern "C"` 观察链接错误。
